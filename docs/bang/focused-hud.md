## 화면과 연결 방식

- 상단: 게임명·현재 차례·남은 시간. 기록·채팅은 버튼으로 열 때만 표시한다.
- 참가자: 한 줄 요약에서 이름/공개 역할·생명력·무기/사거리·손패 수만 비교한다. 누르면 기존 전체 `PlayerInfo`로 인물·능력·장비를 읽는다. 비공개 역할은 요약과 상세에서 모두 유지한다.
- 하단: 내 역할·생명력·무기/사거리와 손패를 모은다. 승리 목표·능력·장비는 ‘내 역할·능력’으로 연다.
- 카드: 한국어 이름·그림·문양/숫자·종류만 상시 표시한다. 효과/사용 규칙은 hover, 키보드 포커스, 터치, 선택 후 ‘설명’으로 확인한다. 선택한 카드에 대해서만 설명/대상/행동을 표시한다.
- 대상이 필요한 카드는 서버가 허용한 상대 요약을 눌러 선택할 수 있다. 기존 대상/행동 드롭다운도 유지한다. 여러 뽑기 선택지는 한 드롭다운과 확정 버튼으로 모은다. 시드가 손패 두 장을 고르면 개별 카드 사용은 제외하고 두 장으로 실행하는 회복 행동만 제시한다.
- 방어 요청에는 공격자와 공격 종류를 표시한다. 상대 차례에는 대기 중임을 명시한다. 실제 행동·타임아웃·기권·결과·복구·정산은 기존 서버 계약을 따른다.
- 상세 창은 native dialog로 배경 클릭/Tab 이동을 제한하며 닫기/Esc/바깥 클릭으로 닫고 원래 버튼으로 포커스를 복원한다. 창 안 장비의 설명창은 같은 dialog에 포털로 표시한다.
- 작은 화면은 상대/손패를 가로로 넘기고 행동 버튼을 손패 바로 아래에 표시한다. 매우 낮은 화면에서도 실제 스크롤 영역을 유지하고 스크롤바는 숨긴다.
