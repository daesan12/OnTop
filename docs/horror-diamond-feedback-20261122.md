## MR 피드백 검토

- InteriorEncounters의 accent는 보석 조명이 아니라 공포 이벤트 대상의 보조광이다.
  기본 intensity=0이며 이벤트의 종류·위치·크기에 따라 배치된다. 획득 시에는 별도
  보석 하이라이트를 만들지 않고 기존 소리와 ref 표시만 갱신한다. 전시 높이에 맞춰
  이 조명을 옮기지 않았으며 역할을 주석으로 명시했다. 기존 램프·손전등도 유지한다.
- 얇은 유리관의 side=2를 명시적인 FrontSide로 바꿨다. 바깥에서 볼 때 앞면만 합성해
  앞뒤 유리의 반투명 막이 겹치는 현상을 줄인다. opacity=.12, depthWrite=false,
  색·거칠기·clearcoat와 유리 형상·위치는 유지했다. 창 밖에서 보는 용도의 단면 표시이며
  새 굴절/투과 모델이나 조명을 추가하지 않는다.
  근거: https://threejs.org/docs/pages/Material.html
- Browser plugin 미제공으로 기존 Playwright/Chrome을 사용했다. 단순 별도 조명 대신
  실제 HorrorZone 전체와 기존 램프·손전등을 렌더링해 정면·좌측·우측·비스듬한 각도
  4개에서 DoubleSide/FrontSide를 비교했다. 공포맵 안내를 실제 버튼으로 닫고 검수했다.
  재현 가능한 비교를 위해 프리뷰 시계를 고정했으며 실서버 이동/게임 입력 검증은 아니다.
- 실제 소스 기본 side=FrontSide를 재검증했다. 표시 중심은 [18.1,8.27,-76.5],
  보석/체인의 최하단 약 8.0035m, 전시함 바닥 기준 7.85m로 받침대에 가리지 않는다.
  획득 상태를 적용하면 보석·체인만 숨고 무광 전시대·유리관이 남는 것을 확인했다.
  평상시 accent는 intensity=0이었다. 앱 오류 없음. 검증용 Chrome·서버는 종료했다.
- FE 14개 테스트·타입 검사·park-integration 빌드 통과. 이번 피드백에서는 E 획득 기준,
  충돌·좌표·생성 맵/버전·FE/BE 계약·DB/Flyway·인프라를 변경하지 않았다.
