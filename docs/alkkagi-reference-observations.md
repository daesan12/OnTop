## 이번 구현 선택

- 반지름을 소형(사/병/졸).24, 중형(차/마/상/포).32, 왕.43으로 구분한다. 영상 폭 비율28:37:50에 가깝게 맞춘 로컬 값이다.
- 첫 근사값 .8/1.4/2.6과 같은 에너지 발사 모델은 사용자 검수에서 ‘졸이 왕을 너무 쉽게 밀어냄’으로 기각됐다. 크기 면적비를 그대로 질량으로 쓰는 것으로는 요구한 게임성을 만들지 못했다.
- 현재 질량은 소형/중형/왕 .8/3.2/19.2(1:4:24)다. **사용자가 정정한 크기별 밀림 저항을 구현한 게임 밸런스 값**이며, 영상에서 역산한 원작 질량이 아니다.
- 발사량은 `기준 충격량 × power × (질량/.8)`으로 출발 속도를 같게 유지한다. 큰 알은 충격량과 밀림 저항이 함께 커진다. 작은 알의 출발 속도만 높이는 이전 에너지 모델은 사용하지 않는다.
- 2026-10-31 사용자 검수에서 왕의 과도한 이동이 확인되어 감속5→30으로 수정했다. 반발.90·기준 충격량12·질량비는 유지한다. 기존 감속5의 최대 자유 이동22.4375칸은 판9×10에 비해 과도했다. 실제 dyn4j 충돌체/감속을 공유하는 무충돌 검사에서 소형·중형·왕 모두 최대힘3.6875칸/이동 약.492초, 절반힘.90625칸,1/4힘.21875칸을 확인했다. 원작 실측이 아닌 현재 로컬 검수 모델이다.
- 같은 근접 정면 충돌(표면 간격.05, 최대 힘,120Hz,4초)에서 졸→왕.024363칸, 중형→왕.265970칸으로 확인했다. 왕→졸은 판 밖으로 보낼 수 있는 힘이다. 경계 없는 두 물체 검사이므로 왕→졸의 전체 이동 거리를 실제 판 이동 거리로 제시하지 않는다. 실제 판의 탈락/턴 전환과 화면 동기화는 별도 검사한다.
- 뒤줄 중앙 빈칸과 포 열/행을 수정했다. 화면·충돌체는 계속 팔각 기둥/원이다. 원작 고정 벽은 기존 확정사항대로 제거하고 아이템 벽만 후속 구현한다.

## 오발 수정

기존 조준은 알 중심에서 포인터 위치를 빼므로 알 가장자리 클릭 자체가 당김으로 계산될 수 있었다. 첫 제스처는 선택만 하고, 이미 선택한 알을 다시 누른 시점의 포인터 위치부터 이동량을 계산한다. 화면12px 미만 또는 판 좌표.08 미만 이동은 발사하지 않는다. Esc·우클릭·입력 취소는 선택/조준을 취소한다. 클릭·미세 흔들림으로 서버 SHOT을 전송하거나 차례를 소비하지 않는다.

단위 테스트와 실제 Chrome의 클릭/드래그 회귀 테스트를 함께 사용한다. 손맛 최종 확정은 로컬에서 큰/작은 알을 직접 비교하는 검수가 남는다.
