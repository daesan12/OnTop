# 주민 NPC와 오목 서비스 연결

AI 운영 안내 공통 기반 MR 위에 주민 대결·관전·표시를 추가한다. 기존 플레이어 오목판을 사용하고 NPC 판은 서버의 별도 0냥 연습 경기로 관리한다. 빈자리에서 쉬움 강잼민·보통 윤한수·어려움 박영감을 선택하거나 혼자 대기하면 약 30초 뒤 보통 상대를 부른다. 주민이 도착해 앉으면 시작하며 무르기·무승부 요청은 거절한다. 한 테이블에 관전 주민은 최대 2명이다. 사람과의 경기 정산·지갑은 변경하지 않는다.

정식 dev/prod/production 서비스는 `AI_ENABLED`·`AI_RESIDENTS_ENABLED`로 켜고 끈다. `/api/v1/ai/features`가 초기화된 주민 기능을 알려주며, 서비스 빌드도 이 응답에 따라 기존 오목판·빈자리 난이도 선택을 표시한다. `/api/v1/ai/companions/status|invite|action|talk`는 로그인한 회원과 실제 공원 채널을 확인한다. 작성자 ID는 본문이 아닌 인증 Principal에서 가져오며 대결의 좌석·소유자·버전·차례 검사는 기존 서비스가 수행한다. 로컬 위치 이동/검수 flush 같은 제어 API는 운영에 노출하지 않는다.

NPC 대결은 0냥·재화 변동 없는 서버 메모리 연습 경기다. 재시작/접속 해제/좌석 변경 시 예약을 해제하고 다시 부르는 방식이며 사람 간 경기의 정산·DB 결과에 끼워 넣지 않는다. 내구성이 필요한 검수·MM 기록은 선행 !502의 DB 저장소를 사용한다. 신규 마이그레이션은 없다. Rapfi는 `AI_RAPFI_PATH`로 서버 OS에 맞는 실행 파일을 지정하며 미설정 시 내장 전술 로직으로 대결하고 실제 엔진 승률은 표시하지 않는다. 로컬 검수 전용 부트스트랩은 기존대로 별도 유지한다.

`scripts/start-ai-park.cmd -Offline`로 검수 서버를 실행할 수 있다. Jev/MM 검수는 기존 로컬 실행 스크립트의 `-LiveJev -LiveMattermost` 옵션을 사용하고 키는 실행한 PowerShell 환경에만 둔다. 이번 MR 검증은 실제 키/웹훅을 사용하지 않는다. Rapfi 실행 파일은 `AI_LAB_RAPFI_PATH`로 지정하고 미설치 시 전술 대체 로직을 사용한다. 서버 운영체제와 맞는 바이너리·평가 파일은 별도로 필요하다.

경찰은 전체 공원, 주민은 현재 맵 테이블 앵커의 경계에 여유 8m를 둔 구역에서 임의 목적지를 선택한다. 옛 광장 고정 X/Z 범위는 제거했다. 목적지는 실제 지형·충돌·A* 경로를 검사한다. 구역 중심이 분수/호수라 시작할 수 없으면 실제 테이블 주변에서 대체 시작점을 찾는다. 테이블 전체를 감싼 사각형이므로 좁은 의미의 중앙광장 폴리곤만으로 제한한 구현은 아니다.
`WORLD_AI_COMPANION_SPEECH`가 HTTP 판 상태보다 먼저 도착하면 동일 경기의 미래 버전 해설을 최대 16건·5초 동안 보류하고 판 버전이 일치할 때 표시한다. 경기 변경·건너뛴 버전·만료된 대사는 폐기하며 다른 경기로 전달하지 않는다.
