# 붕어빵 v5 FE 활성화

- 기준: dev `0d20b3b`. BE 코드·DB·서버 설정은 변경하지 않는다.
- BE v5 규칙·공통 fixture·시작/복구·선택 납품/정산·OpenAPI 기존 테스트 55건 통과.
  실제 DEV DB의 V128 적용과 서버 플래그는 이 로컬 테스트가 확인하는 범위가 아니다.
- DEV 기존 화면에서 v5 어댑터의 연결 오류를 재현했다. 공원 REST 허용 경로가
  `?rulesVersion=v4`만 받아 v5 로비 요청을 전송 전에 차단했다.
  v4/v5만 허용하도록 수정했으며 기존 인증·재시도·요청 경계는 유지한다.
- `frontend/.env.local`에 `VITE_BUNGEOPPANG_RULES_VERSION=v5`를 적용했다.
  로컬 환경 파일은 Git에 올리지 않는다. 공개 설정 예시는 `frontend/.env.example`에 둔다.
- DEV 배포는 별도 Vercel 프로젝트 `ontop-frontend-dev`의 빌드 환경에 같은 값을 사용한다.
  기존 DEV 화면은 이미 v5 어댑터를 선택하고 있었다. 운영 프로젝트 설정은 변경하지 않는다.
- 환경변수 변경 후 FE를 다시 빌드해야 한다. BE는 V128과
  `ontop.minigames.bungeoppang-v5-enabled=true`가 필요하다.
- 롤백: 대상 FE 빌드 환경의 값을 `v4`로 바꿔 다시 빌드·배포한다.
  서버 오류 때 자동으로 미리보기/가짜 보상으로 전환하지 않는다.
- 검증: FE 단위 테스트 936건, 테스트 포함 타입 검사, v5 빌드, 마이그레이션 경계 검사 통과.
  일반 Vite 모드의 브라우저에서 실제 v5 어댑터 → 인증 런타임 → 로비/시작/시간 조회/복구
  HTTP 경로를 거쳐 180초·쟁반 10개·활성 주문 3건 게임 진입을 확인했다.
  이 브라우저 검증의 HTTP 응답은 계약 fixture이며, 실제 DEV 서버 플레이 검증과 구분한다.
