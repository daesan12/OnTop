## 규칙

[Chess.com 한국어 규칙](https://www.chess.com/ko/tiesuwosuru)과
[FIDE Laws of Chess 2023](https://handbook.fide.com/chapter/E012023)를 확인했다.
사용자가 제공한 대한체스연맹 대국방법 URL은 조회 시 502 오류였다.

- 8×8, 표준 32기물 배치. 서버 참가자 목록의 첫 번째가 백이며 백 선공이다.
- 일반 이동, 잡기, 자신의 킹 노출 금지, 체크·체크메이트·스테일메이트를 서버가 판정한다. 킹을 잡는 수는 없다.
- 양쪽 캐슬링: 이동 이력·경로·현재 체크·통과/목적지 공격을 검사한다.
- 앙파상: 직전 두 칸 전진의 다음 수에만 허용하며 잡힌 폰 제거 후 킹 안전성을 검사한다.
- 승격: 퀸·룩·비숍·나이트를 명시적으로 선택한다. 선택 전에는 수가 확정되지 않는다.
- 같은 포지션 3회/50수는 현재 포지션 또는 합법적인 예정 수로 청구할 수 있다.
  반복 포지션에는 차례·캐슬링 권리·실제로 가능한 앙파상 권리가 포함된다.
- 5회 반복/75수는 자동 종료한다. 75번째 수의 체크메이트가 우선한다.
- 왕 대 왕, 왕과 단일 마이너 기물 대 왕, 동일 색 칸의 비숍만 남은 기본적인 기물 부족은 자동 무승부다.
  모든 이론적인 폐쇄/교착 포지션의 도달 가능성을 완전 탐색하는 판정기는 아니다.
- 온라인 규칙 선택: 각자 총 10분, 증분 없음. 제안/응답/재접속으로 시간을 멈추거나 초기화하지 않는다.
  시간 만료 시 상대의 메이트 가능 기물 여부를 검사한다. 터치무브·심판 페널티는 구현 범위가 아니다.
- 합의 무승부 제안은 각자 한 번. 상대의 이동은 제안 거절이며 수락은 상대만 가능하다.
- 기권·로그아웃·탈퇴·재접속 유예 만료는 공통 이탈/종료 계약을 사용한다.
- 기물 가치는 전략 참고일 뿐 실제 코인 정산에 사용하지 않는다.

## FE/BE 연결

기존 `GAME_ACTION_SEND`: `gameId`, `actionId`, `expectedVersion`, `input`.

```json
{"kind":"move","from":"e2","to":"e4"}
{"kind":"move","from":"a7","to":"a8","promotion":"n"}
{"kind":"drawOffer"}
{"kind":"drawRespond","accept":true}
{"kind":"claimDraw"}
{"kind":"claimDraw","from":"g1","to":"f3"}
```

중복 `actionId`의 동일 내용은 기존 결과, 상충 내용은 충돌, 낡은 버전·타인·차례 위반은 거절한다.
공개 상태는 a1부터 h8 순서의 64문자 board, FEN, 양쪽 ID/시계, 현재 차례/기한,
서버 합법 수, UCI 이동 기록, 체크·무승부·종료 상태다. privateState는 항상 빈 객체다.
합법 수는 표시용으로 서버에서 받고 FE가 별도 규칙/승패를 계산하지 않는다.
기록은 좌표 기보(UCI)를 `e2–e4`처럼 표시하며 SAN 기보 변환은 하지 않는다.

관전자 채팅과 핑은 기존 범위·권한·속도 제한·중복 이벤트·낡은 버전 검사를 사용한다.
핑은 기존 `OMOK_SPECTATOR_PING_SEND/OMOK_SPECTATOR_PING`의 좌표 이벤트를 재사용하되,
CHESS에서는 x/y 0~7만 허용한다. 좌표는 a1=(0,0)이다. 경기 참가자는 핑을 보내지 못한다.
서버 프로세스 내 재접속 복구를 지원한다. 진행 중 보드의 서버 재시작 복원을 보장하지 않는다.

## 시각 사양

첨부 보드 이미지는 사용자 제공 참고 이미지이며 `assets/thumbnail.png`에 보관했다.
`concept.png`는 내장 ImageGen으로 생성한 초기 전체 화면 시안이다. `assets/pieces.png`는 시계/승격 선택의 작은 아이콘으로만 사용한다.
대국판은 `ParkChessBoard.tsx`가 기존 테이블의 공원 Canvas에 연결하며, `ChessBoard3D.tsx`/`ChessPiece3D.tsx`의 실제 입체 메시로 표시한다.
오목·알까기처럼 테이블의 목재 집중 화면을 사용하고 좌측 두 시계, 우측 공통 `GameHudMenu`, 공통 `ParkChat`만 가장자리에 배치한다. 큰 한지 전체 화면 패널은 사용하지 않는다.
기물은 회전체 몸통, 두께와 베벨을 가진 나이트/비숍, 룩의 성벽, 퀸의 왕관, 킹의 십자가로 구성한다.
밝은 상아색/짙은 목재 재질, 조명과 실시간 그림자를 사용하며 외부 모델/추가 의존성은 없다.
좌우 회전, 위에서 보기, 기본 시점, 백/흑 화면 뒤집기를 지원하고 회전 시 모든 모서리가 보이도록 카메라를 맞춘다.
3D 기물/칸의 레이캐스트 선택은 기존 서버 합법 수/승격/관전 핑 계약을 그대로 호출한다.
키보드 사용자는 게임 메뉴의 ‘키보드로 칸 선택’ 팝업에서 좌표/기물 이름을 확인하고 Tab/Enter로 조작할 수 있다.
공통 `PaperPopup`으로 승격/기권/키보드 입력의 포커스·Escape·스크롤을 처리하며, 기권은 공통 `OmokSurrender` 흐름을 재사용한다.
후속 사용자 승인에 따라 체스 선택/대국 중 기존 테이블 위의 외관 및 게임 카메라/HUD만 연결한다. 지형·시설 배치·충돌·이동 경로·생성 맵 데이터/버전·서버·인프라는 변경하지 않는다. V188도 유지한다.
시안의 비표준 예시 수와 초기 배치 모순은 따르지 않고 서버의 올바른 표준 배치를 표시한다.
기존 한지 원본 `/art/tablet/hanji.webp`, 먹색 글자, 이중 테두리와 녹색 버튼을 재사용한다.
시계·기록·메뉴·승격은 HTML/CSS, 보드 좌표·핑·선택은 3D 장면으로 표시한다. 시안 이미지를 게임 화면으로 쓰지 않는다.
추가 시계/확인/채팅/복구/청구 버튼은 실제 2인 게임 흐름을 위한 의도적인 시안 확장이다.

생산 에셋 프롬프트 요약: 엄격한 6열×2행 투명 배경, 위 ivory/아래 espresso 목재,
