## 공개하지 않는 후속 항목

**개발용 공포 프리뷰의 비밀 출구 경사 1건**은 후속 작업으로 남긴다.
이 구간은 기본 서비스 `RenewalWorld`에 HorrorZone/CameraController 진입점이 없으므로 공개하지 않는다.
별도 회귀가 서비스 장면에 해당 진입점이 추가되지 않았는지 검사한다.
문제의 높이 변화를 검사하는 원래 단언은 `it.fails`로 실행해 알려진 실패를 추적한다.
이는 출구를 고쳤다는 의미가 아니며, 추후 고치면 expected-fail 표기도 제거해야 한다.
미완성 공포맵 내부 이관은 이번 MR의 완료 항목으로 쓰지 않는다.

길·숲·울타리의 추가 미관 개선은 후속 작업으로 남겨도 되지만, 시설 좌표/입구/충돌/보상 계약을
바꾸면 관련 FE·BE·맵 파일을 다시 생성하고 연결 검수를 수행한다.

## MR과 인프라 전달

- 대상은 dev이며 FE·BE·V167·배포 설정을 하나의 MR로 검토한다. 작업 브랜치 커밋은 기능별로 나눈다.
- Jenkins 기본 `renewal-candidate`는 검수/보관만 한다. MR/머지 사실만으로 dev를 새 공원으로 전환하지 않는다.
- 실제 전환은 [공동 릴리스 절차](park-renewal-release.md)에 따라 V167 이력/예약·백업·정산·입장 제한을 확인한 뒤
  같은 커밋의 BE → FE 순서로 별도 승인한다. 원격 Jenkins/Vercel 실행 결과를 로컬 검사로 대신하지 않는다.
- 기존 게임 플래그, 뽑기/복권의 실제 상품·회원 데이터, 협동 journal, OAuth·DB 비밀값을 보존한다.
- 실제 OAuth·VR 헤드셋·40명 동접·Jenkins/Vercel 권한/서비스 검수는 별도다.
- 인수 시 `localhost:8081` Jenkins 관리 주소는 연결 거부 상태였다.
  실제 후보 job 실행 결과는 확인하지 못했으며 로컬 검수를 Jenkins 성공으로 표시하지 않는다.
- [인프라 담당자 전달용 요청문](park-renewal-infra-request.md)을 함께 제공한다.
