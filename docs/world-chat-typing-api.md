# 닉네임 표시 · 채팅 입력 중 상태

2026-11-04 사용자 확정: 일반 공원 시점에서 앞 16명 제한 없이 본인과 50m 이내 사용자의 닉네임을 표시한다. 화면 밖·집중 게임 시점·숨긴 아바타의 기존 표시 조건과 망원경 전용 220m 설정은 유지한다. 채팅 본문 수신 반경 20m와 별개다.

채팅 기록의 작성자 표시명은 메시지 수신 시점의 공개 프로필(GM 표시 포함)을 FE 기록에 보관한다. 퇴장으로 현재 프로필이 제거되거나 닉네임을 바꾸고 재입장해도 과거 메시지 이름은 바뀌지 않는다. 공원 채팅과 경기 채팅·추천 표시에서 동일하게 적용하며, 서버 요청/응답 필드·DB 저장 정책은 변경하지 않는다. 프로필 조회가 늦으면 대체 이름을 표시하다가 닉네임을 처음 확인할 때 한 번 채우며, 확인된 이름은 다시 쓰지 않는다.

## 요청

기존 인증 Raw WebSocket `/ws/tables`와 현재 입장 채널을 사용한다. 새 REST API·DB 저장은 없다.

```json
{
  "requestId": "typing-1",
  "type": "WORLD_CHAT_TYPING_SET",
  "payload": {
    "typing": true
  }
}
```

`typing`은 boolean 필수이며 다른 필드는 거절한다. 본문·초안·닉네임·사용자 ID를 보내지 않는다. 사용자와 채널은 서버 연결에서 정한다. 채널 미입장은 `NOT_IN_CHANNEL`, 잘못된 필드는 `INVALID_PAYLOAD`다. 기존 인증·맵 확인·유입 제한을 적용한다.

## 응답 · 같은 채널 방송

```json
{
  "requestId": "typing-1",
  "type": "WORLD_CHAT_TYPING_STATE",
  "payload": {
    "channelId": "channel-1",
    "version": 1,
    "users": [
      {
        "userId": "101",
        "expiresInMs": 5000
      }
    ]
  }
}
```

요청자는 요청 ID로 응답을 받고 나머지는 `requestId: null`로 받는다. `users`는 해당 채널의 활성 입력자 전체 목록이며 빈 배열은 전원 해제다. 다른 채널에는 보내지 않는다. 신규 입장자는 현재 목록과 각 입력자의 원래 남은 수명만 받는다.

서버는 활성 갱신을 사용자별 초당 1회 이하로 방송하고, 상태가 달라지는 시작·중지는 즉시 반영한다. 상태 전환에도 기존 연결별 유입 제한은 계속 적용한다. 같은 채널의 `version`이 이전 이하이면 FE는 무시한다. 수명 만료 자체는 추가 방송 없이 FE가 단조 시계 기준으로 해제한다. 다른 입력자 상태 방송을 받을 때도 원래 남은 수명을 사용한다.

## FE 동작 · 종료

공원·오목·알까기와 다른 경기 채팅은 공통 `ParkChat` 패널을 사용한다. Enter로 입력창을 열고 다시 Enter로 전송한다. 정상 승인 후 입력창을 닫고 게임 캔버스로 포커스를 돌린다. Esc는 초안을 보존하고 닫으며, 한글 조합 중 Enter는 전송하지 않는다. 전송 실패·예외는 초안을 유지하고 재시도할 수 있게 한다. 대화 기록은 접기 버튼/Z로 열며 전송 후 미리보기는 내용 높이에 맞게 표시한다. 경기 메시지는 기존 승인된 경기 채널만 사용하고 공원 채팅으로 우회하지 않는다.

관전 종료가 승인되면 서 있는 사용자의 테이블 선택·조회도 정리하여 G 감정표현 단축키를 다시 사용할 수 있다. 벤치/테이블 착석 중 기존 사용 제한은 유지한다. 종료 응답을 기다리는 동안 다른 테이블·경기를 열었다면 이전 완료로 새 화면을 닫지 않는다. 게임 중 G로 감정표현을 허용하는 정책 변경은 아니다.

G는 버튼 실행 키가 아니므로 닫힌 HUD 버튼에 키보드 포커스가 남았다는 이유만으로 막지 않는다. 따라가기 상태 버튼·계정 메뉴 복귀 버튼도 동일하다. 실제 텍스트 입력·열린 메뉴/listbox·대화상자는 계속 G를 차단하고, 연결·활동·쿨다운 제한을 우회하지 않는다. 따라가기 이동 중에는 기존 새 감정표현 시작 제한을 적용하며 종료 후 멈춘 상태에서 사용한다.

- 공원 채팅과 경기 채팅에서 공백 외 문자가 입력되면 시작한다. 표시만 `입력 중…`이며 실제 초안은 전송·저장하지 않는다.
- 입력 중 2초마다 갱신한다. 마지막 키 입력 후 3초, 전송·내용 삭제·blur·닫기·컴포넌트 해제 시 중지를 보낸다.
- 중지 패킷 누락 시 마지막 갱신 후 최대 5초 만료한다. 단절·채널 퇴장 시 서버도 즉시 제거한다.
- 닉네임과 같은 머리 위 레이어에 표시하므로 일반 시점에서는 50m 안에서만 보인다. 채팅 내용 권한·근거리 수신·경기 관전 권한은 바뀌지 않는다.
- 전송 실패는 채팅 본문 입력을 막거나 오류 토스트를 만들지 않는다.

## 검증 범위

`WorldTypingTests`, `WorldTypingWebSocketTests`는 만료·중지/재시작·연결 종료·신규 입장·다른 채널 차단·필드 위조 거절을 검증한다. FE `chatTyping.test.ts`는 전송 간격·중지·버전 역전 거절, `world-typing.spec.ts`는 실제 공원 렌더러와 HTTP/WS 계약 대역으로 20명·49/51m·머리 위 표시·본문 비전송을 검증한다. 개발 서버 배포·실회원 공동 검수와 구분한다.
