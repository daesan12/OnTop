# 주사위·원카드·거짓말 다리 테스트 화면

Java21에서 backend 폴더의 `.\gradlew.bat gamesDemo`를 실행한 뒤 [테스트 화면](http://127.0.0.1:18082/dev/games)을 연다. 기존 오목18081과 별개인 loopback18082 서버다. 화면·가짜 인증/참가 확정은 테스트 클래스패스에만 있고 운영 JAR에는 없다.

1. 게임을 고르고 **테스트 경기 생성**을 누른다. A·B·관전자 소켓이 자동으로 연결된다. 같은 역할을 여러 탭에서 열지 않는다.
2. 주사위는 현재 차례의 **굴리기** → 득점 주사위 체크 → **굴리기 또는 Bank**다. 틀린 선택은 실제 서버가 거절한다.
3. 원카드는 본인 손패에서 활성화된 카드를 제출한다. 공격 받기·무늬 선택·원카드 선언/상대 신고도 실제 입력이다. 상대 화면에는 손패 장수만 나오고, 개인 상태는 각 참가자 패널에서만 볼 수 있다.
4. 다리는 본인 **비밀 굴림 → 숫자 선언**, 상대 **믿기/다우트** 순서다. 본인만 눈을 보고 모두 믿으면 관전자에게 끝까지 숨긴다. 다우트 때만 공개한다.
5. 참가자 **끊기 → 다시 연결**로 같은 손패/눈·기존 마감 복구를 확인한다. 30초 턴/단계는 계속 흐른다. 이 버튼은 정상 소켓 종료이고 heartbeat 무응답 검사는 별도 flowTest다.
6. 새 게임으로 바꾸려면 **현재 경기 모두 기권 요청** 후 종료를 기다린다. 다리의 미처리 선언은 판정 또는30초 마감 뒤 기권을 반영하므로 즉시 종료되지 않을 수 있다.

관전자 공개 JSON·각 참가자 개인 JSON·통신 기록에서 실제 서버 메시지를 확인한다. 기본 두 명 테스트이며 3~4인 규칙은 서버 자동화 검사로 구분한다. 원카드 기권 손패는 2026-10-22 사용자 확정에 따라 정식 엔진과 동일하게 **이번 경기에서 제외(REMOVE)**하며 뽑기 덱으로 돌려 넣지 않는다.

정식 로그인·시작 차감·DB정산·지급·3D 프론트 연동은 검증하지 않는다. 이 도구의 `/dev/games/*` 경로와 `testRole`은 정식 API/인증 방식으로 사용하지 않는다. 결정할 내용은 [팀 협의 목록](team-decisions.md)에 모은다.

도구의 복구 알림 순서 검사는 저장소 루트에서 `node --test backend/src/test/js/games-demo.test.cjs`로 실행한다. 실제 games.js 수신 로직에 DOM/소켓 대역을 제공하며, 실제 브라우저나 서버 실행을 대체하지 않는다.
