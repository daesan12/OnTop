# 가위바위보 룰렛 UI 명세

- 작업 / 브랜치: Jira `S15P31B105-306` / `feat/S15P31B105-306-rps-roulette`
- 진입 방식: 시설 미니게임. 붕어빵 가게 오른쪽 앞의 화면용 게임기 앞에서 E 또는 클릭 → 2D 게임기 창
- 서버 계약: [rps-roulette-api.md](rps-roulette-api.md)
- 참고한 기존 화면: 뽑기방 `LuckyFacilityPanel`(native dialog·포커스), 꼬치왕 이용권(요청 키 복구), 붕어빵(시간 보정·결과 연출)

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 판 (`RouletteFace`) | 파란 판, 노란 별빛 테두리, 분홍·초록 30칸 링, 가운데 점선 LED 손, 모서리 리본(비겼다·이겼다·졌다·대박), 손 아이콘 원 3개 |
| LED 띠 | 배수(×1.0/1.5/2.0/꽝)와 단계 점, 남은 판, 10칸 시간 막대와 초, 안내 문구, 지급액 |
| 조작판 | 손 버튼 3개(크롬 테두리·검은 베젤·흰 돔, 1·2·3), 참가비 3칸 스위치, START, 도전(1차 ×1.5 / 2차 ×2.0), 멈춤(받을 금액 범위) |

## 상태와 조작

| 상태 | 표시 | 켜지는 버튼 |
| --- | --- | --- |
| 대기 / 지난 판 결과 | 엽전 LED, 지난 판 결과 문구 | 참가비, START |
| 엽전 넣는 중 | `엽전을 넣고 있어요…` | 없음 |
| 대결 | LED 손이 0.09초마다 바뀜, 5초 막대 | 손 버튼 |
| 손 내는 중 | `손을 내고 있어요…` | 없음 |
| 공개 | 기계 손·결과 리본 1.1초 | 없음 |
| 선택 | 이긴 손, 10초 막대, 받을 금액 범위 | 도전(2차 전까지), 멈춤 |
| 시간 끝 | `시간이 끝났어요. 서버 판정을 확인하고 있어요.` → 서버 유예 뒤 상태 재조회 | 없음 |
| 룰렛 | 불빛이 최소 두 바퀴 돌고 서버가 정한 칸에서 멈춤(약 3.5초) | 없음 |
| 정산 | `참가비 × 칸 × 배수 = 지급액`, `RewardCoinSource` 엽전 연출 | 참가비, START |

- 결과·지급액·남은 판은 모두 서버 응답만 쓴다. 타이머는 응답의 `serverNow`를 단조 시계에 고정해 계산하고 0초에 결과를 정하지 않는다.
- 공개·룰렛 연출은 판별로 한 번만 한다. 창을 다시 열면 이미 있던 판은 결과만 보여준다. 움직임 줄이기 설정에서는 연출을 건너뛴다.
- 연출 갱신은 매 프레임이 아니라 손 섞기(90ms)·룰렛 한 칸(28ms) 간격 타이머로만 한다.
- 닫기는 창 닫기다. 공개된 판은 서버가 마감에 맞춰 끝까지 처리한다.

## 키보드·접근성

- `1`/`2`/`3` 손, `Enter` START(창에 포커스가 있을 때), `Esc` 닫기. 한글 조합 중·키 반복은 무시한다.
- 실제 `<button type="button">`, 참가비는 `aria-pressed`, 안내 문구는 `role="status"`. 손 버튼은 `바위 내기` 등 이름을 가진다.
- 열 때 `clearRoamingInput()`과 `inputState.minigameOpen`으로 공원 이동·단축키를 막고, 닫을 때 해당 플래그만 푼다.

## 컨벤션과 다른 부분

- **강한 원색·깜빡이는 테두리(2.4):** 게임기 자체의 정체성이라 `.rps-roulette` 창과 설명서 그림 안에서만 쓴다. 지금 누를 수 있는 버튼에만 깜빡임을 주고, 움직임 줄이기 설정에서는 끈다.

## 범위 밖과 검수

- 공원 맵 미변경: 게임기는 충돌이 없고 시설 점유·주변 관전 방송은 위치 확정 후 후속 작업이다. 위치는 `features/rpsRoulette/access.ts`의 값만 옮긴다.
- DEV 화면 확인은 `VITE_RPS_ROULETTE_PREVIEW=true`의 대역 서비스로 할 수 있으며 실제 엽전과 연결되지 않는다.
- 효과음은 기존 `coin-gain`(지급)만 연결했다. 전용 효과음은 별도 작업이다.
