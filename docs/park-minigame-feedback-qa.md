## 독립 실행과 실제 서버 구분

frontend에서 다음 서버를 실행한다.

```text
node node_modules/vite/bin/vite.js --mode park-integration --host 127.0.0.1 --port 5283 --strictPort
```

- `/jumpmap-preview.html`: 실제 점프맵 HUD·결과·낙하 안내를 모의 이벤트로 독립 확인한다. 운영 지갑·랭킹에는 연결하지 않는다.
- 붕어빵: 기존 `dev:bungeoppang:v5` 모드는 지급 서비스를 모의 상태로 바꾸며 실제 엽전을 지급하지 않는다. 이번 진입 화면 검사는 `/park` contract fixture에서 실제 컴포넌트를 확인한다. 꼬치왕은 `/skewer.html`에서 공원을 거치지 않고 실행한다.
- `/park`: 최신 생성 맵에 통합된 진입·게임 선택·준비·진행·결과·공원 복귀·관전·채팅·입력 회귀를 브라우저 fixture로 확인한다. fixture를 실제 운영 HTTP/WS 연결 성공으로 보지 않는다.
- BE의 실제 규칙·시작 예약 계약·중복 actionId·expectedVersion·권한·기권·이탈·재접속·관전·정산은 Java 테스트로 확인한다. 지급 경쟁·원장·롤백·KST 자정·랭킹 SQL은 격리 MySQL 8.4에서 실제 서비스와 DB를 사용한다. 운영 DB와 배포 환경에는 접속하지 않았다. 진행 경기의 서버 재시작 복원은 추가 보장하지 않는다.

앞선 겹침 보완만으로는 게임마다 시간·메뉴·채팅의 인상이 달랐다. 사용자 요청에 따라 PC에서 한지 시간 카드, 녹색 옻칠 패널, 놋쇠 테두리, 기존 부산단디명조 글꼴을 공통 기준으로 사용한다. 판·말·카드·주사위의 기존 재질과 조작은 각 게임에 유지한다.

브라우저는 합성 경기 상태에 실제 게임 HUD·3D 판/카드/주사위/종을 연결해 PC 기본 및 1920×1080에서 확인했다. 로컬 검수 카메라·조립 화면이며 로그인된 실제 서버 경기 인수는 아니다. 후반 캡처 도구 연결이 타임아웃되어 추가 재검수는 중단했으며, 확인한 화면/DOM 측정과 미확인 범위를 개인 근거 기록에 구분한다. 검수 도구는 계속 Git 제외, API 계약·DB 스키마·인증·정산·실제 서버 배포 변경은 없다.

### 차례 전환 안내·관전자 관점 후속

- 기존 알까기만 사용하던 큰 차례 안내를 다른 여섯 게임에도 연결했다. 참가자에게는 내 차례/상대 차례, 관전자에게는 공개된 참가자 닉네임과 차례를 1.5초 표시한다. 다리는 선언자와 실제 판단자를 구분하며, 과일 땡은 카드 공개 차례 안내이고 종 권한을 제한하지 않는다.
- 시계 틱/게임 버전/굴림 갱신은 새 차례로 취급하지 않는다. 추첨·원카드 배분·다리 판정·종 결과 정지·끝난 경기·만료한 차례는 일반 안내를 억제한다. 원카드의 무늬 선택도 같은 차례 알림을 반복하지 않는다. 알까기는 기존 비책 획득 연출 대기 순서를 유지하고 공통 시각 스타일을 사용한다.
- 중복 방지는 마지막 차례 키 하나를 브라우저 모듈 수명에 보관해 재접속의 resetGame/재마운트에도 유지한다. 차례 관찰 컴포넌트는 시계 포털 밖에 유지하고 표시 DOM만 포털에 배치한다. UI 알림은 입력을 차단하거나 서버 타이머/권한을 변경하지 않는다.
- 오목 관전 시계에 차례 참가자 이름을 표시하고 원카드 관전 시계에서 참가자용 행동 지시를 제거했다. 다리 시계는 내 판단 차례를 구분하고, 장부/과일 땡의 내 차례 강조는 참가자 역할에 한정한다.
- 실제 GamePanel 7종을 공개 관전 상태로 정적 렌더링해 차례·게임 메뉴·관전 종료 및 기권/무르기/개인 비책/본인 손패 조작 미노출을 검사했다. 이는 브라우저 배치·두 계정 실제 플레이 인수와 구분한다. CUA 브라우저 연결 시간 초과로 이번 새 화면 캡처·픽셀 겹침 검수는 미완료다.
- FE 전체 2,199 통과/기존 조건부6제외, 최종 포털 보완 뒤 관련29개·제품 tsc 통과. 독립 읽기전용 최종 리뷰 새 구체 결함 없음. 최초 전체 검사 sandbox 임시파일 rename EPERM은 정상 권한 동일 전체 검사로 재실행했다. API/DB/정산/스키마·배포 변경 없음.
