# 백엔드 진행 상황

2026-10-20 · DB 없는 local 구현과 정식 연동을 구분한다.

**채널 선택 → 광장 입장 → 착석 → 게임 선택 → 준비 → 게임 시작 → 게임 진행 → 결과·정산**

| 단계 | 현재 상태 | 남은 것 |
| --- | --- | --- |
| 채널 목록·입장·퇴장 | local 구현 | 실제 로그인 연결 |
| 채널별 테이블 목록·착석 | local 구현 | 최종 맵의 테이블 배치 |
| 첫 착석자 게임 선택·준비 | local 구현 | 프론트 실제 화면 연동 |
| 게임 시작 요청·결과 확인 | 연결부·검증 대역 구현 | 팀원 경기 생성·재화 차감 연결 |
| 경기 끊김·30초 내 복귀 | 연결부·검증 대역 구현 | 실제 로그인·경기 엔진 연결 |
| 광장 이동·채팅 | 미구현 | 메시지 계약·서버 처리 |
| 실제 게임 진행 | 팀원 코드 미연결 | 경기별 입력·상태 연결 |
| 종료·결과·정산 | 팀원 코드 미연결 | 결과 통보·좌석 반환·정산 연결 |

현재는 **광장에 들어와 같은 채널 사람끼리 착석하고 준비하는 구간**이다. 실제 게임 한 판을 끝내는 상태는 아니다. 기본 모드는 준비 표시까지이며 시작 검증 옵션을 켜면 게임 담당 대역에 요청한다.
