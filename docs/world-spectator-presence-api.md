# 경기 관전 수·공개 활동

담당 장대산 · S15P31B105-69. 로컬 구현·검증이며 배포·실제 두 계정 검수는 별도다.

기존 `WORLD_STATE` 전체 상태에 다음 선택 필드를 추가한다. 새 클라이언트 송신 요청은 없다.

```json
{
  "gameWatches": {
    "505": { "gameId": "game-1", "tableId": "table-1" }
  }
}
```

- 같은 채널의 현재 아바타 ID를 키로 한다. 첫 `GAME_STATE` 전송을 마친 승인된 실제 경기 관전자만 포함한다.
- 참가자·관전 요청 대기·단순 `TABLE_WATCH`는 제외한다. 같은 회원은 한 번만 포함한다.
- 같은 경기 ID의 항목 수가 관전자 수다. 별도 정산·회원 조회를 실행하지 않는다.
- 해당 아바타의 공개 `activity`는 `WATCHING`(`관전 중`)이다. 기존 GAME/BUNGEOPPANG이 우선한다.
- 관전 종료·채널 이탈·단절·20m 범위 이탈·착석·경기 종료로 자격을 잃으면 명부와 표시를 함께 해제한다.
- **경기 종료 즉시 0명/표시 해제**가 사용자 확정 정책이다. 결과 화면 수명으로 관전 수를 연장하지 않는다.
- 게임 화면은 눈 아이콘과 `N명 관전 중`의 작은 배지를 사용한다. 숫자는 같은 경기의 승인 명부에서만 계산하며 숫자가 바뀔 때만 짧게 전환한다. 진행 중인 경기가 아니면 배지를 숨긴다. 표시 변경에 새 메시지나 별도 집계 API는 필요하지 않다.
- 알까기는 오른쪽 행동 버튼과 겹치지 않도록 배지를 왼쪽 위에 둔다. 좁은 화면에서는 상단 경기 정보 아래로 내려 표시한다.
- 종료 결과·정산·개인 손패를 삭제하지 않는다. 관전 명부는 화면용 공개 정보이며 권한 판정 원본은 기존 서버 구독이다.
- 명부가 달라지면 해당 채널 월드 버전도 증가한다. FE는 오래된 월드 버전으로 숫자를 복원하지 않는다.
- 서버 이동 동결 판정과 공개 WATCHING 표시는 분리한다. 표시 추가 때문에 새 이동 제한을 만들지 않는다.

`AlkkagiSpectatorFlowTests`는 실제 인증 티켓·Raw WebSocket으로 승인/미승인·수동 종료·경기 기권 종료를 확인한다.
예약·정산과 초기 거리 좌표는 격리 대역이며 실제 공용 DB 검수는 아니다.
