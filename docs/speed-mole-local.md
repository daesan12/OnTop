# 스피드 두더지 로컬 시안

2026-11-05 사용자 확정 규칙을 기존 두더지와 독립된 화면/로컬 모델로 검수한다. 서비스의 게임 목록·기존 두더지·서버 API·DB는 변경하지 않는다. 개발/운영 서버 적용 완료가 아니며 지갑 지급·랭킹·영속 저장은 연결하지 않았다.

## 규칙과 입력

- 위 R/T/Y/U, 아래 F/G/H/J의 4열2행·8개 구멍이다(2026-11-05 사용자 후속 선택).
- 서로 다른 구멍에 두더지 4마리가 유지된다. 시간이 지나도 사라지지 않는다.
- 성공하면 +1점, 잡은 자리 이외의 기존 빈 구멍에 즉시 새 두더지가 나온다. 나머지 두더지는 그대로다.
- 빈 구멍은 −3점, 매 입력마다 최저 0점으로 제한한다. 입력 잠금·기절·콤보 보너스는 없다.
- 시작 버튼·Enter·Space로 3→2→1 준비 카운트다운을 거친 뒤 60초의 단조 시계 마감으로 종료한다. 준비 중에는 타격을 받지 않고 본 게임 시간을 차감하지 않는다. 결과에서도 Enter·Space로 같은 절차를 다시 시작한다. 포커스된 버튼의 기본 Enter/Space 동작은 유지한다.
- 등장 모션 약100ms는 시각 효과이며 즉시 타격할 수 있다.
- 물리 키 code로 한글 입력 상태를 지원한다. 브라우저의 `repeat`가 참인 길게 누르기만 무시하고 새 keydown은 받으므로 keyup 신호를 놓쳐도 특정 키가 잠기지 않는다. 입력창·Ctrl/Alt/Meta 조합은 제외하며 클릭도 지원한다.
- 구멍 앞 테두리는 타원 마스크로 표시하고 두더지 원본 이미지 비율을 유지한다. 머리 영역도 타격할 수 있으며 아래 줄과 윗줄 키 표시의 간격을 분리한다.
- 배경은 사용자가 제공한 전용 `speedMole/assets/cabinet.png`(1672×941)를 사용한다. 점수판과 4열2행 구멍은 이 배경의 화면 비율에 맞춰 배치하고 키 표시는 구멍 앞 테두리에 둔다. 기존 두더지 배경은 교체하지 않는다.
- 종료 확인 중에도 시간은 흐른다. 창을 최소화해도 다음 프레임/입력에 실제 경과 시간을 반영한다. 결과에서 재도전·게임 선택 화면으로 돌아갈 수 있다.

## 파일과 검증

`frontend/src/features/speedMole/game.ts`가 독립 규칙·반복 키 상태를, `SpeedMolePanel.tsx`가 타이머/입력/종료 화면을 담당한다. 기존 mole의 두더지·구멍·망치 이미지와 숫자 표시만 읽어 재사용하며 배경은 전용 파일이다. 테스트는 `frontend/tests/unit/speedMole.test.ts`다.

로컬 실행 진입점은 Git 제외된 `.vite-cache` 아래에 둔다. 테스트 도구·가상 계정·결과를 제품 코드나 실제 서버 성공으로 취급하지 않는다. 서비스 게임칸 편입·서버 권위 결과 검증·보상·랭킹은 이후 별도 합의 범위다.
