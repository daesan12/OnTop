# 응모권 판매 기간 재정의

기본 판매 기간은 KST 월요일 09:00부터 다음 월요일 00:00 직전까지다. 행사 일정으로 기존 회차를 연장해야 할 때만 아래 환경변수 세 개를 한 세트로 설정한다.

```dotenv
RAFFLE_SALES_OVERRIDE_WEEK_START=2026-11-09
RAFFLE_SALES_OVERRIDE_STARTS_AT=2026-11-09T09:00:00+09:00
RAFFLE_SALES_OVERRIDE_ENDS_AT=2026-11-19T00:00:00+09:00
```

종료 시각은 exclusive이므로 위 값은 11월 18일 23:59:59.999까지 판매한다. 연장 종료 뒤에는 같은 주의 새 회차를 만들지 않고, 다음 월요일부터 기본 주간 규칙으로 복귀한다.

세 값 중 일부만 설정하면 애플리케이션 시작을 거절한다. 이미 추첨 준비용 `event_rounds` 행이 생긴 회차도 기간 변경을 거절한다. 운영에서는 다음 순서를 지킨다.

1. 대상 회차가 미확정이고 추첨 준비 전인지 확인한다.
2. 세 환경변수를 추가하고 백엔드 컨테이너를 재생성한다.
3. 현재 응모권 API가 기존 `roundId`와 기존 구매 내역을 유지하며 새 종료 시각을 반환하는지 확인한다.
4. 종료 후에는 추첨 전 백업과 후보 수를 확인한다.
5. 다음 행사 전에 재정의 환경변수를 제거한다.

이 설정은 기존 `raffle_rounds`의 기간과 상태만 동기화하며 Flyway 마이그레이션을 추가하지 않는다.
