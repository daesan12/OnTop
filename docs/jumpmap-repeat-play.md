# 돌탑 점프맵 반복 도전 UI

2026-10-31 사용자 정정 반영. 마지막 연잎 완료는 1초 알림에서 붕어빵 스타일의 지속 완료 화면으로 재정정했다. 이전 준비·카운트다운·타임어택 시안보다 이 문서를 우선한다.

## 현재 흐름

첫 발판 착지 → 서버 자동 시작 → 구간 진행 → 마지막 발판 종이 완료 화면 → 호수 완주/기존 보상. 떨어지면 결과창 없이 직접 돌아와 첫 발판에서 바로 다시 도전한다.

- E 상호작용·준비 화면·시작 버튼·3·2·1·시작!을 사용하지 않는다.
- 타임어택·경과 시간·개인 최고·시간 랭킹 UI와 추가 API 연결은 보류한다. 서버의 기존 기록 데이터나 테이블을 삭제하지 않는다.
- 낙하·조기 호수 진입·일반 종료·재접속 뒤에는 결과 모달을 띄우지 않는다. 마지막 연잎의 완료 화면이 열린 동안만 기존 PaperPopup의 포커스·입력 소유권을 사용하고, 닫으면 이동을 다시 허용한다.
- 첫 방문의 출발 안내는 기존 seenTips에 따라 1회, 1.2초만 작은 한 줄로 표시한다. F1 설명서는 원하는 때 직접 연다.
- 큰 좌우 카드·하단 7테마 보상 띠를 하나의 작은 구간/진행 점/이번 엽전/오늘 수입 표시줄로 대체한다. 현재 높이·타이머·반복 구간 배너는 표시하지 않는다.
- 보상 알림은 0.9초만 작게 표시한다. 예상/정산 중/실제 지급을 구분하고 실제 잔액은 기존 서버 재조회로 반영한다.
- 서버 JUMPMAP_FINAL_PAD를 처음 받으면 붕어빵 결과와 같은 크림색 종이 팝업·일러스트·구간/엽전 카드·녹색 계속하기 버튼의 **돌탑 도전 완료** 화면을 연다. 자동으로 사라지지 않고 계속하기·X·Esc로 닫는다. 중복 이벤트·같은 발판 재착지·복구 상태로 다시 열지 않는다.
- 이 완료 표시는 마지막 발판 도착 안내다. 기존 완주·7구간 보상 확정은 마지막 연잎 이후 호수 진입의 FINISH 판정을 유지한다. 호수 진입 때 두 번째 완료/결과창을 띄우지 않는다. 완료 화면이 아직 열려 있으면 서버 확정 금액과 완주 문구만 갱신한다.

## 코드와 연결

- FE 담당 경로: `frontend/src/features/jumpmap/`. JumpmapHud는 위치를 읽고, JumpmapOverlay는 독립 프리뷰와 같은 HUD와 완료 화면을 렌더한다. 완료는 JumpmapCompletion과 기존 공통 PaperPopup을 재사용한다. state와 controller는 서버 상태·정산·기존 착지 효과를 유지한다.
- 공통 FE: 기존 설명서 catalog의 jumpManual 등록만 유지한다. 준비 화면용 inputOwnership 플래그와 랭킹 requestJSON 허용은 제거해 원래 공통 코드로 돌렸다.
- BE: 보류한 시간 랭킹 Controller/조회/DTO/테스트를 활성 코드에서 제외했다. 최신 dev의 기존 시작·낙하·호수·지갑·복구 경로를 사용한다. 최신 맵 코스 JSON/체크섬 동기화 2개 파일은 유지한다.
- DB migration 추가·변경·번호 예약 없음. 게임 코드·인원·공통 WS 계약·맵 배치·충돌체 좌표 변경 없음.
- 이전 미커밋 파일 110개와 binary patch는 작업 저장소 밖의 로컬 hand-off 백업에 보존했다. 보류한 타임어택 작업은 이번 변경에 포함하지 않는다.
