# 미니게임 공통 보상과 일일 누계

2026-11-24 사용자 피드백에 따라 **미니게임 재화의 일일 획득 상한을 제거한다**. 기존 1,000냥에 도달하거나 넘겨도 이후 경기의 보상을 정상 지급한다. 이 문서가 이전 문서의 일일 100/500/1,000냥 제한 설명보다 우선한다.

## 지급 계약

- 붕어빵(v2/v4/v5), 두더지, 스피드 두더지, 줄넘기, 점프맵, 틀린 그림 찾기, 꼬치왕 협동, 무료 게임의 순위 보상에 사용하는 공통 MinigameRewardBudget.grant는 일일 누계와 무관하게 계산 보상을 지급한다.
- 게임별 점수 환산율, 완주·검증 조건, 참가비, 한 판 지급 범위는 유지한다. 꼬치왕 협동은 기존 DB 계약의 한 판 1,000냥 제한을 유지하되 여러 판을 플레이해 하루 1,000냥을 초과할 수 있다.
- 같은 지갑 잠금과 같은 트랜잭션에서 경기/영수증/지갑/원장을 확정한다. 같은 경기의 재시도·동시 완료는 최초 지급 내역을 반환하며 중복 지급하지 않는다. 이전에 완료된 경기를 소급 재정산하지 않는다.
- todayEarned는 통계용 KST 실제 지급일 누계다. 집계 대상은 MINIGAME_REWARD, JUMP_GATE_REWARD, SKEWER_REWARD, MOLE_REWARD, GAME_RANK_REWARD의 양수 지급이다. 자정 이후의 새 지급은 새 날짜로 집계한다.

## FE/BE 계약

- dailyCap 및 붕어빵 rules의 dailyCoinCap은 정수 0으로 무제한을 표시한다. 큰 유한값을 임시 상한으로 사용하지 않는다.
- 새 붕어빵 완료 응답의 capReached는 false다. 꼬치왕 remainingToday는 무제한일 때 null이다. 일일 누계가 1,000냥을 넘어도 정상 응답이다.
- 화면은 오늘 누계와 일일 제한 없음을 표시한다. 기존 유한 상한이 들어 있는 과거 영수증은 이전 지급액 그대로 읽을 수 있다.
- FE와 BE를 같은 변경으로 반영해야 새 무제한 계약을 함께 사용한다. 기존 배포·네트워크·Jenkins 설정은 수정하지 않는다.

## 별도 정책과 저장

운동기구 FITNESS_REWARD의 하루 500냥은 미니게임 공통 보상과 다른 정책이다. 참가비 배당, 유료 뽑기, 보드게임 정산, 가입/관리자/알림 보상도 각각의 기존 정책을 유지한다. 이 작업은 재화 일일 상한 제거이며 경기 입력·시간·권한 검증을 완화하지 않는다.

기존 원장과 스키마를 사용하며 신규 Flyway는 없다. 적용된 migration을 수정하지 않는다. 과거 jump_daily_earnings도 보존한다.

## 검증

기존 상한 전후와 큰 누계에서도 전액 지급, KST 자정 집계, 재전송 멱등성, 기존 오류·롤백 관련 회귀를 유지한다. MySQL 전용 테스트의 기대값도 새 정책에 맞추며 실제 DB 실행 여부는 작업 기록에서 별도로 구분한다.
