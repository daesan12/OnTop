# 소리함 의견 접수 계약

근거: 수신 M07 소리함 BE 작업 명세(2026-10-24) 및 현재 FE
`frontend/src/features/feedback/validation.ts`. M08 공개 익명 메모와 분리한다.

## 확정된 본문 검증

`feedback/domain/FeedbackText`는 DB 저장 전 사용할 본문 값이다. 회원 인증·HTTP 접수·관리자 조회 API가
등록됐다는 뜻은 아니다. 현재 다음 규칙만 코드로 구현하고 검증했다.

1. 원문이 null이거나 UTF-16 길이 600자를 넘으면 거절한다. 정규화로 짧아져도 원문 상한을 먼저 적용한다.
2. 한글 자모 등 결합 문자를 NFC로 정규화한다.
3. FE와 같은 제어 문자 범위와 Unicode FORMAT 문자를 제거한다. 내부 LF·CR·탭은 보존한다.
4. JavaScript trim과 같은 공백 집합을 앞뒤에서 제거한다. Java String.strip과 다른 NBSP 등도 포함한다.
5. 최종 UTF-16 길이 5~600자를 검사한다. 이모지 한 개는 대체로 두 코드 단위다.

예: `가` 다섯 번은 `가가가가가`, 이모지300개는600단위다. 내부 줄바꿈·탭은 채팅과 달리 허용한다.
의견 본문을 공개 월드·채팅에 방송하거나 사용자 ID와 함께 로그에 남기지 않는다.

## 구현 전에 필요한 제품 정책

수신 명세가 미정으로 명시한 작성자 저장·보관/탈퇴·관리자 지정 방식은 아직 사용자 답변 전이다.
2026-10-25 제안은 회원 ID만 저장/닉네임 사본 없음, 90일 보관, 탈퇴 시 작성자 연결 제거,
서버 설정의 관리자 회원만 조회, FE 초기값2.6m·높이±0.7m·15초 간격이다.
이 값은 질문으로 제시한 추천안이며 승인된 설정이나 적용 완료가 아니다.

확정 후 회원 인증·서버 위치/활동 검사·JPA 접수·최신순 관리자 조회를 연결한다.
동일 사용자/요청 키/정규화 본문은 기존 영수증을, 같은 키의 다른 본문은 충돌로 반환하고
기존 접수 재조회는 새 의견 쿨다운보다 먼저 처리한다. 새 Flyway 번호는 작성 전에 공유·조율한다.
현재 새 SQL·DB 테이블·영구 저장·관리자 권한·접수 URL은 추가하지 않았다.
