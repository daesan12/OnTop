# 첫 주 미니게임 1위 확정 (S15P31B105-354)

## 회차와 기록 기간

- 이번 회차는 `2026-11-02` 월요일 09:00 KST부터 `2026-11-09` 월요일 00:00 KST **직전**까지다. 종료 시각은 포함하지 않는다.
- 대상은 붕어빵과 점프맵 각 1위, 상품은 각각 메가커피 아메리카노 1개다. 두 게임의 당첨자는 같을 수 있다.
- 마감 직전에 끝난 게임의 정산을 기다리기 위해 마감 5분 뒤부터 결과를 확정한다. 자동 실행은 1분마다 미확정 회차를 확인하며, 서버가 꺼져 있었다면 재시작 후 다시 시도한다.
- 회원에게는 `2026-11-09` 월요일 09:00 KST부터 본인의 당첨 여부를 공개한다. 이 작업은 첫 주차만 설정한다. 다음 주차 운영은 별도 상품·기간 확정 후 추가해야 한다.

## 후보와 동점

- 붕어빵은 서버가 완료·검증한 v5, 120초 판만 사용한다. 유효한 결과 JSON의 점수 내림차순, 최대 콤보 내림차순, 정산 시각 오름차순, 기록 ID 순으로 순위를 정한다. 같은 회원의 여러 판은 최고 기록 하나만 남긴다.
- 점프맵은 현재 v3 코스의 유효한 완주 기록만 사용한다. 완주 시간 오름차순, 기록 종료 시각 오름차순, 기록 ID 순이다. 같은 회원의 여러 판은 가장 빠른 기록 하나만 남긴다.
- 두 게임 모두 행사 기간 안에 서버에 저장된 완료 시각을 기준으로 한다. 삭제된 회원과 관리자 조회 ID 목록에 포함된 GM은 제외한다. GM이 1위여도 다음 유효 회원이 선정된다.
- 확정 시 `event_rounds`, `event_prize_slots`, `event_winners`, `event_finalization_attempts`에 회차·상품·당첨 회원·원본 기록 ID·기록 값·달성 시각·실행 결과를 남긴다. 동시 실행은 회차 행 잠금으로 하나의 결과에 수렴한다. 이미 확정된 회차의 재요청은 당첨자를 바꾸지 않는다.

## API와 배포

| 요청 | 권한 | 응답 |
| --- | --- | --- |
| `GET /api/v1/events/minigames/{type}/rounds/{weekStart}/result` | 로그인 회원 | 발표 전 `NOT_ANNOUNCED`, 확정 지연 시 `PENDING`, 발표 후 본인의 `SELECTED`·`NOT_SELECTED` |
| `GET /api/v1/admin/events/minigames/{type}/rounds/{weekStart}` | 관리자 조회 | 후보 수·GM 제외 수·당첨 회원과 원본 기록 |
| `POST /api/v1/admin/events/minigames/{type}/rounds/{weekStart}/finalize` | 관리자 운영 | 마감 5분 뒤 확정 또는 이미 확정된 동일 결과 |

`type`은 `bungeoppang` 또는 `jumpmap`, `weekStart`는 `2026-11-02`다. 모든 응답은 `Cache-Control: no-store`를 사용한다. 회원 API는 다른 회원의 결과를 공개하지 않는다. 연락처 수집은 후속 작업이다.

DEV·운영에서 `MINIGAME_AWARD_ENABLED=true`를 설정하고 앱을 재시작해야 서비스와 자동 실행이 켜진다. 기본값은 `false`다. `MINIGAME_AWARD_AUTO_ENABLED=false`면 자동 확정만 끄고 관리자 수동 API는 유지한다. `MINIGAME_AWARD_WEEK`의 기본값은 `2026-11-02`이며 KST 월요일 날짜여야 한다. 배포 전 관리자 조회·운영 ID와 V153 마이그레이션 적용 여부를 확인한다. 실패한 확정 시도는 이력에 기록하며 다음 자동 실행이나 관리자 API로 재시도할 수 있다.
