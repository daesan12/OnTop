# 아이템 알까기 — 남은 이미지·모델·효과음 전달 목록

2026-10-31 · 로컬 플레이 기준. 아래 에셋이 없어도 게임·아이템·관전·결과는 동작한다. 외부 파일 다운로드/구매/업로드는 하지 않았다. 장기알의 자체 제작 렌더 모델·나무결/한자 텍스처는 코드에 포함한다.

## 이미지·3D

현재 판·팔각 장기알·한자·홍/청 구분·벽·선택 링·발사/훈수 화살표·충돌 링·낙하는 Three.js 기본 Geometry와 직접 그린 텍스처로 구현했다. **필수 외부 GLB/사진은 없다.** 원작 이미지나 소리를 복사하지 않는다.

| 우선순위 | 요청할 파일 | 권장 전달 형식 | 현재 대체 표시 |
| --- | --- | --- | --- |
| 자체 제작 | 아이템 아이콘8종: 벽/재배치/힘/확대/축소/추가 발사/교환/방어 | AlkkagiItemCard의 원본 SVG 경로. 각 아이템 키와 대응하며 외부 이미지 불필요 | 한지/목재 카드와 아이콘 |
| 자체 제작 | 카드 공통 앞 프레임 | CSS 한지 톤·목재 테두리·인장·선택/비활성 표시. 뒷면은 현재 상대 손패를 표시하지 않아 미사용 | 실제 보유 카드/조회용 도감 |
| 선택 | 나무판 재질 교체 | 현재 자체 제작 목재/격자 Canvas 텍스처 사용. 외부 재질 교체는 선택 | 밝은 목재 판면·짙은 테두리·장식선/궁성 |
| 선택 | 장기알/벽 외형 고도화 | 장기알 몸체는 자체 코드 모델로 제작 완료. GLB 교체는 선택, 벽은 후속 | bevel 팔각 목재 알/직사각 벽 |

모델을 받을 경우: 바닥 중앙을 원점, Y 위쪽·XZ 판 평면으로 맞춘다. 장기알은 반지름1/높이1의 정규화 모델로 전달하면 런타임에서 현재 반지름(.24/.32/.43)·높이(.27)에 맞출 수 있다. 벽은 길이/두께/높이를 독립 조절할 수 있게 한다. 콜라이더는 서버의 원/회전 직사각형이므로 시각 모델 모서리를 실제 물리로 오해하면 안 된다. 변경 모델은 기존 충돌 반경·테이블/맵 좌표를 바꾸지 않는다.

외부 파일을 전달할 때 출처 URL·제작자·라이선스·상업 이용/수정 가능 여부를 함께 남긴다. 아직 외부 파일이 없으므로 확정된 외부 출처·라이선스는 없다. 실제 전달 전 빈/깨진 파일이나 사용하지 않는 asset URL을 코드에 넣지 않는다.

## 효과음 담당에게 전달

짧은 비루프 효과음 OGG 또는 MP3로 전달하면 된다. 아래 파일명은 전달 규칙 제안이며 현재 파일이 있다는 뜻이 아니다. 효과음은 아직 재생하지 않는다.

프론트는 실제 입력·서버 승인 상태로부터 `window`의 **`alkkagi:feedback` CustomEvent**를 발행한다. 상세 형식은 `{ id, type, at, pieceId?, strength?, winner?, endReason? }`다. id로 중복 재생을 막고, 최초 접속/재접속에서 과거 결과·낙하·충돌을 다시 재생하지 않는다. 서버 스냅샷은 화면에서100ms 버퍼로 재생하므로 효과음 실제 적용 시 렌더 타이밍과 함께 맞춘다. 개인 카드 ID·RNG 시드·상대 손패는 이벤트에 넣지 않는다.

| 이벤트 type | 재생 조건 | 제안 파일 |
| --- | --- | --- |
| PIECE_SELECTED | 유효한 알을 눌러 조준 시작. 관전자는 현재 턴 알만 | select.ogg |
| SHOT | 서버가 새 simulationId의 발사를 승인 | shot.ogg |
| PIECE_HIT | dyn4j 실제 postSolve의 양수 normal impulse. 같은 쌍100ms 제한 | hit-piece-weak/medium/strong.ogg |
| WALL_HIT | 실제 벽 접촉의 postSolve | hit-wall.ogg |
| PIECE_FALL | 서버 alive가 true→false로 변경된 새 탈락 | fall.ogg |
| CARD_ACQUIRED | 본인 PRIVATE_STATE에 새 카드 ID 추가. 최초 손패 복원은 제외 | card-gain.ogg |
| ITEM_WALL | 설치 검증·소모 확정 | wall-place.ogg |
| ITEM_RELOCATE / ITEM_SWAP | 재배치/교환 확정 | relocate.ogg / swap.ogg |
| ITEM_POWER_UP / ITEM_DEFEND | 힘 강화/방어 확정 | power-up.ogg / defend.ogg |
| ITEM_GROW / ITEM_SHRINK | 크기·질량 변경 확정 | grow.ogg / shrink.ogg |
| ITEM_EXTRA_SHOT | 추가 발사 활성화 확정. 별도 시간 연장 없음 | extra-shot.ogg |
| TURN_CHANGED | 서버 다음 turnNumber 확정 | turn-change.ogg |
| TURN_WARNING | 같은 턴의 남은 시간이5초 이하로 처음 진입 | turn-warning.ogg |
| GAME_FINISHED | 새 종료 확정. winner(0홍/1청/null무승부)와 자신의 역할로 분기 | win.ogg / lose.ogg / draw.ogg |

충돌 강도 구분은 로컬 믹싱용 임시 기준이다: normal impulse<2 약,2~8 중,8이상 강. 원작 측정값이 아니다. 서버는 최근24건만 전달하며 오래된 사건은 클라이언트에서 재생하지 않는다. 아이템 전용 소리와 공통 카드 사용음을 동시에 겹쳐 틀지 않는다. 전용 파일이 없다면 card-use.ogg 하나를 공통 대체음으로 연결할 수 있다.

전체 음소거/음량·사용자 첫 조작 후 오디오 활성화·여러 충돌의 동시 재생 상한은 실제 파일 적용 시 오디오 담당이 연결한다. 파일이 없어도 네트워크 오류나 게임 실패로 취급하지 않는다.

## 로컬에서 확인

화면: `http://127.0.0.1:5206/alkkagi-preview.html?role=red` → 청팀 화면/관전 링크로 세 역할을 연다.

- 일반 플레이: 연습 카드 받기 없이 테스트 시작. 처음0장, 손실3/6/9/12/15개 이정표에서 열세일 때 지급한다.
- 개별 검수: 시작 전 카드 두 종류 선택 → 연습 카드 받기 → 시작. 카드 선택/대상·미리보기/확정·취소를 확인한다.
- 일반 발사: 알을 누른 채 바로 당겨 놓는다. 클릭만 하기·Esc·우클릭은 발사하지 않는다.
- 벽: 커서 이동→초록/빨강 미리보기→Q/E 또는 휠 회전→클릭 고정→확정. 고정 후 ‘벽 위치 다시 고르기’ 가능.
- 관전: 현재 턴 알을 드래그해 파란 훈수 전송. 실제 발사·카드 사용은 불가. 채팅/커서는 같은 로컬 판에 공유된다.
- 종료: 기권 확인 또는 실제 전멸/시간 판정 → 결과 → 다음 판 준비. 새 판에 손패·벽·채팅·훈수를 이월하지 않는다.

미정 정책의 로컬 임시값·실제 공원/DB 연결 경계는 [카드 계약](alkkagi-items.md)과 [결정 목록](alkkagi-decisions.md)에 구분했다. 사운드/이미지 전달 전에도 위 흐름을 테스트할 수 있다.

사용자 검수 반영(2026-10-31): 장외 비행·공격 강화/방어막·크기 변경 이펙트·10초 경고는 외부 에셋 없이 구현했다. 현재 에셋은 로컬 플레이/개발 검수의 필수 조건이 아니다. 정식 공원 배포에는 게임 선택·회원·예약/정산 연결이 별도로 필요하며 로컬 데모만 배포하면 서비스 게임이 되는 것은 아니다.

장기알 자체 디자인: AlkkagiPiece/pieceGeometry는 깎인 팔각 모서리·목재 측면·하단 띠와 나무결 바탕/홍청 이중 원·한자를 생성한다. 폰트 파일/외부 이미지/모델을 배포하지 않으며 사용 가능한 시스템 한자 글꼴로 Canvas에 그린다. 서버 반경 안의 정점·높이.27·승인 위치와 기존 pointer 동작을 유지한다. 배율/아이템 효과/장외 비행은 상위 보드와 같은 경로로 동작한다.

장기판 자체 디자인: AlkkagiBoardSurface는 밝은 나무결/짙은 목재 테두리·얇은 장식선·기존 격자·궁성 무늬를 단일 Canvas 텍스처로 생성한다. 9×10/Y=0 입력 평면을 유지하며 측면/아래 받침은 렌더 전용·raycast 제외다. 테두리는 평면 무늬로 공이나 벽을 막지 않고 기존 장외 중심 경계도 바꾸지 않는다. 외부 장기판 모델/이미지가 없어도 이 자체 디자인으로 로컬 검수할 수 있다.

아이템8종은 AlkkagiItemCard에서 사용자 제공 WebP를 표시하며, 이미지 실패 시 기존 자체 SVG와 CSS 프레임을 대체 표시한다. 실제 보유 카드만 버튼이며 도감은 읽기 전용 article이다. 조작은 기존 손패ID/선택/취소/서버확정/canItem을 그대로 사용한다. 판의 가로선은 실제 초기 좌표±1.2/2.2/3.2/4.2와중앙0, 세로선은-4~4이며 궁성은2.2~4.2에맞췄다. 정면 직교 투영으로 높이에 의한 알 윗면/바닥선 원근 오차를 제거했다. 서버 좌표/초기배치/물리/장외는 바꾸지 않고 자유이동을격자에스냅하지않는다.

카드 이미지 전달 규격: 원본600×900px PNG/sRGB(2:3), 게임용WebP는 장당100~300KB를 시작 목표로 시각검수한다. 목표를 맞추느라 글씨/윤곽이 뭉개지면 화질을 우선하며 원본PNG는 보존한다. 현재 카드UI와3장선택창은 사용자 제공 이미지를2:3비율로 표시한다. 이미지 전송 실패 시 자체SVG로 대체하며 카드 이름과 선택·사용 기능을 유지한다.

손패 정책 확정: 장수 한도 없이 누적한다. 이미2장을 갖고 있어도 다음 손실 이정표의 후보선택/획득을 건너뛰지 않는다. 보유 카드는 장수 표기와 줄바꿈/스크롤로 보여주며 아이콘/카드2:3비율·선택/사용방식은 유지한다.

## 사용자 제공 카드 적용 (2026-10-31)

바탕화면 `알까기` 폴더의 1024×1536 PNG8장을 원본 변경 없이 게임용600×900 WebP(sRGB, quality90, effort6)로 변환했다. 결과는 `frontend/src/game/alkkagi/assets/cards/`에 정적 import하며 도감·손패·후보선택에 함께 사용한다. 원본/변환 바이트·SHA-256 출처는 같은 폴더 manifest.json에 기록한다. 원본 합계20,956,496바이트, 변환 합계1,110,274바이트이며 실제 로딩시간 개선 수치는 측정하지 않았다. 썸네일은 이번 범위에 포함하지 않았다.
