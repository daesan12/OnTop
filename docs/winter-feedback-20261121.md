## 눈싸움

- 눈은 최대 3개까지 모으고 한 번에 1개씩 소비한다. 줍기 요청 ID 64개를 기억해 같은 요청의 재전송으로 수량이 증가하지 않게 한다. 채널 이탈 시 소지·예약 비행·중복 기록을 정리한다.
- 눈더미에서는 Q 수집 / R 던지기다. 눈더미 밖에서는 기존 Q 던지기도 유지한다. 보유량을 `눈덩이 N / 3`으로 표시한다.
- 준비 시작 250ms에 손의 눈을 숨긴다. 실제 발사는 기존 300ms 준비 뒤 진행한다. 여분이 있어도 던지기 회복 650ms 동안 손에 표시하지 않는다. 탄약 감소 패킷이 발사 패킷보다 먼저 도착해도 재수집 모션으로 오인하지 않는다.
- 발사는 탄약과 궤적만 확정한다. 서버 틱에서 비행 시간 경과 후 현재 대상 위치·활동·면역을 다시 확인하여 명중을 적용한다. 목표 위치를 벗어나거나 채널을 떠난 대상에게 뒤늦게 명중하지 않는다. 세 번째 명중 시점부터 기존 5초 빙결을 시작한다.
- 발사 이벤트의 `hitUserId`는 조준 당시 예상 대상이다. 확정 결과는 새 `WORLD_SNOWBALL_IMPACT` (`shotId`, `channelId`, `userId`, `hitUserId`, `impactedAt`)로 알린다. 확정 결과 전에는 명중·피격 안내를 표시하지 않는다. 기존 STATE·WINDUP·EVENT와 A/D 탈출 계약은 유지한다.
- FE는 표시 시계가 조금 늦어도 빙결 시작 전에 얼음 효과를 그리지 않는다. 손 소품은 발사 구체보다 먼저 갱신한다.
- 눈싸움 버튼이 기존 채팅창에 가려지는 문제도 확인했다. 해당 겨울 UI만 별도 위치에 배치하고 작은 높이에서는 실제 스크롤을 허용한다. 버튼·소지량을 자르거나 오른쪽 스크롤바를 노출하지 않는다.
