## 같은 궤적의 화면 재생 비교

실제 Java 궤적+실제 AlkkagiReplay 클래스를 Node24에서 실행했다. 60fps 가상 화면·지연30ms, 지터는FIFO -12~15ms 합성이다. 실제 브라우저 RTT/GPU 측정과 구분한다. 아래는 새 모델32개 판 소형 최대힘, **생존 말만** 위치오차를 합산한 결과다.

| 전송/버퍼 | 무지터 최대오차 | 합성지터 최대오차 | 첫 움직임 지연 | 직렬화fixture 총량 |
| --- | ---: | ---: | ---: | ---: |

지터 RMSE는20/100 약.00598,40/100 약.00617로 이 조건에서는40Hz가 더 낫지 않았다. 재생 중 freeze 표본0이지만 최초 버퍼 대기는 별도125/175ms에 포함한다. 움직인 말별 첫 움직임 지연은 충돌에 의해 움직이기 시작한 표적의 시각 지연 대체 지표다. 순간속도는 수신 지터로 물리속도보다 커질 수 있다.

fixture bytes는 전체 서비스 STATE에 시각/메타데이터 등을 모두 넣은 실제 네트워크 측정이 아니다. WebSocket/TLS헤더도 제외됐다. 12화면은 단순히12배로 추정하며 서버 부하를 실제로 발생시키지 않았다. 40Hz를 기본 적용하지 않는다.

이 전방 시나리오의 탈락 애니메이션은0회다. 외곽 탈락 궤적은 따로 재생 비교하고, 실제 브라우저의 낙하/숨김·새 관전/복구도 기존 Chrome 시나리오와 수동 검수로 확인한다. 재접속 시 과거 낙하를 재생하지 않는 정책은 유지한다.

## 실제 로컬 수신 관측

관전자 연결에서25개 STATE의24개 수신간격을 짧게 관측했다. fixed-delay 방식1494.2ms(평균62.26ms), fixed-rate 타이머 시도1446.3ms(평균60.26ms), 최종 발행 기반 유한 송신1200.1ms(평균50.00ms)였다. 최종 seqStep은24개 모두1, 수신 간격은약39.4~62.8ms였다. 개별 jitter까지0이 된 것은 아니다.

최종25개 실제 payload는117,025bytes였다. 앞선 관측과 경기 상태/숫자 문자열 길이가 같다는 보장이 없어 바이트량 전후 개선으로 비교하지 않는다. TLS/WebSocket 헤더 제외, 한 로컬 관전자·짧은 구간이며 운영 사용자/부하/RTT 결과가 아니다. 실제 루프의 명목 주기를 확인하는 보조 근거로만 사용한다.
