# OnTop 시연 시나리오

## 1. 준비

### 계정

- 발표자 A: GM/관리자 권한 계정
- 참여자 B: 일반 사용자 계정
- 예비 계정 C: 재접속·멀티플레이 대체 계정

실제 계정 ID·비밀번호는 문서에 적지 않고 발표자에게 별도 전달합니다.

### 브라우저와 장비

- Chrome 최신 버전 2개 프로필 또는 Chrome + Edge
- 화면 해상도 1920×1080, 브라우저 배율 100%
- WebGL·하드웨어 가속 활성화
- VR 시연 시 OpenXR 호환 HMD와 컨트롤러

### 시작 15분 전 점검

1. `https://api.on-top.world/actuator/health`가 `UP`인지 확인
2. `https://www.on-top.world` 로그인·공원 입장 확인
3. FE·BE 공원 `mapVersion` 일치 확인
4. WebSocket 연결, 채널 입장, 랭킹 API 확인
5. 발표용 계정의 엽전·뽑기권·관리자 권한 확인
6. 게임 테이블과 미니게임에 진행 중 세션이 없는지 확인

## 2. 조작 안내

| 조작 | 기능 |

| `WASD` / 방향키 | 이동 |

## 3. 권장 시연 흐름(약 20분)

### 3.1 로그인과 온보딩 — 2분

1. `https://www.on-top.world` 접속
2. SSAFY 또는 네이버 로그인 선택
3. 최초 계정이면 닉네임·기본 캐릭터 설정
4. 금칙어·중복 닉네임 검증을 짧게 설명
5. 공원 입장

핵심 설명: OAuth 이후 Access/Refresh 인증, 서버 검증 닉네임, 환경별 콜백 분리.

### 3.2 220m 공원과 실시간 멀티플레이 — 3분

1. A와 B가 같은 공원 채널 입장
2. 이동·점프·감정표현·채팅 시연
3. 상대 아바타 위치와 외형이 실시간 동기화되는 모습 확인
4. 열기구·오리배·대여 시설 중 하나를 `E`로 이용
5. 잠깐 새로고침 후 재접속·위치 복구 확인

핵심 설명: 자체 Spring WebSocket, 서버 맵 버전 확인, 동적 채널, 이동 검증과 재접속.

### 3.3 테이블 게임 — 4분

1. A와 B가 오목 또는 알까기 테이블 앞에서 `E`
2. 착석 → 판돈/준비 → 게임 시작
3. 한두 수 또는 조작을 시연
4. 관전자 화면·채팅·훈수 표시 확인
5. 정상 종료 또는 기권 후 결과·정산 확인

시간이 충분하면 원카드·브리지·Farkle·할리갈리 중 하나를 추가로 보여줍니다.

핵심 설명: 서버 권위 상태, 중복 요청 방지, 지갑 원장 정산, 이탈·재접속 처리.

### 3.4 미니게임과 랭킹 — 4분

1. 점프맵 안내 비석에서 랭킹 확인
2. 점프맵 V2 또는 돌탑 생존전 플레이
3. 두더지·스피드 두더지·구구구 줄넘기 중 하나 플레이
4. 결과 화면과 랭킹 갱신 확인
5. 관리자 계정에서 의심 타이밍 감사 화면을 짧게 소개

핵심 설명: 게임별 규칙 버전·집계 기간 분리, 서버 기록, 반복 초단기 입력 감사.

### 3.5 상점·뽑기·옷장·마이룸 — 3분

1. 의상 뽑기 기계 앞에서 `E`
2. 뽑기권 구매 또는 보유권으로 캡슐 뽑기
3. 보상 의상을 옷장에서 확인하고 착용
4. 마이룸에서 보유 의상·외형 확인
5. 공원 복귀 후 다른 사용자에게 외형이 동기화되는 모습 확인

핵심 설명: 지갑·아이템 원장, 멱등성, S3 Presigned PUT, CloudFront 공개 에셋.

### 3.6 AI 주민과 아재개그 — 2분

1. 김부장 NPC와 대화 시작
2. 아재개그 한 개 제출
3. 공개 적합성 검수·채점·심사평 확인
4. Rapfi 기반 오목 NPC가 활성화돼 있으면 상태와 대결 진입 소개

외부 API 지연 시 고정 대사/비활성 안내로 전환하고, 오류로 전체 공원 흐름이 막히지 않는 점을 설명합니다.

### 3.7 이벤트·응모권·관리자 — 2분

1. 주간 랭킹과 이벤트 기간 확인
2. 응모권 구매 후 고유 응모 번호 확인
3. 관리자 화면에서 공지·이벤트·스킨·일괄 엽전 지급 미리보기 소개
4. 실제 전체 지급·추첨 실행은 평가 데이터 보호를 위해 누르지 않음

핵심 설명: 주차별 번호 유일성, 멱등키, 관리자 권한 분리, 감사 원장.

## 4. 선택 시연: VR

1. HMD에서 공원 입장
2. 이동·시점·메뉴 조작
3. 오목 착석 또는 꼬치왕 협동 진입
4. PC 사용자와 같은 세션에서 상호작용 확인

HMD 연결이 불안정하면 녹화 영상과 PC 화면으로 대체하고 본 시연을 중단하지 않습니다.

## 5. 장애 시 대체 동선

| 문제 | 즉시 조치 |
| --- | --- |
| OAuth 실패 | 이미 로그인한 예비 프로필 사용 |
| 같은 채널에 못 만남 | 채널 번호 확인 후 재입장 |
| WebSocket 재연결 | 새로고침 후 30초 이내 복구 확인 |
| 외부 AI 지연 | AI 기능을 건너뛰고 게임·관리자 시연 진행 |
| 게임 진행 상태 잔류 | 예비 테이블 사용; 운영 DB 직접 수정 금지 |
| 프론트 자산 로딩 지연 | 강력 새로고침 1회, 이후 예비 브라우저 사용 |
| VR 장비 실패 | PC 시연과 사전 녹화 영상으로 대체 |

## 6. 시연 후 확인

- 테스트 경기·보상·관리자 실행 내역 기록
- 오류 로그와 4xx/5xx 확인
- 임시 기능 플래그와 테스트 관리자 권한 원복 여부 확인
- 사용한 임시 API 토큰·계정 비밀번호 폐기 또는 회전
