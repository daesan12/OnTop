# 흑백수사 대표 그림

- `cover.webp`: OpenAI 내장 Image Gen으로 2026-11-21 생성한 게임 선택/설명서용 그림. 768×512, WebP.
- 사용자 제공 타일 사진은 타일 구조 참고로만 사용했으며 원본 사진을 배포하지 않는다.
- 생성 방향: 한국 공원 정자의 나무 테이블, 짙은 녹색 천, 한지색/검정 타일, 금색 이중 테두리, 숫자 1·3·6·9·11과 공개된 7. 인물·로고·UI 없음.
- 플레이 중 타일은 `ParkSecretTiles.tsx`에서 실제 공원 테이블 위에 배치한다. 대표 그림은 실제 게임판을 대신하지 않는다.
- 숫자패·조커패는 `DavinciBoard.tsx`의 공용 Three.js 모델을 사용한다. 원목 상하 마감, 기와 먹색/상아색 면, 구름 문양, 숫자 밑줄과 온탑 로고 조커를 사용한다.
- 조커 앞면은 기존 `src/assets/entry/ontop-logo.webp` 원본을 비율·투명도·색상 그대로 재사용한다. 로고는 알려진 조커 앞면에만 표시하며 로딩 중에도 타일/공원 렌더링을 유지한다.
- 숨은 패와 조커의 외형·창살 뒷면은 색상별로 동일하다. 조커 문양·숫자 텍스처는 본인이 알거나 공개된 값에만 생성한다.
- `/secret-tiles-preview.html?view=tiles`는 검정/흰색 숫자·조커·뒷면을 함께 보는 로컬 에셋 검수 진입점이다.
