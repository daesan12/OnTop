- 낚시터는 원본 목재 데크·낚싯대 거치대·목재 벤치·안내판을 유지하며 돌 테이블을 두지 않는다. 나무 접근로의 육지 끝을 도로 경계와 같은 +4.085m로 맞추고 데크까지 완만하게 높인다.
- 호수섬을 23×29m로 늘려 큰 팔각정과 버드나무를 위한 여유를 확보했다. 한 개의 아치 다리는 서쪽 +4.685m, 섬 쪽 +4.285m로 끝 높이를 맞췄다. 다리와 나무 진입로 아래에는 겹치는 지상 포장면을 생성하지 않는다.
- 선착장 진입로는 폭 3.4m의 나무 길 하나로 정리했다. 도로 경계 (51,26.5)에서 옆 출입구까지 이어진다.
- 선착장 GLB의 로컬 인스턴스에서만 부스 깊이를 줄여 뒤쪽 보행 여유를 만들었다. 원본 데크·접안 손가락·외곽 난간·승인 GLB는 보존한다. 실제 GLB 삼각형의 가로/바닥 raycast로 옆 출입구와 뒤 통로를 검사한다.
- 2척 접안과 3척 순환, 전진 방향, 아치 다리 아래 선체와 차양의 높이 여유를 유지한다.

## 점프 정원과 건물

- 점프맵 시작 석탑을 (-66,13)으로 안쪽에 옮겼다. 반지름 13m 돌담 정원과 남쪽 출입구를 만들고 큰 안내 비석을 (-61,27)에 놓았다. 석탑 주변 수목을 비웠다.
- 전체 145개 발판과 9개 관문은 기본 상태에서 보인다. 첫 발판은 도전 시작 조건이며, 관문 순서와 호수 도착 판정은 유지한다. 재시작해도 발판을 숨기지 않는다.
- 기존 7단계 다음은 두더지·비둘기·오리다. 두더지는 갈색 둥근 몸체, 분홍 코, 검은 눈과 흰 하이라이트, 돌 둘레로 만들었다. 착지 윗면은 평평하게 유지한다.
- 오락실은 건물·지붕·내부 게임기를 함께 더 줄여 (-65,48)의 잔디 안에 놓았다. 민속놀이존은 남서 팔각정 옆 (-61,78)로 옮기고 길을 재연결했다.
- 서쪽 대여소는 (-78,39)로 옮겼다. 모든 짝 대여소의 전체 지붕 폭과 차량을 포함해 지면을 평탄화하고, 자전거·킥보드 메시 최저점을 바닥에 맞췄다. 전기자전거 배터리 모듈을 유지한다.

## 높은 지형과 마감

- 대석탑 정원을 (0,-73)으로 뒤로 보냈다. 원본 26m 석단·돌울타리·사방 계단은 그대로 이동한다. 각 방향 계단의 끝은 돌길과 접하고 남쪽 긴 계단과 우회로를 유지한다.
- 대석탑과 열기구 지면 +22m를 유지한다. 열기구 승강장은 (-40,-76)으로 약간 안쪽에 놓아 담장 여유를 확보하고, 전체 원형 바닥을 평탄화해 바닥이 묻히지 않게 했다.
- 도로 어깨를 채워 움푹 파인 지형을 완화하고 급경사는 석재 옹벽으로 마감한다. 높은 길의 난간은 실제 포장면 합집합 경계를 따라 연결하며, 기둥과 하부 석재는 잔디 쪽으로 물렸다. 계단·시설 출입부는 열어 둔다.
- 건물마다 흙판이나 별도 큰 앞마당을 만들지 않는다. 지붕·계단·대여소 폭을 포함한 시설 발자국 아래는 잔디로 남기고 시설 바닥 높이를 맞춘다. 원래 광장·분수·운동마당·대석탑 석단은 해당 시설의 원본 바닥을 유지한다.
- 수목은 수관 폭으로 길·건물·외곽 기와돌담 여유를 검사한다. 급한 옹벽 면에는 심지 않고 완만한 언덕에는 키 큰 가는 나무, 평지에는 여러 수종을 섞는다. 추가 벤치 6개와 가로등은 숲길 옆 잔디에 둔다.
- 기존 공원 외곽 기와돌담·정문, 차도·도시 건물·산·서울타워 배경을 유지한다. 공중을 포함한 모든 플레이어 높이에서 외곽 경계 통과를 막는다.

## 확장과 변경 범위

220×220m / 최대 40명 기준, 시설·장소 37곳, 팔각정 총 6개, 짝 대여소 7곳, 돌 테이블 4개, 확장 부지 3곳과 NPC 자리 4곳을 유지한다. 입구 새 길과 겹친 18×14m 확장 부지는 크기를 유지한 채 (-18,-38) 정원 아래로 옮겼다. 북쪽 24×20m와 서쪽 22×18m도 유지한다.

주 구현은 src/park-renewal/와 독립 HTML/Vite 설정이다. 공통 추적 파일은 이전 DistantLandscape.tsx의 선택적 anchorTowerToRidge와 이번 PlannedLandmarks.tsx의 선택적 furniture 속성만 변경했다. 둘 다 기본 동작을 유지한다. 서버·DB·공통 protocol·기존 실제 맵 등록 파일은 수정하지 않았다.

배치·보행·점프 Node 검사 21개, 실제 모델·원본 보존 Vitest 20개. 로컬 WebGL에서 입구·호수·언덕·점프 정원과 시설 접점을 확인한다. 타입 검사·빌드·diff 검사도 수행한다. 기존 큰 JS 청크 경고와 테스트 로더의 Three CJS 경고가 남는다.

독립 로컬 배치 화면에 반영한 상태다. 실제 서버 통신·대여·미니게임 진입·보상·영속 기록·40명 동접·VR 헤드셋은 검증하지 않았다. 장식 메시 전체에 대한 정밀 충돌 대신 경계·울타리·보행 바닥과 시설 영역의 단순 충돌을 사용한다. 망원경·메모함은 로컬 시각 배치이며 실제 서버 상호작용 좌표는 후속 통합 대상이다.

최종 자동 검증 결과: Node 21개 + Vitest 20개, 총 41개 통과. TypeScript, 로컬 Vite 빌드, git diff --check 통과. 원격 반영 없음.
