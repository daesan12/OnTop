# 기존 붕어빵 게임 전용 렌더링

기준: `dev`의 `b7a13bb69a233082280d6ee3b50e285a8d4d2f3e`.

기존 완성본을 유지하기 위해 해당 커밋의 `world/art` 구현을 게임 내부에서 재사용한다. `propGeometry.ts`는 게임에서 사용하는 `PropBuilder`까지만 가져왔으며, 나머지 파일은 모듈 경로만 조정했다. `../privateGriddle.ts`의 `rounded`·`griddle`도 같은 커밋에서 가져왔다.

새 공원의 로우 폴리 정책이 작은 조리 도구·붕어빵 무늬·손님 얼굴을 생략하지 않도록 공원용 빌더와 분리했다. 공원 카트 모델·맵 배치·충돌·게임 규칙·서비스 통신은 이 디렉터리에서 변경하지 않는다. 공통 음영/캐시처럼 동일한 구현은 원래 모듈을 사용한다.

게임 업데이트 시 원본 커밋과 기존 동작을 먼저 비교한다. 새 맵 외형을 맞춘다는 이유로 게임을 다시 구현하거나 단순화하지 않는다.
