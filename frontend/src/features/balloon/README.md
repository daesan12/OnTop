# 하늘언덕 열기구 프리뷰

기준은 `origin/feat/park-renewal-restart`의 `3fb7048e`다. 작업 시작 당시 최신 `origin/dev`의 `2bc38cdd`가 기준 이력에 포함되어 있었다.

`frontend`에서 프로젝트 의존성을 설치하고 실행한다.

```sh
pnpm exec vite --config vite.balloon-preview.config.ts
```

[로컬 프리뷰](http://127.0.0.1:5226/balloon-preview.html)에서 W 또는 위 방향키로 승강장에 접근한 다음 E를 누른다. 기본 프리뷰는 혼자 탑승하고 출발하기를 누르면 바로 이륙한다. 조종석에서 WASD 또는 방향키로 이동하고 Space와 Shift로 상승·하강한다. 동승석은 드래그나 좌우 화살표로 시점을 돌린다.

- `?guests=3`은 네 번째 자리 탑승을, `?guests=4`는 만석을 보여준다.
- `?coins=0`은 잔액 부족을, `?role=passenger`는 동승과 대기 시간 종료 후 출발을 보여준다.
- 비행 중 '조종자 이탈 확인'을 누르면 승강장 자동 복귀를 확인할 수 있다.
- 가상 요금은 10냥, 최대 대기 시간은 12초, 운항 시간은 90초, 착지 후 제거 시간은 5초다. 요금은 출발 시 가상 잔액에서 차감된다.

`flight.ts`는 프리뷰 비행 상태와 경계를 계산한다. 승강장 및 열기구 모델, 캐릭터 로더, 한지 팝업은 리뉴얼 브랜치의 자산을 가져온다. 지형, 탑승 인원, 엽전은 프리뷰용이고 서버 연결은 다음 단계다. 통합 시 리뉴얼 맵의 `balloon` 시설 진입점과 공원 지형 데이터를 연결하고, 서버에서 좌석 예약, 요금 차감, 비행 위치, 재접속 상태를 확정한다.
