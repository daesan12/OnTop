# 오목 · 렌주

15×15 교차점에서 흑부터 번갈아 한 돌씩 놓아요. 서버가 착수와 승패를 판정해요.

## 판과 목표 알아보기

흑은 정확히 5개, 백은 5개 이상을 가로·세로·대각선으로 이으면 승리해요. 빈 점이나 상대 돌이 끼면 연결되지 않아요. 판이 가득 차도 승자가 없으면 무승부예요.

## 내 차례에는 이렇게 해요

1. 내 차례에 판의 빈 교차점을 골라 클릭해요. 놓은 돌을 움직이거나 무를 수 없어요.
2. 서버의 승인과 최신 판을 기다려요. 잘못된 착수라면 안내를 읽고 다른 교차점을 골라요.
3. 내 차례 전체 제한시간은 30초예요. 설명서를 읽거나 다시 접속해도 연장되지 않으며, 만료되면 시간패예요.

## 흑돌의 금수 알아보기

흑의 삼삼·사사·장목(6개 이상)은 금수예요. 단, 같은 착수로 정확히 5목을 완성하면 승리가 우선해요. 백에는 이 금수를 적용하지 않아요.

금수로 거절된 착수는 판·차례·제한시간을 바꾸지 않아요. 자유룰과 구별해 주세요.

## 연결과 결과

연결이 끊기면 서버 복구를 기다려요. 기권이나 복구 유예 만료는 서버 규칙으로 처리해요. 결과와 엽전은 서버가 확정한 내용을 확인해요.
