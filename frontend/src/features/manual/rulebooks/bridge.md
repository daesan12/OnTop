# 거짓말 다리 건너기

나만 본 주사위 눈을 숨기고 1~4를 선언해요. 이웃이 믿으면 전진하고, 다우트하면 진실을 밝혀 틀린 쪽의 말이 연못으로 떨어져요.

## 연못 위의 작은 다리

각자 말 7개를 받아요. 처음에는 현재 말 하나가 출발점 0에 있고 나머지 6개는 예비 말이에요. 다리의 이동 칸은 1~8이며 위치 9 이상으로 나아가면 골인해요.

현재 말이 골인하거나 떨어지면 예비 말 하나가 출발점으로 나와요. 같은 칸에 여러 사람의 말이 함께 있어도 괜찮아요. 골인하고 남은 이동 거리는 다음 말에 넘기지 않아요.

## 굴리고 → 선언하고 → 판단해요

1. 내 차례에 ‘비밀 주사위 굴리기’를 눌러요. 여섯 면은 1·2·3·4·X·X예요. 실제 눈은 나만 볼 수 있어요.
2. 1~4 중 하나를 선언해요. 실제 숫자를 말해도, 거짓말을 해도 돼요. X가 나왔다면 1~4를 골라 반드시 거짓말을 해야 해요.
3. 다른 사람들은 시계 방향으로 한 명씩 판단해요. 자기 판단 차례에 ‘믿기’ 또는 ‘다우트!’를 눌러요. 다우트는 ‘지금 거짓말했죠?’라는 도전이에요.
4. 모두 믿으면 선언한 숫자만큼 현재 말이 전진해요. 실제 눈은 끝까지 공개하지 않아요. 한 명이라도 다우트하면 바로 공개하고 판정해요.

> 기억해 주세요: 말이 움직이는 애니메이션보다 판정이 먼저 확정돼요. 결과 표시가 끝나면 다음 입력 안내를 따라 주세요.

## 다우트하면 누가 떨어지나요?

| 공개한 실제 눈            | 떨어지는 말      | 전진하는 말                    |
| ------------------------- | ---------------- | ------------------------------ |
| 선언과 다름 · 다우트 성공 | 선언자의 현재 말 | 도전자의 현재 말 · 선언 값만큼 |
| 선언과 같음 · 다우트 실패 | 도전자의 현재 말 | 선언자의 현재 말 · 선언 값만큼 |

### 예시 · “4가 나왔어요!”에 다우트했다면

실제 눈이 2 또는 X → 거짓말! 선언자의 말이 떨어지고 도전자 말이 4칸 전진해요.

실제 눈이 4 → 진실! 도전자 말이 떨어지고 선언자 말이 4칸 전진해요.

다우트 없이 모두 믿었다면 → 실제 눈과 무관하게 선언자 말이 4칸 전진해요.

## 골인 번호와 승리

처음 골인한 말은 1번 점수 자리에, 다음 말은 2번 자리에 놓여요. 이런 식으로 8번까지 순서대로 번호를 받고 그 번호만큼 점수를 얻어요.

현재 유효한 골인 말 3개를 모으면 즉시 승리해요. 같은 순간 8번 골인 번호가 발급돼도 3개 골인 승리를 먼저 적용해요.

3개 골인 승리 전에 8번까지 번호가 발급되거나, 모든 사람에게 현재 말과 예비 말이 없어지면 점수를 비교해요. 기권하지 않은 사람 중 남아 있는 골인 말 점수 합이 가장 높은 사람이 이겨요. 동점은 공동 승리예요.

### 예시 · 2번과 6번에 내 말이 있다면

현재 점수는 2 + 6 = 8점이에요. 이후 2번 말을 잃으면 6점만 남아요. 사라진 2번 자리는 회색 X로 남고, 다음 골인 말에게 다시 주거나 번호를 당기지 않아요.

## 이동할 말이 없어도 다우트할 수 있어요

현재 말과 예비 말이 모두 없어도 골인한 말이 남아 있다면 다른 사람의 선언을 믿거나 다우트할 수 있어요. 다만 내 주사위 차례는 건너뛰어요.

이 상태에서 다우트에 성공하면 상대의 현재 말은 떨어지지만, 내 말의 이동 보상이나 새 말은 생기지 않아요.

다우트에 실패하면 내가 가진 골인 말 중 가장 낮은 번호의 말 하나를 잃어요. 그 자리의 점수도 사라지며, 번호는 다시 사용하지 않아요. 현재 말이 있다면 골인 말 대신 현재 말이 떨어져요.

## 시간이 지나거나 연결이 끊기면

다시 연결해도 이미 본 눈을 새로 굴리거나 제한시간을 처음부터 받지는 않아요.

기권하거나 유예 안에 돌아오지 않으면 진행 중인 선언의 판정을 마친 뒤 기권을 반영해요. 남은 말과 골인 말은 제거되고, 이미 발급한 골인 번호는 재사용하지 않아요.

기권하지 않은 사람이 한 명이면 그 사람이 승리해요. 모두 기권하면 승자 없이 끝나요. 말이 소진된 것은 기권과 달라요.

| 상황 | 현재 처리 |
| --- | --- |
| 30초 안에 굴리지 않음 | 자동 굴림 없이 차례 건너뛰기 |
| 30초 안에 선언하지 않음 | 자동 선언 없이 차례 건너뛰기 |
| 내 판단 순서에서 30초 경과 | 자동 믿기 후 다음 판단자로 이동 |
| 판정 후 약 1.5초 | 결과 연출 후 다음 단계 |
| 연결 끊김 | 30초 복구 유예 · 원래 눈과 마감 유지 |

> 설명서를 열어도 단계별 30초 제한시간은 멈추지 않아요. 굴리기·선언·각 사람의 판단은 별도 단계예요.
