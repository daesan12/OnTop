# 크리스마스 트리형 상호작용 아트

2026-11-22 사용자 요청에 따라 built-in `image_gen`으로 새로 생성했다.
소리함·메모함·뽑기 화면의 이미지는 복사하지 않았다. 공원 GLB·배치·충돌에는 사용하지 않는다.

- `tree-frame.webp`: 1122×1402, 투명 외곽을 가진 데스크톱용 트리 실루엣.
- `tree-frame-mobile.webp`: 887×1774, 좁은 화면에서도 입력 영역을 넓게 확보한 별도 세로 변형.
- 원본 PNG는 Codex generated_images에 보존하고 프로젝트에는 WebP quality=90,
  alphaQuality=100으로 인코딩했다. 이미지 안에는 글자·버튼·입력란을 그리지 않았다.
  제목·장식 선택·작성·이름 공개·편지 조회는 실제 DOM 및 기존 서버 계약을 사용한다.

생성 프롬프트 요지: 하나의 온전한 크리스마스 전나무 형태 UI 외곽, 꼭대기의 입체 금빛 별,
눈 덮인 정교한 가지·따뜻한 전구·가는 금색 가랜드·붉은 리본, 밑동의 포장 선물과 눈.
중앙은 실제 텍스트와 입력을 위한 넓고 조용한 짙은 녹색 벨벳 영역으로 비운다.
외부는 투명하며 사각 게시판·기와·건물·목재 프레임·종이 패널·텍스트·버튼은 그리지 않는다.
모바일 변형은 원본을 레퍼런스로 재생성하며 1:2 비율, 높이 20~85% 구간에서
중앙 폭을 넓히고 가장자리에만 가지·리본·전구를 배치한다.

원본 파일:

- desktop: `exec-3f1bcd46-a312-4303-bf27-f12b2a99f578.png`
- mobile: `exec-adb705ce-3bef-4769-a12c-c14245040a42.png`

검수에서는 실제 브라우저의 트리 실루엣·별·가지/선물의 비율, 녹색/금색 대비,
장식이 매달린 선택 형태, 작성란과 버튼의 가독성 및 작은 화면 스크롤을 확인한다.
