# BE 담당자에게 보낼 글

공원 관련 FE 변경과 별도로, 서버 처리가 필요한 두 가지를 요청드립니다. 상세 조건은 [BE_PARK_FOLLOWUP_2026-10-29.md](./BE_PARK_FOLLOWUP_2026-10-29.md)에 정리했습니다.

**1. 보이지 않는 의자에 막히는 문제**

팔각정은 기본 의자 2개만 보이고, 승인된 3인/4인 설정에 따라 추가 의자가 나타납니다. 그런데 서버 충돌은 항상 4개라 빈자리에서도 지나가지 못하는 상태입니다. 서버도 승인 인원수에 맞춰 의자 충돌을 켜고 꺼 주세요. 2인은 3·4번 자리, 3인은 4번 자리를 지나갈 수 있어야 합니다. 주변 사람도 의자 수를 맞춰 볼 수 있도록 공개 상태 갱신 방식도 공유 부탁드립니다.

**2. 게임·상점 이용 말풍선**

붕어빵처럼 실제 게임 중인 사람에게 '게임 중', 추후 상점 이용자에게 '상점 이용중'을 표시하려고 합니다. FE는 기존 WORLD_STATE의 activity 값 GAME/SHOP을 받아 표시하도록 준비했습니다. BE에서 실제 게임 시작 시 GAME을 방송하고, 정산·종료·기권/탈락 시 해제해 주세요. 대기·준비·관전은 제외하면 됩니다. 상점은 추후 진입·종료 API와 상태 해제 규칙을 합의한 다음 SHOP으로 연결하면 됩니다.

FE는 현재까지의 서버 계약을 유지했고 BE 코드는 수정하지 않았습니다. 새 공개 의자 메시지, 맵 변경 자료, 상점 API가 확정되면 알려 주세요. 필요한 FE 후속 연동을 맞추고, BE 반영 후 두 브라우저로 실제 통행과 말풍선 전파를 함께 확인하겠습니다.
