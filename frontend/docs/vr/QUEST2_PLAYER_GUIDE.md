# Quest 2 플레이어 가이드 — OnTop 공원·꼬치왕·점프맵 접속하기

안내 기준: **2026-11-04**

대상: VR 기기를 가지고 OnTop 개발 테스트에 참여하는 사람, PC 서빙 담당

개발자용 준비·ADB·배포 확인은 [Quest 2 개발자 가이드](QUEST2_DEVELOPER_GUIDE.md)를 읽는다.

> **배포 확인 전 안내문이다.** 현재 공원·점프맵 VR은 로컬 개발 소스가 따로 있다. 아래 개발 주소에 모든 VR 기능이 이미 공개되었다고 보장하지 않는다.
>
> 주최자가 아래 “테스트 공개 확인표”를 채우고 배포 확인을 알려준 뒤 참여한다. VR 버튼이 없다면 개발자 모드를 켜기 전에 배포 버전을 문의한다.

## 바로 보는 접속 순서

**Quest 기본 브라우저 → https://dev.on-top.world/park → OnTop 로그인 → 채널 선택 → 공원 VR 시작 → 권한 확인 → 스틱 이동·A 점프**

꼬치왕을 함께 할 때는 PC 친구도 같은 개발 사이트·같은 채널에 각자 로그인한다. 같은 협동 방에서 **Quest 사용자는 VR 요리사**, **PC 사용자는 서빙 담당**을 고른다.

이 안내는 기기 안의 브라우저가 직접 게임 공간을 그리는 WebXR 방식이다. PC 모니터를 헤드셋에 비추는 방식과 다르다.

## 무엇을 준비해야 하나요?

### VR로 접속하는 사람

- 기본 설정을 마친 Quest 2와 양손 컨트롤러.
- 기기에서 사용하는 자신의 Meta 계정.
- 인터넷 연결과 Quest 기본 브라우저.
- OnTop 게임 계정.
- 테스트할 개발 사이트 주소와 주최자가 정한 채널.

### 꼬치왕의 PC 서빙 담당

- 키보드·마우스가 있는 PC와 웹 브라우저.
- VR 사용자와 **다른 OnTop 계정**.
- 같은 개발 사이트·채널·협동 방.
- VR 헤드셋은 필요하지 않다.

### 일반 플레이에 필요하지 않은 것

**배포된 HTTPS WebXR 사이트를 브라우저로 플레이하는 경우**, Meta 개발자 등록·개발 조직 가입·개발자 모드·USB 디버깅·ADB·USB 케이블·APK 설치·SideQuest·Quest Link/Air Link는 필수 준비물이 아니다.

일반 플레이어는 개발자의 Meta 계정으로 로그인하거나 개발자 PC에 연결할 필요가 없다. Facebook 계정 연결도 Quest 사용의 필수 조건은 아니다. [Meta 공식 계정 FAQ](https://developers.meta.com/vr/faqs/)를 참고한다.

다만 학교·회사에서 관리하는 기기, 보호자/네트워크 정책으로 제한된 기기는 관리자의 허용이 필요할 수 있다. 다른 제조사의 헤드셋·PSVR·PC VR 등 모든 VR 기기에서 자동으로 지원되는 것은 아니다. **기기와 브라우저가 WebXR의 몰입형 VR을 지원하고 게임이 그 조작을 지원해야 한다.**

## 1. Quest에서 사이트 열기

1. Quest 전원을 켜고 자신의 기기 계정으로 홈에 들어간다.
2. Wi-Fi가 연결됐는지 확인한다.
3. 양손 컨트롤러가 연결되고 포인터가 보이는지 확인한다.
4. 앱 목록에서 **브라우저 / Meta Quest Browser**를 연다.
5. 주소창에 아래 주소를 직접 입력한다.

~~~text
https://dev.on-top.world/park
~~~

6. OnTop 계정으로 로그인한다. 가입·캐릭터 설정이 처음이라면 화면 안내를 마친다.
7. 주최자/친구와 약속한 채널을 선택하고 공원이 뜰 때까지 기다린다.

**주소를 구분한다:** 개발 테스트는 `dev.on-top.world`다. `dev-api.on-top.world`는 게임 화면 주소가 아니다. 다른 사람이 보낸 `localhost:5288`은 그 사람 PC로 연결해 주는 주소가 아니므로 일반 참여자가 사용하지 않는다.

로그인할 때 “Meta 기기 계정”과 “OnTop 게임 계정”은 서로 다른 용도다. PC의 게임 로그인 세션이 Quest 브라우저에 자동으로 공유되지는 않는다.

## 2. 평면 브라우저에서 실제 공원 VR로 들어가기

페이지가 처음 열릴 때 공원이 평면 창 안에 보이는 것은 정상이다. 그다음 사이트의 VR 버튼으로 공간 안에 들어간다.

1. 채팅 입력창·설정·팝업·진행 중 게임을 닫고 공원 산책 상태로 돌아온다.
2. **공원 VR 시작**을 컨트롤러 포인터로 가리킨다.
3. 검지 트리거를 눌러 버튼을 클릭한다.
4. 사이트가 VR·공간 추적 권한을 요청하면 주소와 안내를 확인한다. 허용할지 본인이 선택한다.
5. 주변 전체가 공원 공간으로 보이고 고개를 돌릴 때 시야가 움직이는지 확인한다.
6. 양쪽 스틱을 중앙에 놓고 A 등 버튼을 한 번 뗀 다음 조작한다.

브라우저 창을 크게 만들거나 전체 화면으로 바꾸는 것만으로 게임 속 VR에 들어가는 것은 아니다. **사이트의 VR 시작 버튼을 눌러야 한다.**

WebXR은 지원 브라우저·보안 연결·사용자 클릭 등의 조건을 사용한다. [MDN의 WebXR 시작 안내](https://developer.mozilla.org/en-US/docs/Web/API/WebXR_Device_API/Startup_and_shutdown)를 참고한다.

## 3. 공원을 돌아다니기

아래는 현재 공원·점프맵 로컬 VR 버전을 바탕으로 한 안내다. 주최자가 배포 버전을 확인한 뒤 같은 조작인지 검수한다.

| 하고 싶은 일 | 조작 |
| --- | --- |
| 앞뒤·좌우로 움직이기 | 왼쪽 스틱 |
| 고개를 돌려 보기 | 헤드셋을 자연스럽게 움직이기 |
| 달리기 | 왼손 그립을 잡은 채 왼쪽 스틱 |
| 점프 | 오른손 A |
| 몸의 진행 방향 회전 | 오른쪽 스틱 좌우. 기본 부드러운 회전 90도/초, 설정에서 속도·스냅 선택 |
| 돌탑 놀이 방법 보기 | 왼손 X |
| 공간 속 안내 버튼 누르기 | 해당 손의 레이저로 가리키고 트리거 |
| 공원 VR 끝내기 | 오른손 B 또는 시스템의 VR 종료 |

이동은 보고 있는 방향의 수평 방향을 기준으로 한다. 스틱을 놓으면 멈춘다. A를 길게 누르면 자동으로 계속 뛰는 방식이 아니다. 부드러운 회전은 스틱을 기울이는 동안 이어지고, 스냅 회전은 중앙에 놓았다가 다시 기울일 때 한 번씩 적용된다.

전망대 정상에서는 **망원경 이용**을 검지 트리거로 선택한다. 오른쪽 스틱으로 보는 방향을 조절하고, 오른손 B를 눌러 VR 공원 시야로 돌아온다.

### 내게 맞는 회전과 눈높이 — 배포 후 확인할 새 설정

저장된 설정이 없으면 공원·점프맵 VR에 들어갈 때 기준 눈높이 1.65m가 적용된다. 다른 눈높이나 회전 방식을 원하면 **VR 편안함 설정**에서 바꿀 수 있다. 선택은 이 브라우저에 저장된다. 저장이 차단된 브라우저에서도 현재 페이지의 선택은 사용할 수 있다.

- **회전 방식:** 부드러운 회전 또는 스냅 회전. 부드러운 회전은 60·90·120도/초, 스냅은 30·45도 중 선택한다. 처음에는 부드러운 회전 90도/초다. 고개 움직임은 실제 움직임 그대로 반영하며 큰 방향 전환은 오른손 스틱으로 한다.
- **서서 플레이:** Quest가 제공하는 바닥과 실제 머리 높이를 사용한다. 기기의 바닥 설정이 잘못됐다면 Quest에서 먼저 맞춘다.
- **앉아서 플레이:** VR 진입 시 현재 자세를 기준으로 가상 눈높이를 맞춘다. 기준은 1.4·1.6·1.65·1.8m 중 선택하며 기본값은 1.65m다. 고개를 숙이거나 움직인 차이는 보정 후에도 그대로 반영된다.

VR 안에서도 **왼손 X → 편안함 설정**으로 열 수 있다. 레이저로 버튼을 가리키고 검지 트리거를 눌러 선택한다. 자세를 바꾸면 **현재 자세로 눈높이 재설정**을 누르고 스틱을 놓은 채 헤드셋을 안정적으로 유지한다. 각 설정 변경·재설정 요청 이후부터 캐릭터와 머리 높이가 400ms 이상 안정된 뒤 반영된다. 대기 중 다시 누르면 마지막 요청부터 기다린다. 공중에서는 낙하가 이어지므로 먼저 착지한다. 실제 코스 높이·캐릭터 위치·점프 판정은 바뀌지 않는다.

설정에서 A는 안내로 돌아가기, 안내에서 A 또는 X는 닫기다. 닫거나 설정을 바꾼 뒤에는 스틱을 중앙에 놓고 버튼을 뗐다가 다시 조작한다. 평소에는 정면 안내판을 상시 표시하지 않는다. 이 설정은 공원·돌탑에 적용하며 꼬치왕 주방의 조작 안내는 별도로 따른다.

**실제로 뛰어서 점프하지 않는다.** 게임 점프는 A로 한다. 헤드셋의 플레이 경계를 유지하고 컨트롤러 손목 스트랩을 사용한다. 어지럽다면 VR을 종료하고 쉬어 간다.

시스템 메뉴·추적 중단 후에는 스틱을 중앙에 놓고 버튼을 뗐다가 다시 조작한다. 일반 메뉴나 다른 게임으로 들어갈 때는 공원 VR이 끝나고 평면 화면으로 돌아올 수 있다.

## 4. 친구와 꼬치왕 — VR 요리사 + PC 서빙 담당

이 모드는 **정확히 두 명**이 각자 기기와 게임 계정으로 같은 가게를 운영한다. Quest가 두 대일 필요는 없다.

### 방에서 만나기

1. Quest와 PC에서 모두 **같은 개발 사이트**에 로그인한다.
2. 같은 공원 채널에 들어간다.
3. VR 체험관 입구로 이동한다.
4. Quest 사용자는 입구의 **꼬치왕 입장**을 검지 트리거로 선택한다. PC는 화면 버튼 또는 E를 사용한다.
5. 한 사람이 **방 만들기**를 선택한다. Quest에서는 컨트롤러로 한글·영문 이름과 비밀번호를 입력할 수 있다.
6. 다른 사람은 **친구 방 참가하기**에서 같은 가게를 선택한다. 비밀 가게에는 방 비밀번호를 입력한다.
7. Quest 사용자는 **VR 요리사**, PC 사용자는 **서빙 담당**을 고른다.

1인 연습 또는 10냥 이용권 화면만 보이면 이번 2인 협동 화면과 다르다. 주최자에게 협동 모드 활성화 여부를 확인한다.

### 준비하고 시작하기

1. Quest 요리사가 **VR 주방으로 들어가기**를 선택하면 현재 VR 세션에서 주방이 열린다.
2. 주방 공간의 준비 버튼으로 준비한다. PC도 **준비 완료**를 누른다.
3. 두 사람의 준비가 확인되면 카운트다운이 시작된다.

일반 브라우저 화면에서 먼저 입장했다면, 요리사 역할을 고른 뒤 **VR로 요리하기 → 헤드셋 연결하기**로 주방 VR을 시작할 수 있다.

### 영업하기

| VR 요리사 | PC 서빙 담당 |
| --- | --- |
| 주방에 전달된 그림 주문을 확인 | 손님에게 주문 접수 |
| 트리거로 음식을 집고 꼬치에 꽂기 | 주문을 주방으로 전달 |
| 그립으로 꼬치 잡기 | 전달대에서 완성 접시 수령 |
| 끝 재료를 가리키고 트리거로 빼기 | 맞는 테이블에 서빙 |
| 오른쪽 전달대나 제출 안내를 가리키고 트리거로 제출. 꼬치를 잡은 채로도 제출 가능 | 필요 시 사케 제공·자리 정리·식기 세척 |
| 공간의 인사 안내에 응답 | 화면의 인사 안내에 응답 |

PC 기본 조작은 WASD 이동과 E 상호작용이다. 행동 위치와 조건은 게임 화면의 안내를 따른다. 제작·제출·수령이 안 되면 주문 선택·접시 공간·현재 역할·연결 상태를 먼저 확인한다.

결과의 점수·지급·랭킹은 서버가 확정한 화면을 따른다. 연습/프리뷰 결과와 온라인 결과를 혼동하지 않는다. 게임 중 연결이 끊기면 새 계정을 만들거나 다른 방에 바로 들어가기보다 같은 계정으로 기존 경기 복귀 안내를 확인한다.

### 공원으로 돌아가기

영업 종료 후 결과를 확인하고 공원으로 나간다. 몰입형 주방 화면에 남아 있다면 시스템 메뉴 또는 주방의 종료 안내로 VR을 끝낸다. 다시 공원 안을 돌아다니려면 공원 화면의 **공원 VR 시작**을 누른다.

## 5. 돌탑 점프맵을 VR로 플레이하기

공원·점프맵 VR 기능이 공개된 버전에서 진행한다.

1. 공원 VR 상태로 돌탑 점프맵 입구에 간다.
2. X로 놀이 방법을 보고 안내를 확인한다.
3. 왼쪽 스틱과 A로 첫 돌에 올라간다. 현재 로컬 규칙은 **첫 돌 착지로 도전 시작**이다.
4. 왼손 그립 달리기와 A 점프를 이용해 구간을 이동한다.
5. 마지막 연잎에 착지해 완주한다. 실패·재도전 조건은 현재 게임 안내를 따른다.
6. VR 공간의 완주 결과·랭킹을 확인한다.
7. 레이저/트리거 또는 안내된 A 조작으로 계속하기를 누르고 공원 이동으로 돌아간다.

A로 안내를 넘길 때는 버튼을 뗀 뒤 다시 누른다. 화면이 닫힌 직후 의도치 않게 점프하지 않도록 처음에는 스틱을 중앙에 둔다. 보상이 “확인 중”이면 확정 지급으로 생각하지 말고 결과가 갱신되는지 확인한다.

## 6. 다른 장소에 있는 친구도 가능한가요?

각자의 기기에서 인터넷으로 같은 개발 사이트에 접속할 수 있으면 된다. 일반 HTTPS 접속은 같은 Wi-Fi·개발자 PC·USB를 공유할 필요가 없다. 접속 지역/네트워크/서비스 참여 제한이 있으면 주최자의 안내를 따른다.

꼬치왕의 두 사람은 **같은 환경 + 같은 채널 + 같은 협동 방 + 서로 다른 역할**을 맞춰야 한다. 같은 URL만 열고 서로 다른 채널에 들어가면 같은 방을 찾지 못할 수 있다.

모든 기기 지원과 무제한 동시 접속을 보장하는 뜻은 아니다. 초기 공개는 검증된 기기·브라우저와 주최자가 정한 테스트 규모를 기준으로 한다.

## 7. 막혔을 때 바로 확인할 것

| 문제 | 해결 순서 |
| --- | --- |
| 사이트 자체가 안 열림 | Wi-Fi·개발 주소·개발 서버 점검 공지 확인 |
| 공원 VR 시작이 안 보임 | 주최자에게 VR 배포 버전 확인 → Quest 기본 브라우저·업데이트 확인 |
| VR 시작이 회색 | 로그인·채널 입장 완료 → 열린 창·다른 게임 종료 |
| 큰 평면 창만 보임 | 사이트 안의 VR 시작 버튼을 눌렀는지 확인 |
| VR 권한 거절 후 안 됨 | 브라우저의 해당 사이트 권한을 확인하고 재시도 |
| Meta 검토를 거치지 않았다는 안내 | 주소·내용 확인 후 본인이 진행 여부 선택. APK 설치나 개발자 모드 설정으로 바꾸지 않음 |
| 스틱/A가 안 먹음 | 양손 연결·배터리 → 스틱 중앙/버튼 해제 → 추적/포커스 확인 |
| 눈높이가 이상함 | 기기의 바닥·플레이 경계·시점 재설정 확인 후 VR 재진입 |
| 친구의 가게가 없음 | 같은 개발 환경·채널인지, 가게가 대기 중이고 정원이 남았는지 확인 |
| 요리사가 준비할 수 없음 | 역할이 요리사인지, VR 방식 선택과 실제 주방 VR 연결을 마쳤는지 확인 |
| 점프맵 결과가 공간에 안 보임 | 주최자에게 점프맵 VR UI의 배포/검수 여부 문의 |
| 로컬 주소를 받았는데 안 열림 | 개발자에게 공개 HTTPS 개발 URL을 요청. 내 localhost는 다른 사람 PC가 아님 |

인증서 경고를 무시하거나 브라우저 보안을 끄는 방법으로 해결하지 않는다. VR 콘텐츠 안내와 인증서 오류는 다르다. 기기 계정 문제라면 게임 계정을 바꾸기 전에 기기 관리자에게 확인한다.

### 문의할 때 전달하면 좋은 내용

- 접속 URL과 발생 시각.
- Quest 모델·OS/브라우저 버전.
- 로그인·채널·방 입장·VR 시작 중 어느 단계인지.
- 오류 문구 그대로 또는 해당 화면.
- 공원/꼬치왕/점프맵 중 어떤 모드인지.
- 양손 컨트롤러 상태와 PC 친구 쪽 연결 여부.

비밀번호·로그인 토큰·인증 코드는 전달하지 않는다.

## 주최자가 복사해서 보내는 초대문

아래 문장은 **테스트 공개 확인표와 Quest 실기기 검수가 끝난 뒤** 사용한다.

~~~text
OnTop Quest VR 개발 테스트 안내

접속 주소: https://dev.on-top.world/park
환경: 개발 서버
검증 버전/날짜: [주최자가 입력]
지원 확인 기기: [주최자가 입력]
만날 채널: [주최자가 입력]
만날 가게: [방 생성 뒤 안내]
문의 방법: [주최자가 입력]

Quest 기본 브라우저에서 접속해 OnTop 계정으로 로그인해 주세요.
공원 입장 뒤 '공원 VR 시작'을 눌러 주세요.
개발자 모드·USB 연결·별도 앱 설치는 필요하지 않습니다.

기본 조작: 왼쪽 스틱 이동 / A 점프 / 오른쪽 스틱 회전 / B 공원 VR 종료
꼬치왕: Quest는 VR 요리사, PC 친구는 서빙 담당을 고릅니다.
PC 친구도 같은 개발 주소·같은 채널에서 서로 다른 게임 계정으로 접속합니다.
~~~

## 안내의 확인 범위

이 문서는 2026-11-04 최신 origin/dev의 협동 UI와 feat/quest-vr에 이관한 로컬 공원·점프맵 XR 소스를 대조해 작성한 사용자 안내다. **다른 사람의 Quest에서 접속 성공이나 공개 개발 사이트의 VR 배포 완료를 직접 확인한 문서는 아니다.** 공개 전 주최자가 상단 확인표를 갱신한다.

Meta 계정 안내는 [Meta 공식 FAQ](https://developers.meta.com/vr/faqs/), WebXR 진입 조건은 [MDN 공식 문서](https://developer.mozilla.org/en-US/docs/Web/API/WebXR_Device_API/Startup_and_shutdown)를 참고했다. 개발자 설정·ADB·원격 디버깅·배포 준비의 자세한 절차는 [개발자 가이드](QUEST2_DEVELOPER_GUIDE.md)에 모았다.
