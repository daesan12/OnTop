## 1. 생성 데이터 로딩과 정책 전달

## 2. 가구 통과·올라타기 차단

- `physics.furniturePolicy`: `kind=no-climb`, `movementHeight=2.5`, `landing=slide-out`, `landingHeightTolerance=0.12`, `exitGap=0.03`.
- 기존 `table-N-top`, `table-N-chair-[0-3]` box ID와 게임별 의자 활성화 규칙을 유지합니다. 캐릭터 반경/충돌 여백은 형상에 미리 넣지 않았습니다.
- 걸어서 통과하거나 점프로 올라설 수 없게 하고, 높은 곳에서 떨어지거나 내부 좌표로 복구돼도 보이지 않는 차단 기둥 위에 서 있지 않게 합니다.
- FE 참조: `frontend/src/network/furnitureLanding.ts`. 발이 box 상단+0.12m보다 높거나 머리가 box 하단보다 낮으면 제외하고, 나머지 수직 중첩에 대해 box의 로컬 X/Z에서 캐릭터 반경을 한 번 적용한 경계 밖으로 밀어냅니다. 비활성 의자는 제외합니다.
- 밀려난 프레임의 grounded를 해제합니다. **차단 기둥 모서리의 잔여 접촉이 지지를 재생성해 공중 정지하지 않도록** `furnitureAllowsSupport`와 같은 지지 제외 처리가 필요합니다. FE는 발이 하단+0.12m보다 높고 상단+0.12m 이하이며, 수평 거리가 각 half extent+캐릭터 반경+2×exitGap 안쪽인 접촉을 지지로 인정하지 않습니다. 바닥까지는 중력이 계속 적용됩니다.
- 앉기/퇴장은 기존 좌석 및 서버 lease를 사용합니다. 2인/4인 전환, 비활성 좌석 자리, 퇴장 좌표가 새 차단 형상 때문에 막히지 않는지도 확인해 주세요.
- 내부 복구나 낙하 후 큰 수평 보정은 서버가 검증된 형상으로 안전 좌표를 먼저 확정하는 방식으로 처리합니다. 클라이언트의 임의 큰 이동을 허용하는 예외를 추가하라는 요청은 아닙니다.

## 3. 분수대 진입·정착 차단

- `fountain-basin` hull ID는 유지합니다. 외형 하부 반경 6.588m(5.4×1.22), bottom=-1.1m, top=2.5m의 원형 이동 차단 기둥입니다.
- `physics.fountainPolicy`: `kind=no-climb`, `shape=cylinder`, `landing=slide-out`, `exitGap=0.03`, `characterRadiusIncluded=false`.
- 발 높이가 top+0.12 이하, 머리 높이가 bottom 이상이고 중심 거리가 radius+캐릭터 반경+exitGap보다 작으면 수평 바깥으로 밀어냅니다. 정확히 중심이면 남쪽(+Z)으로 이동합니다. 보정 프레임의 grounded를 해제합니다.
- FE 참조: `frontend/src/network/fountainExclusion.ts`. 주변 내려가는 광장·계단·벤치와 분수 외형은 변경하지 않습니다.

## 4. 최신 이동 프로필과 점프 동기화

- 최신 dev의 `PARK_V1` 선택과 기존 이동 연속성 개선을 보존해 주세요. FE의 가구·분수 차단은 **일반 이동과 `PARK_V1` 두 경로 모두** 적용됩니다.
- `PARK_V1`의 일반 지면 jumpSpeed=8, gravity=30과 프로필 선택을 유지합니다. **팔각정 바닥 위에서만 `physics.pavilionTunedJumpSpeed=8.6`을 적용**합니다. 기본 높이로는 1.22m 난간을 넘지 못해 필요한 구간별 보정입니다. 아래와 같은 팔각정 바닥 조건을 사용하고, 프로필의 중력·일반 지면·계단·최신 점프맵 규칙은 유지합니다. BE에서도 권위 이동과 위치 검증에 같은 구간별 값을 연결해 주세요.
- 프로필 없는 일반 이동 경로에서는 팔각정 바닥에 한정해 `physics.pavilionJumpSpeed=7.8`을 사용합니다. FE 조건은 발 높이와 floor 차이 <0.15m, 팔각정 중심 거리 <4.5×scale+0.3m입니다. 이 경로를 서버에서도 사용하는 경우 권위 이동과 위치 검증 모두 같은 정책이 필요합니다.
- 난간은 기존 1.22m의 유한 높이입니다. 걷기는 막고 점프로 넘을 수 있어야 합니다. 탁자·의자는 넘거나 올라설 수 없습니다.
- 최신 점프맵의 코요테·입력 버퍼·서버 상태·보상/지갑·재접속 계약은 유지합니다. 점프맵 전체를 새로 작성하는 요청이 아닙니다. 기존 BE 진행 요청은 `frontend/docs/jumpmap/BE_추가요청_2026-10-30.md`를 함께 확인해 주세요.
