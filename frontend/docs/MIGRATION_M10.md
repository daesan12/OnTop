# M10 오목 화면 이관

기준: 2026-10-24. M09 커밋 `29a5dd4` 위에서 작업하며 기존 로그인·월드·테이블 로비·카메라·Spring HTTP/RawWS 연결을 유지한다. M11 이후의 게임 화면과 BE·배포 설정·패키지·맵·에셋 파일은 변경하지 않는다.

## 적용 범위

- 프로토타입 `GomokuBoard.tsx`의 교차점 미리보기·마지막 수 표시를 기존 `OmokBoard.tsx`에 맞춘다. 기존 15×15 격자·판 높이·스케일·가구·돌 인스턴스는 유지하며 장식 에셋 전체를 교체하지 않는다.
- 본인 차례의 빈 교차점 위에서만 반투명 돌과 표시 원을 보여준다. 마우스 이동은 ref로 처리한다. 클릭 전에는 판·버전·착수 수를 바꾸지 않는다.
- 왼쪽 버튼을 누른 교차점과 뗀 교차점, 경기 ID와 버전이 모두 일치하고 기존 `canPlace()`와 카메라 준비 검사를 통과한 경우에만 기존 착수 명령을 보낸다. 우클릭·드래그·상대 차례·관전자·대기/복구·시간 만료·응답 대기에는 입력하지 않는다.
- 서버 `lastMove`를 3D 원, 접근성 판의 테두리/`aria-current`, 행·열 문구로 함께 표시한다. 0부터 시작하는 서버의 x=열/y=행을 화면에서만 1부터 표시한다.
- 본인의 승리/패배, 공개 관전의 흑/백 승리, 무승부와 종료 사유를 서버 필드로 표시한다. 관전자에게 개인 정산 대기나 기권/정산 요청 권한을 표시하지 않는다.
- 요청 중·확인 응답 뒤 최신 판 대기·응답 불명·최신 판 재조회·복구 안내는 기존 경로를 유지한다. 같은 수를 자동 재전송하지 않는다. 카운트다운이 0이면 입력을 막고 서버 종료 판정을 기다리며 로컬 시간패를 만들지 않는다.
- 기존 착석 1인칭, 자기 차례 보조 탑뷰, 관전 판/테이블 시점, 결과 뒤 좌석 유지와 M09 다음 판 표시 흐름을 유지한다.

## 실제 BE 계약 우선

프로토타입 문서는 자유룰·턴 제한 없음이지만 현 프로젝트의 `docs/omok.md`와 Java 구현은 **렌주·한 수 30초**다. 현재 기능을 유지하기 위해 흑 33/44/장목 금수, 흑 정확히 5목·백 5개 이상 승리, 기존 마감 시각을 유지한다. FE에 금수·승리·무승부 판정 엔진을 복제하지 않는다.

| 기능 | 기존 연결 | 처리 원칙 |
| --- | --- | --- |
| 착수 | `GAME_ACTION_SEND {gameId, actionId, expectedVersion, input:{x,y}}` | 기존 인증 소켓 하나, 서버 승인 경기·버전 사용 |
| 확인/공개 판 | `GAME_ACTION_RESULT`, `GAME_STATE`, `GAME_STATE_CHECK` | 확인 응답을 돌로 취급하지 않음. 낮은 버전·다른 경기는 기존 store에서 폐기 |
| 금수·오류 | 기존 `GAME_ACTION_*` / `ERROR` | 서버 거절 유지. 금수 후 같은 마감 안에 재착수, 상태 불명 시 조회 |
| 단절·복구 | `GAME_RECONNECT_CHECK` / `GAME_CONNECTION_STATE` | 같은 판/마감 복원. 임의 턴 시간 초기화 없음 |
| 공개 관전 | 기존 `GAME_WATCH` / `GAME_STATE` / `GAME_UNWATCH` | 공개 상태만 표시하고 착수·개인 결과 요청 금지 |
| 결과·정산 | 기존 `GAME_RESULT_CHECK` / `GAME_RESULT` | 실제 결과 표시만. 지갑·지급·SETTLED를 로컬에서 생성하지 않음 |

## 없는 BE 기능만 분리

현재 `TableProtocol`과 `OmokMatch.apply()`에는 공개 수동 기권 명령이 없다. 접속 단절 만료의 내부 FORFEIT는 사용자가 누르는 기권 API와 다르다.

- `game/surrender.ts`는 FE 내부 포트이며 REST/WS 명세 제안이 아니다. 일반 개발·운영은 `unavailable`, 기권 버튼은 연결 준비 안내와 함께 비활성화한다.
- `DEV && MODE === 'facility-preview'`에서만 `game/mock/MockSurrenderService.ts`와 `OmokSurrender`의 목업 안내·의사 확인/계속 두기 UI를 사용한다.
- 이 목업은 **기권 의사 확인의 미리보기만** 반환한다. 기존 경기 store·돌·차례·승패·좌석·지갑에 쓰지 않고 요청을 서버로 보내지 않는다. 실제 게임은 계속되며 일반 환경의 서버 오류를 목업 성공으로 바꾸지 않는다.
- 실제 기권 연결에는 BE의 요청 명령·진행 단계/대상·중복 처리·종료/정산·취소 가능 여부 계약이 필요하다. 임의 명령·TABLE_LEAVE·연결 끊기로 대체하지 않는다.
- M09의 공개 경기 ID 공급 계약은 여전히 미연결이다. 기존 공개 참조 미리보기 포트와 실제 GAME_WATCH 권한 검사를 유지한다. 개발 서버의 TABLE_OUT_OF_RANGE 원인/설정 확인은 보류 상태이며 우회하지 않는다.

## 실행·검증 범위

일반 실행은 기존 `pnpm dev`, 기권 미리보기는 `pnpm dev:facilities`를 사용한다. 로그인·기존 서버 연결은 그대로 필요하며 별도 목업 입장 화면은 추가하지 않는다.

Browser plugin not available. 기존 Playwright/Edge를 사용했다. 검사 흐름은 `/park` → 실제 로비 명령 경로로 착석/오목 → 교차점/접근성 판 착수 → 확인 대기·거절/재조회·복구 → 서버 종료/결과와 공개 관전이다. 데스크톱 1920×1080/1280×720과 오목 패널 390×844를 확인하며 모바일 전체 서비스 지원이나 성능 개선을 주장하지 않는다.

검증 명령:

```sh
pnpm typecheck:tests
pnpm test
pnpm build
pnpm check:migration
pnpm exec playwright test tests/e2e/omok.spec.ts tests/e2e/omok-migration.spec.ts tests/e2e/table-lobby.spec.ts tests/e2e/park.spec.ts
pnpm test:e2e:facilities
```

기존 Java 코드 검증은 `backend/`에서 Java 21로 다음을 실행한다. BE 소스 수정은 없다.

```sh
./gradlew test --tests com.ssafy.ontop.table.OmokFlowTests --tests com.ssafy.ontop.game.omok.OmokBoardTests --tests com.ssafy.ontop.game.omok.OmokEngineTests --tests com.ssafy.ontop.game.omok.domain.RenjuRulesTests
```

실제 화면과 BE 엔진의 추가 검증에는 기존 테스트 클래스패스의 `omokDemo`를 `127.0.0.1:18081`로 실행하고 Edge 독립 세션 흑101·백202·관전자505를 연결했다. 새 React 공원의 기존 소켓/파서/store/착수 포트와 실제 Java 엔진·RawWS를 사용해 9수 후 흑 5목 승리, 세 판·마지막 수 일치, 흑 승리/백 패배/관전 흑 승리, 종료 후 입력 차단과 관전 종료를 확인했다.

2026-10-24 최종 검증: 타입 검사, FE 단위 24개 파일/168개, 일반 모드 회귀 21개, M01~M10 전용 시설 미리보기 28개, 기존 Java 오목 규칙/소켓 46개, 추가 React+Java 3세션 시나리오 1개, 운영 빌드·목업 제외 검사 모두 통과했다. 실제 BE 화면 확인 뒤 관전자의 불필요한 개인 정산 안내를 제거하고 영향받는 일반 오목 5개와 전용 시설 미리보기 28개를 최종 코드로 다시 검증했다. 검증 집합은 위 범위이며 저장소의 모든 E2E나 개발 서버 배포 검수라는 뜻은 아니다.

마지막 스크린샷 검수에서 관전 대역이 참가자 전용 시작/정산 단계를 잘못 보내는 것을 확인해 테스트 대역만 수정했다. M09/M10 미리보기 3개를 재실행해 오류 안내 없이 통과했다. 변경 범위는 M10 관련 프론트 17개 파일이며 원본 혼합 작업 폴더의 144개 변경 파일·HEAD·변경 목록 보존을 확인했다. 이 단계에서는 새 커밋·푸시·머지·배포를 하지 않았다.

이 추가 검증의 인증·사용자 프로필·테이블 목록·내부 경기 생성은 테스트 대역이며, 관전 참조는 M09 미리보기 포트로 제공한다. 실제 로그인 계정·전원 준비에 따른 참가 차감·DB 정산·개발 서버 배포를 완료했다는 의미가 아니다. 어댑터·증빙·실행 설정은 Git 밖 QA 디렉터리에만 보관하며 제품/BE에 테스트 인증 코드를 넣지 않았다. 검증 뒤 이번 테스트 서버만 종료했다.

돌 geometry/material을 공유하고 인스턴싱하며 미리보기는 기존 돌 geometry를 재사용한다. 격자/표시 원의 자원 수명은 R3F/기존 dispose 흐름을 따른다. 새 파일형 에셋이나 텍스처는 없으며 KTX2/Meshopt·다인원 FPS·최적화 완료를 주장하지 않는다. 기존 큰 3D 청크·Three.Clock/ANGLE 경고와 PC 이외의 전체 HUD 반응형 검수는 남아 있다.
