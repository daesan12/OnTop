# M11 주사위 원본 시각 요소 보완

기준: 2026-10-24. 기존 기능과 BE 계약을 유지하는 프론트 변경이다.

## 원본과 범위

`Desktop/topgoal.zip` 및 이를 풀어둔 `Desktop/topgoal/apps/web/`의 원본을 사용한다. `features/tables/farkle/art/`, `pour.ts`, `presentation.ts`를 확인했다.

게임 규칙·인증·실제 난수·패 배분·비밀 눈·기권·정산은 현재 BE 계약을 유지한다. 원본 Colyseus 연결이나 프로토타입 상태 모델은 복사하지 않는다. 게임 선택/준비, 요청 식별자·버전, ACK/최신 상태 대기, 응답 불명·복구·시간 만료 입력 차단과 관전자 권한은 기존 경로다. 새 목업 게임 엔진·가짜 결과·API를 추가하지 않는다.

가죽 컵·안감·테두리·밴드·바느질, 목재 트레이·금속 장식·마모·보관선, 둥근 뼈색 주사위·눈금 아틀라스·접촉 음영·선택 고리와 컵 쏟기 연출을 이관했다.

원본 아틀라스는 BoxGeometry 면 순서에서 `+X=3,-X=4,+Y=1,-Y=6,+Z=2,-Z=5`다. 기존 점 메시의 면 순서와 다르므로 최종 회전을 함께 바꿨고 승인된1~6이 실제 윗면에 오르는 검사를 유지했다. 눈·확률·점수는 바꾸지 않는다.

쏟기 연출은 승인된 새 rollId 수신 후에만 재생하며 컵/주사위가 같은900ms 표시 타임라인을 샘플링한다. 키보드 굴림은 기본 컵 위치, 실제 컵을 놓은 굴림은 해당 위치를 시각 출발점으로 사용한다. 원본의 서버 rolling 단계·시간은 복제하지 않는다. 효과음은 아래 2026-10-26 보완을 따른다. BUST 때 이미 지워진 실패 눈을 만들지 않으며 기존 안내와 다음 차례를 표시한다.

## 비용과 최적화

컵의 동심 형상32→24분할, 바느질44→32개/줄, 작은 못과 주사위의 과한 분할을 줄였다. 같은 재질의 컵 테두리/밴드 geometry를 합쳤다. 원본 절차식 텍스처를 첫 사용 때 생성해 공유한다.

측정 조건은 Core Ultra9 185H/Intel Arc(ANGLE D3D11), Edge156.0.4314.42/WebGL2,1920×1080 Low(내부1280×720),16인·같은 착석1인칭·주야간·로컬 계약 HTTP/RawWS다. 워밍업 후240프레임 이상·GPU timer3표본을 수집했다. geometry 추정은 인스턴스 행렬·색 배열을 제외한다. 단일 장비 표본이며 별도 CPU 단계별 프로파일·다른 장비 FPS 보장은 없다.

## 동작 검수

기존 컵 흔들기·놓기·Esc/blur 취소, 승인된1~6 윗면, 선택·재굴림·Bank·복구·타임아웃을 확인했다. 기존6개 점 인스턴스를 제거하고 공유 눈금 geometry/material은 경기 전환 후 유지했다.

실제 React+Java의 독립 참가자101/202·관전자505로 버전29·14번째 차례까지 진행했다. 101이3,450점 대202의1,750점으로 TARGET_REACHED 승리했다. 실제 난수·재굴림·Bank·세 공개 판 일치·관전자 행동0개·페이지/콘솔 오류0개를 확인했다.

Browser plugin not available에 따라 기존 Playwright/Edge를 사용했다. 페이지 제목·실제 본문·프레임워크 오류 오버레이 없음과 조작 후 상태를 검사했다. 타입·FE 단위27개 파일/203개·빌드·이관 경계 검사도 통과했다. 커밋별 분리본의 검사 기록은 Git 밖 QA 폴더에 별도 보관한다.

Java 검수의 로그인·프로필·목록·내부 경기 생성은 테스트 대역이며 규칙·개인/공개 RawWS·복구는 실제 BE다. 공개 경기 참조는 기존 미리보기 포트다. OAuth·DB 참가금/정산·개발 서버 배포 검수는 아니다. 수동 기권·공개 gameId 공급의 기존 미연결 항목도 유지한다. 검수 뒤 자체 테스트 서버만 종료했다. Three.Clock/ANGLE·큰3D청크 경고와 좁은 화면 전체 HUD의 한계는 남는다. PC 웹 검수이며 모바일 서비스 지원을 뜻하지 않는다.

## 2026-10-26 효과음·카메라·관전 HUD

최신 dev `13fc1ff`에서 FE 표시 계층만 보완한다. 앞 절의 과거 검수 수치·미연결 목록과 구분한다.

- 원본 Web Audio 삼각파 타격음을 컵의 실제 마우스 이동 강도와 승인된 굴림의 210ms 간격에 연결한다. 사용자 조작 전에는 AudioContext를 생성하지 않는다. 음소거는 즉시 진행 중인 음을 끊고, 경기 화면 해제 시 노드와 컨텍스트를 해제한다. 80ms 간격·최대 2음으로 제한하며 숨긴 탭에서는 소리를 만들지 않는다. 소리 재생 실패가 게임 명령을 막지 않는다.
- 참가자 본인 차례에는 원본 FOV 48°, 테이블 높이 1.06 + 확대 배율 × 2.09, 좌석 방향 × 배율 × 1.15 위치로 부드럽게 전환한다. 상대 차례의 착석 시점, 주변 둘러보기, 선택적인 판 시점 고정을 제공한다. 위치·회전·FOV가 안정되기 전의 3D 컵/주사위 조작을 막는다. 기존 오목·관전 카메라 계산과 자유 시점 복원 계약을 유지한다.
- 원본 관전 HUD 스타일과 공개 점수·차례·HOT DICE/BUST/Bank·이번 굴림/보관 주사위·최종 승자를 연결한다. 관전자는 참가자 R/Q/T 단축키를 설치하지 않고 선택·굴림·기권·개인 정산 컨트롤을 받지 않는다. 공개 판/테이블 시점·설명서·음소거·재조회·관전 종료를 제공한다.

기존 Spring 공개 DICE 상태와 요청만 사용하며 BE·규칙·난수·승패·정산·의존성·잠금파일·맵·3D 에셋은 수정하지 않는다. BUST 직전 주사위 눈과 직전 Bank 금액은 현 공개 상태에 없으므로 임의 복원하지 않는다. 해당 정보를 원본처럼 추가 표시하려면 별도 BE 공개 계약 확장이 필요하다.

검증 대상은 `/park` → 착석/주사위 시작 → 자동 시점/컵·버튼 굴림/음소거 → 결과와 `/park` → 벤치 가까이 관전 → 공개 굴림/점수/종료다. Browser plugin not available에 따라 기존 Playwright/Edge, 1920×1080·1000×700 PC 창과 로컬 HTTP/RawWS 계약 대역을 사용한다. 네이티브 AudioContext/oscillator 동작·종료 해제는 확인하지만 실제 출력 장치 청음·운영 OAuth/DB 다중 사용자 통합 검증은 포함하지 않는다. 기존 큰 청크 경고는 유지된다. 캡처·실행 결과는 저장소 밖 QA 폴더에 보관한다.

최종 FE 단위56파일/535개, 테스트 타입 검사·배포 빌드·이관 경계·공백 검사를 통과했다. 브라우저는 신규7개와 기존 주사위3개, 공개 관전9개, 시점 복귀10개, 기권15개, 오목 카메라2개, 테이블 화면12개, 로비4개로 서로 다른62개를 확인했다. 마지막 HUD 간격 보완 후 관전2개를 재실행해 모두 통과했다. 신규 흐름에서 페이지/콘솔 오류·Vite 오류 오버레이가 없었고, 1000×700에서 관전 종료 버튼이 스크롤 없이 완전히 보이며 벤치 조작 영역과 겹치지 않음을 확인했다.
