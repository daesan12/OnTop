# 180m 공원 기본 배치 시안

사용자 제공 `최종배치안.png`를 위치·규모 기준으로, `최종맵.png`를 분위기 참고로 삼은 FE 검토용 시안이다.
공원 내부는 180 × 180m, 외곽 표시 범위는 약 316m다. 도로·보도·외곽 건물은 배경이며 캐릭터 이동 범위에 포함하지 않는다.

## 실행과 검토

```sh
cd frontend
pnpm dev:layout
```

`http://127.0.0.1:5201/layout-preview.html`에서 연다. 이 페이지는 `layout-preview` 개발 모드의 독립 진입점이다.
로그인, 세션 취득, 서버 요청, 게임용 WebSocket 연결을 시작하지 않는다. Vite 개발 서버의 HMR 연결만 사용한다.
기본 `/park`는 기존 서비스 맵과 프로토콜을 사용한다.
일반 서비스용 맵 설정·맵 버전·서버 데이터는 이 시안으로 덮어쓰지 않는다. 기존 맵 자동화도 실행하지 않는다.

- **조감도:** 드래그 회전, 휠 확대/축소. 다시 누르면 전체 배치 시점으로 복귀한다.
- **위에서 보기:** 북쪽을 위로 한 공원 배치를 확인한다.
- **남산 뷰:** 기존 산 능선과 남산타워가 있는 남서쪽 배경을 확인한다.
- **산책하기:** 정문 안쪽에서 시작한다. WASD/방향키 이동, Shift 빠르게 이동, 캔버스를 드래그해 시점을 돌린다.
- **시설 목록/화면 라벨:** 시설 위치를 선택해 확대하거나 산책 접근 위치로 이동한다.
- **주간/야간, 시설명:** 배치와 시야를 비교한다.

좁은 세로형 미리보기에서는 조감도/평면 시야각을 창 너비에 맞춰 전체 배치가 보이게 한다. 산책 시야각은 유지한다.

## 배치 원본과 유지한 모델

`src/map/park/definition.ts`가 시안 배치 원본이다. `src/layout-preview/layout.ts`와 `lakeLayout.ts`는 공통 결과를 재노출하는 호환 어댑터다. 미터, Y-up, 북쪽은 -Z이며 내부 경계는 X/Z ±90이다.
도면 번호 01~27은 설명용 번호다. 기존 네트워크/시설 ID로 대체하지 않는다.

일반 정자 P1~P8과 중앙 P0를 유지하며, 테이블 `table-1`~`table-16`의 ID와 좌석 앵커 데이터를 그대로 보존한다.
정자별 위치는 고정 ID 대응표에서 지정한다. 피크닉 테이블 세 곳도 삭제하지 않고 숲·쉼터에 배치한다.

기존 `TableShell`, 일반 정자 코드 가구, 중앙 정자 가구, 소리함 코드 모델, 붕어빵 카트 코드 모델,
돌탑·한옥·운동기구·분수·나선형 전망대 모델을 재사용한다. 캐릭터/GLB 파일은 수정하지 않는다.
공유 컴포넌트에는 선택적 배치/검토 콜백, 운동마당의 선택적 구역/기구/바닥, 비둘기의 선택적 서식지 입력, 하늘의 미리보기용 고정 시간과 기존 전망대 모델의 재사용 export를 추가한다. 기본값은 기존 서비스 설정을 사용한다.

생활광장 상점·응모·포토부스, 낚시 데크, 광고 위치와 식재는 형상/배치 검토 단계다. 정문은 단일 좁은 입구(개구부 5.2m)·기존 외곽 기와 담장과 연결된 목재 기둥·석재 기단·공포·곡선 기와지붕·등을 코드로 구성했다.
민속놀이실·숲 탐색·이벤트 예비지·물고기 먹이주기 등은 구역과 위치를 표시하며 새 게임/구매/낚시 기능을 추가하지 않는다.
에어벌룬은 풍선 두 개와 세로 패널을 배치하며 지상 무게추는 두지 않는다.

## 길·울타리·생활광장 보완

중앙축·좌우 정자 열·횡단로의 중심선은 직선으로 유지한다. `pathNetwork.ts`가 직선 도로들의 외곽선을 하나로 합치고 오목한 코너는 최대 3m로 여유를 채우고 볼록 모서리는 0.6m만 다듬어 포장 폭을 유지한다.
작은 잔디 틈이나 겹친 띠가 생기지 않게 교차로를 한 면으로 삼각 분할한다. `pathUnion.ts`가 숲길·전망대·외곽 순환로의 곡선 리본도 직선망과 합친다. 접점의 겹침 면과 내부 경계석을 제거하고 실제 외곽선만 포장한다.
일반 정자는 X ±24m에 열을 맞추고 북쪽 P5/P6는 Z -61m, 정문 쪽 P7/P8는 Z 74m에 둔다.
`landscapeGeometry.ts`는 이 통합 도로의 경계선을 따라 경계석을 생성하며 출입구와 다른 동선이 닿는 부분은 생략한다.
체험관·운동마당을 가로지르던 길은 구역 바깥과 열린 입구로 연결했다.

`layout.ts`의 `FENCE_COURTS`는 정자와 VR 뜰의 사각 울타리를, `ROUND_COURTS`는 운동마당의 타원형 울타리와 출입구를 지정한다. `KIOSK_FENCE_RUNS`는 소형 건물의 바로 뒤와 양옆에만 울타리를 둔다.
목재 난간·기둥·돌 기단과 미리보기 충돌 박스는 같은 `FENCE_RUNS`에서 생성한다.
중앙 정자는 남북 주출입구와 서쪽 연결 출입구를, 나머지 시설은 각 진입로에 대응한 개구부를 둔다.

생활광장은 중심 Z 42m, 70×34m의 블록 포장 안에 반지름 7.4m 원형 스폰 표시를 넣었다. 북쪽 끝 Z 25m를 유지하고 남쪽을 Z 59m까지 넓혔다.
동심원 인레이·팔방 꽃 문양·화단 4개·곡선 벤치를 추가했다. 정문에서 광장까지도 같은 블록 색·줄눈·완성 높이로 연결했다.
기존 시설 ID/모델을 유지하며 야외 돌 테이블 네 세트는 중앙 문양을 둘러싸도록 재배치한다. 새 통로를 확보하기 위해 소리함은 X -18m로, A2 광고판은 Z -13m로 길 옆에 옮겼다.
화단·벤치의 고체 영역도 미리보기 이동 검사에 반영한다. 외곽 배경 건물에는 이동/충돌 데이터를 추가하지 않는다.
상점/응모부스는 광장 서쪽 가장자리에, 포토부스는 맞은편 동쪽 가장자리에 배치한다. 건물은 기존 시안의 65~75% 크기다. 상점은 남동쪽 45도, 응모부스는 남쪽, 포토부스는 남서쪽 45도를 향한다.

## VR 구역과 호수 보완

체험관의 파란 바닥을 제거하고 기존 한옥 형상을 재사용한 VR 체험관/민속놀이 존 2동을 동향(+X)으로 배치했다. 뜰 전체에는 같은 타일 마감을 사용한다.
동쪽에는 기존 VR 석탑을 다시 배치했다. `SITES.vr`, `folk`, `vrPagoda`가 시안 위치를 지정한다.
전망대 동서남 접근로와 분수광장의 남·동·서쪽 직선 진입로, 북서 숲 연결로를 추가했다.
VR 북쪽 출입구에서 분수광장으로 이어지는 길과 서쪽 출입구를 추가했다.

분수는 기존 `ParkFountain`의 수조·물줄기·화단·동심원 석재 포장을 그대로 사용하며, 기존 `groundHeight`로 낮은 분수광장 지형을 재현한다.
외곽 배경 바닥이 공원 밑을 덮던 부분을 제거해 낮은 분수 수조와 수중 물고기를 가리지 않게 했다.
기존 `EnvironmentScene`의 하늘, `DistantLandscape`의 산 능선과 남산타워, 기존 `PlannedCity`·`CityStreets`·`ParkBoundary`를 직접 재사용한다.
기존 광고 건물 6동과 일반 건물의 모델·배치 순서·높이·화면, 도로·신호등·보도·가로등, 기와 담장의 석재·기와·막새 디테일을 유지한다.
공원 확장분에 맞춰 외곽을 10m 바깥으로 옮기고 도로/담장 길이를 180m에 맞췄다. 정문 5.2m 개구부를 제외하고 담장을 연결한다. 기본 서비스의 160m 설정은 그대로다.
시안에서만 `cornerRadius=6`을 지정한다. 외곽 도로·보도·차선은 같은 중심을 공유한 곡선 링이며, 담장 모서리는 기존 석재·기와·막새 지오메트리를 곡선에 맞춰 휘어 연속 연결한다.
내부 외곽 산책로도 반경 7m로 코너를 둥글게 잇고, 보행 경계와 담장 식재는 둥근 모서리를 따른다.
도로·건물 범위 약 316m 바깥의 먼 산/지평선도 배경이며 이동할 수 없다.

`lakeLayout.ts`의 `CROSSINGS`는 북쪽(Z -26m) 돌다리와 남쪽(Z +9m) 목교의 위치·폭을 지정한다.
`SHORE_RUNS`는 두 횡단로·낚시 데크·서/동 수영 진입부를 비운 호수 울타리이며 렌더링과 충돌 검사가 같은 구간을 쓴다.
기존 `LAKE_ROCKS` 배치를 호수 크기에 맞춰 변환하고, 바위의 회전/변형을 포함한 전체 반경에 여유를 더해 난간 안쪽으로 옮긴다. 접근로와 겹치는 바위는 제외한다.
다리 양끝은 해당 Z의 타원형 물가와 0.55~0.65m만 겹치도록 계산한다. 목교는 낮은 양끝에서 중앙이 1.85m 올라오는 아치이며, 판재·난간·곡선 하부 보와 보행 높이가 같은 프로파일을 따른다.
징검돌은 약 0.62m 두께의 비정형 석재로, 깎인 가장자리·작은 깨짐·석재 질감을 표현한다.
기존 `LakeFish` 모델/애니메이션을 새 호수 좌표로 변환해 재사용하며 연잎·연꽃·갈대와 수변 수목을 추가했다.
`layout-shore-trees` 그룹은 `plannedSpecies: willow`를 표시한 별도 수변 수목 배치다. 현재는 기본 나무이며 추후 버드나무 모델로 교체할 수 있다.
담장 안쪽 X/Z ±87.6m에는 남쪽 정문을 비우고 공원 한 바퀴에 별도의 나무 열을 추가했다.
일반 숲 식재 간격은 3.15m로 줄이고 나무별 수관 크기를 조절했다. 길·뜰·시설·광장 안에는 새 나무를 심지 않는다.

## 시설 간 동선과 비둘기

X -39m의 서쪽 직선길을 Z -76~84m로 연속 연결했다. VR 동측 입구에서 Z -8m 횡단로를 통해 중앙으로 진입한다.
운동마당은 중심 (-63,64), 가로 30m·세로 22m인 타원 공간으로 남쪽으로 옮겼다. 기구는 반지름 (11.5,7.5)m인 타원 위에서 중앙을 향하며 형상/크기/ID를 유지한다. 바닥만 타원으로 그리며 기구 모델은 늘이지 않는다.
기구별 다른 색 바닥을 없애고 전체를 같은 석재 마감으로 통일했다. 중앙에는 큰 나무와 네 방향 통행 틈이 있는 원형 벤치를 둔다.
VR 뜰은 중심 (-61,-12), 40×40m로 넓혔다. 숲길/이벤트 예비지는 중심 (-64,21), 32×26m다. 타원형 순환 광장을 없애고 도면의 나무 사이 S자 동선을 재현했다. 별도 큰 공터를 만들지 않고 기존 수목과 길 옆 벤치 두 개를 유지한다.
붕어빵 카트는 (-51,23)의 작은 둥근 모서리 석재 쉼터에 배치하고 숲길과 연결한다. 기존 카트 ID/코드 모델은 그대로다.
운동마당 동측 입구는 Z 64m에서 서쪽 종축에 연결된 뒤 Z 56m 길로 광장과 연결되고, 부스 사이 통로는 Z 43m에서 별도로 연결된다.
운동마당 바닥 판은 통행 가능한 표면으로 취급하고, 실제 기구의 충돌 박스만 차단한다.

일반 정자의 뜰/울타리는 14.5×17m로 줄였다. 중앙 정자와 양옆 정자 사이 X ±14.9m에 폭 2.6m의 통로를 두었다.
계단은 `pavilionStairJoin` 기준으로 팔각 바닥 면에 겹쳐 붙였고, 미리보기 바닥 높이도 원형 거리 대신 실제 팔각 면을 검사한다.
전망대에는 동서남북 진입과 반지름 11.5m 순환 산책로를 추가했다. 정상 데크 벤치 두 개는 원래 `TOWER_BENCH_SITES`의 상대 위치·높이·회전을 그대로 옮기고 기존 주철 프레임과 목재 슬랫으로 복원했다.

`PreviewPigeons`는 기존 `ParkPigeons` 렌더러/형상과 `createBirds`/`stepBird` 행동을 재사용한다.
광장·VR 뜰·남동쪽에 세 무리, 총 18마리를 배치했다. 새 맵의 지면/장애물과 미리보기 이동 속도를 입력해 걷기·먹이 쪼기·달려올 때 날아 피하기를 유지한다.
실서버 아바타/위치 상태를 수정하지 않는다. 기존 서비스의 비둘기는 별도 입력 없이 기존 설정으로 작동한다.
VR 점프맵/석탑은 북쪽 VR 건물 정면인 (-48,-23)으로 옮기고, 그 남쪽에 돌 책상과 의자 두 세트를 배치했다. 새 돌 가구는 장식이며 서버 착석 ID를 만들지 않는다.
VR 점프맵은 기존 24개 `VR_COURSE_PADS`의 높이·ID를 유지하며, 폭·두께·높이·회전 순서를 유지하고 반지름을 4.7m에서 5.9m로 넓혀 석탑과의 겹침을 없앴다. 발판 표면은 석탑에 어울리는 석재색이다. 기존 석탑 모델은 바꾸지 않으며 별도 돌기둥·받침 구조를 추가하지 않는다. 아래 FE 체험에서 전체 7구간을 직접 점프할 수 있다.

## 이동과 적용 범위

미리보기의 `canWalk`는 공원 경계, 기본 시설 박스와 호수, 횡단 동선, 울타리와 광장 가구를 검사한다.
`walkHeight`는 배치 검수를 위한 높이를 제공한다. 깊은 물에서는 기존 `SWIMMING` 설정의 수영 속도/깊이 기준/부유 높이를 사용하고 수면 시점과 잔물결 및 수영 상태를 표시한다.

- 점프맵은 기존 107 발판/6 문·치수·높이·반투명 규칙을 유지한다. 공유 로컬 석재/목재 색·노멀·거칠기 맵, 테마별 광택, 석재 가장자리의 작은 마모, 붕어빵 양각 비늘, 초롱 종이 결, 연의 한지 결을 더한다. 형상은 테마당 한 번 만들고 재질별 인스턴싱한다.

이번 변경도 FE 독립 미리보기에만 적용하며 BE/실서비스 맵 설정/버전/캐릭터 파일을 수정하지 않는다.

## 역할별 광장 건물·혼합 식재·분수 확대

- VR 뜰은 중심 (-63,-12), 34×40m로 안쪽으로 당긴다. VR/민속 건물은 X=-74, 점프맵 석탑은 (-53,-23)이다. 원형 석재 인레이를 제거하고 원래 공통 타일 바닥으로 되돌린다. 별도 VR_EDGE_TREE_SITES 17곳에 기존 잎 클러스터를 사용한 나무를 두며 모든 출입구/직선길을 비운다.
- 분수 수평 배율 1.22, 물줄기 수직 배율 1.65를 적용한다. 수면 높이는 고정하고 물줄기만 수면에서 늘린다. 기존 분수 모델/물방울을 사용하며 원형 바닥·잔디 구멍·주변 식재·미리보기 바닥 높이/충돌/가로등 배제 범위를 함께 조정한다. 서비스 ParkFountain의 기본값은 1이다.
- 계단 경사 난간의 프레임은 진행 방향/수평 가로축/위쪽 축으로 구성한다. 최단 쿼터니언 회전에서 발생하던 단면의 옆 기울기를 없애며, 계단 진행 방향의 필요한 경사는 유지한다.
- 정문에 남아 있던 3.1m 회색 돌기둥을 없애고 목재 문기둥을 기와 담장과 같은 Z=90에 둔다. 기와 담장의 개구부는 5.2m로 줄여 목재 기둥까지 연결한다. 남쪽 담장/정문 앞은 모서리를 따라 연속 석재 보행면으로 덮고, 남쪽 수목 아래에는 잔디 대신 금속 수목 보호대를 둔다.
- 동일한 축소 키오스크 모델을 제거한다. PlazaBuildings.tsx는 상점(9.6×7.2m 한옥·진열대·도자기), 응모부스(7.8×5m 행사 캐노피·접수대·응모함·추첨 원판·안내판), 포토부스(8.8×6.6m 스튜디오·카메라 간판·사진 스트립·출력구)를 각각 만든다. 시설 ID layout-shop/layout-drink/layout-photo와 남동향/남향/남서향을 유지한다. 역할 표현용 외형이며 새 구매/응모/촬영 API는 호출하지 않는다.
- 건물 위치는 (-29,35)/(-26,50.5)/(29,35)다. 건물 실제 폭/깊이를 기준으로 붙는 울타리와 회전된 직사각형 충돌을 계산한다. 전면 통로와 Z=43/56의 기존 연결 동선을 유지한다.
- 첨부 park_image_5.jpg처럼 광장 북쪽에 목재 플랜터 두 곳, 작은 나무·관목·큰 잎 식물·양치식물, 기존 주철/목재 벤치 네 개와 목재 휴지통 두 개를 배치한다. 남쪽의 기존 꽃 화단/벤치는 유지한다. 동선/중앙 원형 문양과 돌 좌석 주변은 비운다.
- 광장 가로등은 가장자리 우선 배치 후 건물/화단/통로와 겹치는 후보를 제외한다. 응모부스/상점/포토부스의 출입부는 별도 모델 조명을 둔다.
