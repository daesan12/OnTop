## 상태·권한

게임 상태와 표현 상태를 분리한다. `useGame`의 version·hand·playableCardIds·canDraw는 변경하지 않는다. 뒤집힌 카드의 DOM에는 앞면 텍스트·aria-label을 남기지 않는다. 선택/제출은 cardId로 유지하며 뒤집힌 카드를 클릭하면 제출 대신 전체 복구한다.

선택은 gameId/userId/version 범위로 관리한다. 요청 중에도 보호할 cardId를 유지한다. 서버 상태 갱신 후 이전 선택이 표시되지 않게 한다. 관전자에게는 privateState를 요구하지 않는다.

2026-10-29 사용자 요청 및 BE 구현 반영 후 장난 transport와 뿅망치 방어는 FE 기본 ON이다. `VITE_ONECARD_PRANKS=false`는 장난 전체, `VITE_ONECARD_PRANK_DEFENSE=false`는 방어를 명시적으로 끈다. 이는 BE 지원 여부 자동 탐지가 아니다. 실행 서버에는 대응 속성과 새 BE 이미지가 필요하며 [서버 활성화 요청](handoff/뿅망치_전체랭킹_서버활성화_요청_2026-10-29.md)을 따른다. 미지원/권한 오류는 장난만 비활성화하고 카드 게임 입력·복구 오류와 섞지 않는다. 아래 날짜별 기록의 기본 OFF는 당시 검수 조건이다.

### 후속 카드·게임판 스타일 수정

사용자 요청에 따라 설명 문장과 `cardDescription`을 제거하고 기존 `cardEffect`의 짧은 능력명만 표시한다. 일반 카드에는 문구를 넣지 않는다. 아이보리 그라데이션·금색 내부 테두리·희미한 워터마크·하단 반전 숫자/무늬로 앞면을 다듬고, 뒤집기 뒷면은 청록 격자·금색 중앙 장식으로 통일한다. 공개 카드도 같은 팔레트를 쓴다.

`game/onecard/artwork.ts`는 CanvasTexture로 펠트 질감·이중 금색 외곽선·모서리 장식·네 무늬 메달리온·카드 더미 영역을 만든다. 정적 펠트/뒷면은 원카드 최초 표시 시 한 번 생성해 재사용하고, 공개 앞면은 카드 변경/해제 시 기존 수명 관리대로 정리한다. 비공개 손패는 3D 재질에 포함하지 않는다. 공용 테이블·카메라·서버 계약은 이번 수정에서 바꾸지 않는다.

Browser plugin not available. 1920×1080·1536×1024·1280×720·390×844를 캡처했다. `/park` → 원카드 착석/준비 → J 선택 → 관전자 뒤집기 → 손패 정리로 두 장 복구, 그리고 낼 카드가 있어도 드로우 → 다음 차례 전환·모바일 손패 탐색을 확인했다. 페이지 제목·실제 경기 내용·오류 overlay 부재·console error 부재·스크린샷·상호작용 검증이 통과했다. 기존 THREE.Clock 폐기 예정/셰이더 정밀도 경고는 남는다.

### 상대가 든 손패와 간결한 HUD

`OneCardHeldHand`는 아바타의 양손 뼈 중간 위치를 추적해 공개 카드 수 기반의 뒷면 fan을 표시한다. 실제 카드 앞면·ID·무늬는 구독하지 않으며 양면 모두 공용 뒷면이다. 후속 요청에 따라 10장 제한을 제거하고 최대 54장까지 실제 공개 카드 수와 같은 수를 아바타별 instanced mesh 하나로 표시한다. 정규화된 fan 좌표로 장수가 많아져도 손 안의 범위를 벗어나지 않는다. 테이블에 누워 있던 손패 소품은 제거한다. 자신의 아바타는 본인 1인칭 화면에서 숨겨지고 관전자에게는 동일한 손패 소품이 보인다. 비활성·손패 0장·경기 종료·다른 테이블에서는 표시하지 않는다.

원카드 자세는 `heldHand.ts` 안에 둔다. 공용 `avatarMotion`에는 선택적인 앉은 자세 콜백만 추가하고, 원카드 경기 참여자에게만 주입한다. 이모트/패배 반응은 기존 우선순위를 유지하며 종료/퇴장/다른 게임에서는 기본 자세로 돌아간다. 공용 캐릭터 모델·재질을 수정하지 않는다.

좌상단 제목·규칙 한 줄, 손패 제목·강조 카드 안내, 드로우 설명, 차례·회전 방향·덱/턴 수·시간 부연 문구를 DOM에서 제거한다. 좌상단에는 `남은 시간 / N초` 타이머만 표시하고 5초 이하에서 강조한다. 서버 마감 시각을 따르며 0초에서는 기존 행동 차단을 유지한다. 무늬 선택 버튼·원카드 선언/신고·공격·복구/오류·결과/승리 등 실제 행동과 필수 상태는 유지한다.

손패의 숫자·무늬는 왼쪽 위와 오른쪽 아래를 동일 크기로 맞추고 아래는 180도 회전한다. 화면 테스트는 제목/손패/드로우 안내 부재, 아래 숫자와 회전, 남은 시간/만료 시 입력 차단, 4인 공개 장수 기반 손패와 관전자 비공개 손패 차단을 확인한다. 실제 남녀 캐릭터 리그로 얼굴 아래 손패 높이와 원카드 종료 후 기본 자세 복원을 단위 검증한다.

검증: 관련 단위 테스트 4파일 35건, 원카드 E2E 7건, 최종 손패 높이 조정 후 UI E2E 3건, 앱/테스트 타입 검사·프로덕션 빌드 통과. Browser plugin not available이므로 기존 로컬 `127.0.0.1:5213/park`의 Playwright/Edge 경로를 사용했다. 페이지 제목·경기 내용·오류 overlay/console error 부재, 선택·드로우·무늬 선택·선언/신고·0초 입력 차단·관전자 뒤집기/전체 복구를 검증했다. 4인 플레이·관전자·390×844 모바일을 캡처하고 최종 화면을 직접 확인했다. 기존 THREE.Clock/셰이더 정밀도·대용량 청크 경고는 남으며 실제 서버 관전자 계약과 다른 브라우저 공동 접속 검증은 범위 밖이다.

### 정확한 장수·공통 지도 차단·Esc 기권·마감 다듬기

- 상대 손패의 실제 인스턴스 수가 공개 장수와 같도록 10장 상한을 제거했다. 1·7·17·54장 fan이 같은 손 범위에 들어오는 단위 검증과 두 창에서 17→1→5장 증감을 확인하는 E2E를 추가했다. privateState는 계속 2D 개인 손패만 사용한다.
- `navigation/mapAccess.ts`에 네 게임에 공통인 지도 차단 정책을 둔다. `ParkMap`의 버튼·M 입력과 `openParkMap`의 직접 호출에 같은 정책을 적용하고, 게임 시작 시 지도/길 안내를 닫는다. 정상 공원 지도와 이동 경로 선택 기능은 유지한다.
- 채팅 입력란 높이를 `--chat-composer-height`로 공유한다. 접힌 전송 아이콘과 열린 입력란의 전송/닫기 버튼은 내부 높이에 맞추고 최소 크기·줄바꿈 때문에 밖으로 밀리지 않게 한다. 일반 공원은 52px, 게임의 작은 입력란은 36px다.
- 정상 플레이의 우상단 규칙/새로고침/기권 도구는 제거했다. 관전 종료·시점 변경과 오류/복구·결과 확인은 필요한 상태에만 별도 컨트롤로 유지한다. `OneCardForfeitDialog`는 body portal의 native dialog로 Esc 입력을 받고 기존 `canStartForfeit`/`canRetryForfeit`와 runtime 계약을 사용한다. 최초 포커스는 `계속 플레이`에 두고 Esc 취소 후 이전 카드 포커스를 복원한다. 채팅·IME·다른 대화상자는 Esc를 먼저 처리하며 기권은 최종 확인 클릭에서만 요청한다. 응답 유실·3인/4인 탈락 후에도 같은 actionId의 명시적 확인 경로를 제공한다. 다른 게임 기권 UI는 유지한다.
- 남은 시간 글자는 데스크톱 42px/모바일 34px로, 공개 카드 요약은 68×96px/56×80px로 확대했다. 무늬 글자도 확대하고 카드 종이 음영·금색 이중 프레임·펠트 자수/모서리 곡선과 카드 더미 영역을 다듬었다. 기존 디자인 시스템 안의 코드 재질/CSS 수정으로 구현하며 새 배경 에셋은 추가하지 않는다.

검증 흐름: 일반 공원 지도 열기/닫기 → 게임 입장 → 지도 버튼/M/직접 호출 차단 → 채팅 접힘/펼침 아이콘 경계 검사 → 채팅 Esc는 입력만 닫기 → 카드 선택 → Esc 기권 창/기본 취소 포커스 → Esc 취소/선택 보존 → 확정 두 번 클릭에도 한 번 요청 → 서버 결과 반영. 별도로 3인 원카드 기권 승인 후 receipt 유실 → 같은 요청 확인으로 추가 적용 없이 복구를 확인한다. 브라우저 테스트는 기존 mock 계약을 사용하므로 실제 관전자 BE 배포 완료를 의미하지 않는다.

### 개인 손패 높이 조정

후속 요청에 따라 손패 영역의 높이를 데스크톱 `clamp(36px, 6dvh, 64px)`, 모바일 36px 늘려 카드와 묶음 탐색을 위로 올린다. 하단 제출·드로우·정리 버튼은 기존 위치를 유지한다. 선택·hover의 추가 들어올림과 카드 뒤집기는 기존 변환을 유지한다. 손패 장수 규칙은 기존 기획/서버 판정을 유지하며 이번 변경은 원카드 전용 CSS 배치만 조정한다.

검증: 로컬 Playwright/Edge에서 4인·선택/드로우·뒤집기/복구·관전자 E2E 3건과 Vite 빌드가 통과했다. 1920×1080·1536×1024·1280×720·390×844를 캡처하고 데스크톱·낮은 화면·모바일의 최종 배치를 직접 확인했다. 카드·버튼의 겹침이나 잘림은 없고 기존 페이지/콘솔 오류 검증도 통과했다.

### 관전자·플레이어 두 창 수동 검수

`onecard-four-player.spec.ts`의 수동 검수 모드는 실제 FE 두 창에 공유 mock 이벤트 전송 계층을 연결한다. 4인 경기의 플레이어 도윤과 별도 관전자 구경꾼으로 입장한 뒤 창을 유지하며, 두 창을 모두 닫으면 종료한다. 운영 BE 연결이 아니며 일반 브라우저에서 URL만 열어 같은 시연에 입장할 수 없다.

`frontend` 디렉터리에서 PowerShell로 실행한다.

```powershell
$env:ONECARD_INTERACTIVE_PREVIEW='true'
node node_modules/@playwright/test/cli.js test --config playwright.onecard.config.ts onecard-four-player.spec.ts --headed --timeout 0
```

관전자 창에서 도윤이 들고 있는 손패 영역을 직접 누른 뒤 플레이어 창에서 선택한 J가 유지되고 다른 2장만 뒤집히는지 확인한다. 뒤집힌 카드 또는 `손패 정리 · 2장 복구` 한 번으로 전체 복구한다. 같은 차례 재개입은 막히고 관전자는 카드 앞면을 받지 않는다. 검수 중 타이머는 고정하며 일반 제출·드로우는 시연 범위를 알리는 오류 응답으로 거절해 창과 연결을 유지한다. 수동 모드를 끄면 기존 자동 E2E가 실행된다. 별도 서버가 필요하면 `ONECARD_PREVIEW_PORT`로 포트를 지정한다.

원카드 관전은 높은 대각 시점을 사용하고 기존 벤치 시점 전환 버튼은 숨긴다. 우상단 관전 종료 버튼 또는 Esc로 종료하며 승인되면 벤치로 돌아온다. 중앙 안내 패널은 제거하고 손패의 실제 투영 위치에 최소 46px 선택 영역을 배치한다. 복구 캡처는 Y축 회전이 끝난 뒤 촬영해 모든 카드가 돌아온 상태를 확인한다. 수동 검수의 시간 고정은 `Date.now`만 바꿔 Three.js의 `performance.now` 기반 렌더링과 카메라 보간을 유지한다.

Browser plugin not available이므로 기존 프로젝트 Playwright 경로를 사용했다. 1920×1080·1280×800·390×844에서 페이지 내용·오류 overlay 부재·콘솔 오류 부재와 실제 조작을 확인했다. 비합법 카드 hover·일반 카드 안내 생략·뒤집힘 시 능력 DOM 제거·조커별 +7/+5·버튼/키보드 기권·취소 시 선택 유지·중복 기권 차단·복구·승인 후 타격의 시간별 transform 변화와 잔상 제거·터치 드래그/모션 줄이기를 검증했다. 검수 중 발견한 타격/차단 피드백 key 중복을 고쳤다. 실제 다중 계정 서버 검수와 운영 플래그 활성화는 포함하지 않으며 기존 Three.js/번들 크기 경고는 남는다.

### 2026-10-29 관전 직접 선택·경기 채팅 공통 정책

원카드 관전에는 실제 3D 손패만 표시한다. 확대된 2D 손패·부채꼴·네모 선택 영역을 제거하고 `OneCardHeldHand`의 instancedMesh에서 가장 앞에 보이는 instanceId를 직접 선택한다. 캐릭터 몸에 가린 카드를 클릭하지 않으며 겹친 뒷면은 가장 앞 카드만 처리한다. 선택 강조는 실제 카드 크기의 3D 윤곽선으로 제한하고 카드 위치와 크기를 바꾸지 않는다. 실제 손에 들린 카드 수는 공개 장수와 동일하다. `OneCardSpectatorHands`는 화면 하단의 작은 상태 문구와 화면 읽기/키보드 접근만 제공한다. 참가자별 손패에 진입한 뒤 좌우/Home/End로 탐색하고 Enter/Space로 해당 위치를 선택한다. 현재 차례의 손패를 보기 쉬운 방향을 기본 관전 시점으로 사용하고, 빈 공간을 드래그해 가려진 손패를 확인한다. 손은 캐릭터가 실제로 카드를 잡은 채 얼굴/테이블에 묻히지 않도록 배치한다. 공개 카드 위치와 화면 버전 API를 재사용하며 선택·제출 보호, 복구·면역·방어 규칙을 유지한다. 포인터 소유권은 공통 입력 계층에 두어 카드 선택과 시점 회전을 분리하고, pointerup/cancel·blur·화면 변경에 정리한다.

지도·옷장 잠금은 공통 `gameplayLock`, Esc 종료는 공통 `SpectatorExit`, 채팅 전환은 `gameChatScope`로 네 게임에 적용한다. 입력 중 Esc는 채팅부터 닫고 다음 Esc로 관전을 해제한다. 해제 승인을 받으면 벤치로 복귀한다. 경기 시작 대기에는 채팅 전송을 막고 현재 경기 승인 후 전용 메시지를 사용한다. 기존 오목 이벤트 계층을 재사용하되 채팅 권한 범위를 네 게임으로 확장했다. 경기별 접속 중 이력 100개와 짧은 말풍선을 분리하고 경기·역할·채널 변경/관전 해제 때 초기화한다. WORLD 메시지로 대체하지 않는다. BE도 같은 경기의 참가자·승인 관전자에게만 전달하며 진행 중 WORLD 전송 우회를 거절한다. [공통 채팅 계약](../../docs/websocket-api/10-game-spectator-events.md)을 함께 배포해야 한다.

검증: 로컬 `/park`, Playwright/Edge(브라우저 플러그인 미제공), 1920×1080 플레이어·1280×800 관전자·390×844 관전자 화면을 사용했다. 4게임 관전 정책 4건, 4인 두 창 직접 선택/복구/경기 채팅 1건, 기권·툴팁·아이콘 3건, 방어 2건으로 관련 E2E 총 10개가 통과했다. 페이지 제목·본문·오류 overlay 부재·페이지/콘솔 오류 부재, 실제 카드 장수, 비차례 선택 시 무전송, 비공개 패 수신 부재, 경기 채팅 양 창 표시/WORLD 무전송, Esc 종료 후 이력 제거를 확인했다. 관련 단위 테스트 42건, BE WebSocket 통합 10건, 타입 검사·프로덕션 빌드도 통과했다. 실제 배포 서버의 다중 계정 검수는 포함하지 않으며 기존 Three.js 경고와 번들 크기 경고는 남는다.

### 카드 한 장 지정 후속 검증

카드를 누르면 `cardIndex`(0 기반 공개 위치)와 `handVersion`을 함께 보내 해당 한 장만 뒤집는다. 서버가 실제 장수와 버전을 검증하며 방어 대기 중 버전이 바뀌면 취소한다. 플레이어는 승인 이벤트의 위치를 같은 버전의 본인 손패에 대응하고, 선택/제출 중인 카드면 다른 카드로 대체하지 않고 즉시 복구한다. 기존 대상/턴/면역/방어 제한은 유지한다. 구형 위치 미지정 요청은 기존 최대 2장 동작을 유지한다. 새 FE는 항상 위치와 버전을 보내므로 FE·BE 함께 배포한다.

검증: 관련 단위 테스트 27개, BE 단위/프로토콜/WebSocket 통합 18개, 브라우저 E2E 3개 및 테스트 타입 검사·Vite 빌드 통과. 로컬 Playwright/Edge 1920×1080 플레이어·1280×800 관전자·390×844 관전자에서 세 번째 카드 선택→해당 K 한 장만 뒤집힘→한 번에 복구, 선택 K 보호/뿅망치 방어, 17번째 카드 탐색, 비차례 카드 선택 시 무전송, 모바일 카드 버튼 간 겹침 부재, 카드 포커스 중 Esc 종료를 검증했다. 잘못된 위치/오래된 버전/불완전한 필드 쌍/중복 eventId의 선택 변경도 검사했다. 페이지/콘솔 오류는 없었으며 기존 Three.js 경고와 번들 크기 경고는 남는다. 배포 서버 검수는 포함하지 않는다.

### 전체 손패 부채꼴 검증 기록 (이후 3D 직접 선택으로 대체)

세 장씩 넘기는 방식은 제거했다. 실제 손패 1/3/4/5/7/17/39장에 대한 전체 카드 버튼 개수를 확인하고, 17번째·39번째 카드를 페이지 이동 없이 직접 선택했다. 기존 두 창 흐름에서 도윤의 세 번째 카드만 뒤집히고 선택한 J는 보호되며 한 번에 복구됨을 확인했다. 390×844에서는 네 손패 그룹의 겹침/화면 이탈이 없고, 실제 터치 탭 및 touchStart→touchMove→touchEnd로 다섯 번째 카드에서 두 번째 카드로 이동해 선택하는 동작을 검증했다. 모바일 17장 캡처와 카드 포커스 중 Esc 종료도 확인했다. 로컬 Playwright/Edge E2E 3개(4인 1·방어 2), 테스트 타입 검사와 Vite 빌드가 통과했다. Browser plugin not available로 기존 Playwright 경로를 사용했고 페이지/콘솔 오류는 없었다. 기존 Three.js 및 번들 크기 경고는 남는다. 이번 표시 방식 수정은 기존 카드 위치·버전 API를 재사용한다.

### 실제 3D 손패 직접 선택 최종 검증

사용자 정정에 따라 큰 2D 카드 UI와 해당 카드 뒷면 SVG를 제거했다. 자동 검증은 2D 버튼을 클릭하는 대신 실제 3D 카드 인스턴스 표면을 투영하고, 다른 카드/몸에 가리지 않은 실제 픽셀을 찾아 캔버스에 마우스/터치 이벤트를 보낸다. 카메라가 멈춘 후 검증하고, 가려진 손패는 실제 빈 공간 드래그로 회전해 확인한다. 1/3/4/5/7/17/39장 유지, 실제 세 번째 카드만 뒤집기, J 선택 보호, 한 번에 복구, 비차례 카드 무전송, 실제 3D 손패에서 방어 시도/타격/차단 만료, 모바일 네 참가자 카드 접근과 17번째 카드 터치, 비공개 손패 미수신, Esc 종료를 확인했다. 겹친 인스턴스의 중복 클릭과 카메라 드래그 충돌을 수정했으며 선택 중 카드 자체를 움직이지 않아 클릭 위치를 안정적으로 유지한다.

로컬 Playwright/Edge 1920×1080 플레이어·1280×800 관전자·390×844 관전자에서 관련 E2E 3개, 단위 테스트 27개, 테스트 타입 검사 및 Vite 빌드가 통과했다. 페이지/콘솔 오류는 없고 기존 Three.js/번들 경고는 남는다. Browser plugin not available이므로 기존 Playwright 경로를 사용했다. 실제 운영 서버·계정 검수는 포함하지 않는다.

공통 입력 회귀도 추가 확인했다. 오목/원카드/주사위/브리지 관전 정책 4개와 원카드 기권·툴팁·아이콘 컨트롤 3개가 통과해 이번 최종 검증의 관련 E2E는 총 10개다. 카드별 포인터 소유권 정리는 키보드·채팅 소유권과 분리했고, 다른 게임에서는 기존 조작을 유지한다.
