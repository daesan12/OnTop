## 상태·권한

게임 상태와 표현 상태를 분리한다. `useGame`의 version·hand·playableCardIds·canDraw는 변경하지 않는다. 뒤집힌 카드의 DOM에는 앞면 텍스트·aria-label을 남기지 않는다. 선택/제출은 cardId로 유지하며 뒤집힌 카드를 클릭하면 제출 대신 전체 복구한다.

선택은 gameId/userId/version 범위로 관리한다. 요청 중에도 보호할 cardId를 유지한다. 서버 상태 갱신 후 이전 선택이 표시되지 않게 한다. 관전자에게는 privateState를 요구하지 않는다.

장난 transport는 `VITE_ONECARD_PRANKS=true`일 때만 활성화한다. 기본값 false. 이는 BE 지원 여부 자동 탐지가 아니다. 운영 활성화는 BE 계약 확정·서버 배포·다중 계정 검수 이후에 한다. 미지원/권한 오류는 장난만 비활성화하고 카드 게임 입력·복구 오류와 섞지 않는다.

## UX 검수

1920×1080·1280×720·390×844에서 손패·제출·드로우·정리 접근을 확인한다. 전 좌석 카메라 수치는 단위 테스트하며 실제 장면에서 어깨/테이블 가림을 검수한다. reduced-motion에서는 회전·들어올림 전환을 제거한다. 54장 탐색, 마지막 한 장, 무늬 선택, 공격 누적, 기권·복구·오래된 버전 차단을 확인한다.

## 로컬 구현·검증 기록

구현: 어깨 카메라·내 아바타 표시, 부채꼴 손패·묶음 탐색·선택 강조·전략 드로우 유지, 머리 위 공개 장수, 준비용 소품, 장난 제안 계약 어댑터와 한 번 복구를 반영했다. BE는 이번 작업에서 수정하지 않았다. 장난 기본 비활성 조건은 위와 같다.

- 타입 검사: 앱 및 테스트 TypeScript 통과. 프로덕션 `tsc` + Vite build 통과.
- 단위 테스트: 원카드 규칙/표현/장난, 오목 카메라, 아바타 모션/투명도, 카메라 복귀, 로비 런타임 7개 파일·57개 통과.
- 브라우저: 전용 `http://127.0.0.1:5213/park`. Browser 플러그인이 제공되지 않아 프로젝트 Playwright + headless Edge 사용. 2·3·4인, 공격/K/무늬/선언/신고, 버전 불일치/복구, 플레이어 뒤집기/복구/전략 드로우, 승인 관전자 전송/손패 비노출/관전 종료를 검증했다.
- 화면: 1920×1080, 시안 원본 크기 1536×1024, 1280×720, 390×844. `page.screenshot` 캡처 후 `view_image`로 시안과 구현을 직접 대조했다.
- 확인 경로: 합법 카드 선택 → 선택 카드 보호 상태에서 2장 뒤집기 → 앞면 DOM·접근성 이름 미노출 → 손패 정리 한 번으로 전부 복구 → 선택 유지 → 합법 카드가 있어도 드로우 → 상대 턴. 좁은 화면에서 다음 묶음과 필수 버튼의 화면 내 배치 확인.
- 페이지 제목·경기 내용·Vite 오류 오버레이·브라우저 런타임/console error 확인. 기존 Three.Clock 폐기 예정 안내/일부 GPU 정밀도 경고와 기존 대형 번들 경고는 별도 공통 렌더러/빌드 항목이며 이번 원카드 실행 실패는 아니다.

상단 문구 대조: 새 마케팅 문구를 추가하지 않았다. 기존 ‘원카드’, 규칙·최신 확인·기권을 유지하고 공개 카드/현재 무늬 요약을 상단 중앙에 둔다. 필수 기존 안내와 선택 카드명 버튼 등 시안과의 의도적 차이는 [시안 설명](../../docs/design/onecard/README.md)에 기록했다. 전체 장면은 기존 에셋을 사용하므로 시안의 사실적 인물과 동일한 렌더링을 의미하지 않는다.

남은 검수: BE 계약 확정·실서버 동시 관전자 한도·재접속 면역 동기화, 다중 계정 공동 검수. 네 좌석 수식은 검증했으나 실제 여러 사용자/모든 공원 테이블의 그래픽 검수는 별도다.

실행: 작업 폴더 `frontend`에서 `node node_modules/@playwright/test/cli.js test --config playwright.onecard.config.ts`. 로컬 pnpm의 의존성 자동 설치 검사 때문에 직접 Node 진입점을 사용했다. 개발은 같은 폴더에서 `node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5212 --strictPort`로 실행할 수 있다.
