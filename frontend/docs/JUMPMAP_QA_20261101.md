# 점프맵 진행 유지와 돌 울타리 기단 QA

기준 `origin/dev@fc2a8cb5`, 최신 맵 `c05d8ada`. 작업 위치 `OnTop/qa-jumpmap-20261101`, 브랜치 `fix/jumpmap-qa-20261101`. 독립 실행은 `node node_modules/@playwright/test/cli.js test --config playwright.jumpmap-qa.config.ts`, 포트 5238.

## 원인과 변경

30초 주기의 REST 상태 조회는 월드의 activeRun을 먼저 읽고 DB를 기다린 다음 새 revision을 붙였다. DB 대기 중 START/END 이벤트가 발생하면, 낡은 빈 상태가 WS보다 큰 revision으로 진행 중 판을 지워 높이 15m 이상 발판이 비참가자 표시(.15)로 돌아갈 수 있었다. 상태 조회 전에 revision을 고정하고 월드 조회를 지연 호출하도록 변경했다. 최신 WS 이벤트가 낡은 응답을 이기며 보상·문 통과·종료 판정은 유지한다. 서비스 잠금과 월드 잠금을 겹치지 않는다.

돌 울타리(`layout-central-pagoda-stone-balustrade`) 모서리에서 긴 기단 두 개의 윗면이 겹치는 깊이 충돌을 제거했다. 긴 기단을 모서리 받침 위치에서 끝내고 모서리 받침을 한 번만 만든다. 목조 전망대·충돌 데이터·코스·맵 버전은 변경하지 않는다.

## 검증과 연결

BE 지연 DB 중 시작 이벤트 재현 및 기존 진행/종료/정산 테스트 통과. FE 기존 규칙·복구·표시/물리 21개와 기단 레이캐스트 검사 통과. 최신 맵 E2E 기존 11개 및 지연 응답 후 진행/발판 유지 1개 통과. 기단 네 모서리에서 같은 윗면이 한 번만 교차하는지 검사했다.

공통 변경은 기존 JumpmapController 상태 조회 호출이며, REST 응답 필드·WS·지갑·보상·종료 계약은 유지한다. DB/Flyway 변경 없음. E2E HTTP/WS는 계약 대역이며 운영 실서버 세션의 중단 로그를 직접 확인한 결과는 아니다. 확인한 경쟁 조건을 수정했으며 사용자 현상이 발생한 실서버 종료 사유 전체를 단정하지 않는다. 전체 통합 검증은 후속 통합 브랜치에서 수행한다.

기둥·받침·계단 기초의 보이지 않는 밑면이 바닥과 같은 높이에 겹쳤다. 접지 상자에서 아래 방향 면만 생성하지 않아 그림자 깊이 충돌 요인을 제거했다. 난간 크기·위치·상단 모양·이동 충돌과 맵/코스 버전은 유지한다. 변경 경로는 `layout-preview/pagodaBalustrade.ts`, 해당 시각 보존 체크포인트와 검사에 한정한다. 게임 규칙·시작·문 통과·기권·재접속·보상 계약 및 BE/DB/Flyway 변경 없음.

접지 면·계단 측면·모서리 레이캐스트와 시각 보존 검사 4개, 최신 맵 Edge 이동 시점 E2E 1개 통과. 화면 검증은 HTTP/WS 대역을 사용한다. 사용자 GPU의 기존 반짝임을 직접 측정한 결과는 아니며, 겹친 면의 제거와 최신 맵 렌더링을 검증했다. 공통 오디오를 포함한 통합 결과는 통합 문서에 기록한다.
