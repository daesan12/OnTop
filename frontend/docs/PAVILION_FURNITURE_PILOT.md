# 일반 정자 테이블·의자 코드 모델 확대 적용

## 적용 범위

- P1 시범 승인 후 일반 정자 P1~P8, 화면 테이블 `table-6`~`table-13` 총 8곳에 같은 스타일을 적용했다.
- `TableShell`의 기존 그룹 위치·크기·클릭 이벤트·`OmokBoard`는 유지한다.
- 공통 `PavilionWoodTable`은 이 그룹 안의 가구 외형만 교체한다. 승인한 시범의 부품·색상·재질·치수는 그대로다.
- 중앙 정자 P0는 기존 `MainPavilionTable`과 중앙 정자 의자를 유지한다.
- 야외 테이블·피크닉 테이블·캐릭터·우체통·카트에는 적용하지 않는다.
- 원본 GLB와 서버 테이블 매핑은 수정하지 않는다.
- 일반 정자가 모두 코드 의자로 바뀌어 사용하지 않는 의자 GLB의 사전 로딩 한 줄만 제거했다.
  기존 `WoodTable.tsx`와 원본 파일은 보존하며 중앙 정자/캐릭터 로딩은 변경하지 않는다.

## 외형

- 다섯 장의 목재 판재와 양끝 마감재로 구성한 상판.
- 어두운 하부 프레임·다리·가로대와 밝은 상판의 목재 색상 구분.
- 기존 좌석마다 세 장의 좌판, 살 등받이, 팔걸이, 프레임을 코드로 구성.
- 작은 황동색 마감과 기존 공유 목재 텍스처 사용. 새 다운로드 에셋은 없다.
- 정적 형상/배치 데이터는 모듈에서 한 번 만들고 다섯 instanced batch로 렌더링한다.
  매 프레임 형상/재질 재생성이나 React 상태 갱신은 추가하지 않는다.

## 유지한 계약

| 항목 | 기준 |
| --- | --- |
| 테이블 외곽 | 기존 2.1 × 1.6m |
| 테이블 상판 높이 | 정자 바닥 기준 1.06m |
| 의자 좌판 높이 | 정자 바닥 기준 0.56m |
| 의자 위치·방향 | 기존 `TABLE_SEATS`의 네 좌표와 yaw 그대로 사용 |
| 의자 외곽 | 기존 충돌체의 0.8 × 0.8m 범위 안 |
| 테이블 선택·착석·일어나기 | 기존 `TableShell`/runtime/서버 응답 흐름 |
| 서버 이동·충돌·버전 | 공통 설정/생성 결과 변경 없음 |

`TABLES`, `TABLE_SEATS`, 충돌체, 맵 버전, Java 코드, 배치별 서버 ID는 변경하지 않는다.
실행 서버에서 각 테이블이 연결되는지는 해당 환경의 기존 매핑에 따른다.
외형 확대 때문에 새 서버 ID나 배포 매핑을 추가하지 않는다.

## 확인 방법

기존 로그인·공원에서 P1~P8로 이동하면 동일한 코드 가구가 표시된다.
로그인/실서버 없이 재현하려면 프론트 폴더에서 아래 계약 대역 검증을 사용한다.

```sh
pnpm exec playwright test pavilion-furniture.spec.ts --reporter=line
```

검증 환경은 로컬 Vite, Edge, 1920×1080 및 1280×720이다.
Browser plugin not available: 기존 Playwright 설정을 사용한다.
`QA_ARTIFACT_DIR`를 지정하면 해당 폴더에 정자별 낮/착석 화면을 저장한다.
P1/P8은 밤·기존 착석 카메라·작은 화면도 저장한다.
지정하지 않으면 기존 fixture의 OS 임시 QA 폴더에 저장한다.

8개 테스트가 각 정자의 HTTP/WebSocket과 서버 ID 연결을 테스트 안에서만 대역으로 제공한다.
기존 부모 그룹에 대한 실제 3D 클릭, 서버 응답 후 좌석 확정, 다른 참가자의 착석 표시,
일어나기, 일반 정자 8곳 적용, 중앙/야외/피크닉 정자 외형 제외, 상판 크기와 높이,
불필요한 의자 GLB 요청 부재, 콘솔 오류를 확인한다.
`furnitureProbe.ts`의 고정 비교 카메라는 테스트 전용이며 production에서 불러오지 않는다.

실제 서버의 물리/거리 판정·실사용자 두 계정·전체 GPU 성능은 이 테스트의 검증 범위가 아니다.
기존 Three.Clock 폐기 예정 및 환경 셰이더 정밀도 경고는 수정 전 장면에서도 확인되었다.
Medium/High 전체 경로와 다른 GPU의 성능은 별도 검수 대상이다.

## 승인 경위와 유지 범위

P1 한 곳에서 확인한 색상·등받이·팔걸이·판재 비율을 사용자가 승인해 나머지 7곳으로 확대했다.
이번 확대는 정자별 좌석·상호작용·충돌·맵 버전의 변경을 포함하지 않는다.
캐릭터와 중앙 정자는 계속 기존 구현을 사용한다.
