# 감정표현·테이블 착석 동기화: BE 구현 확인 및 FE 연동

갱신일: 2026-10-28 (KST). 확인한 최신 dev: `0093398`.

BE 담당자의 완료 회신 후 소스와 `docs/world-websocket-api.md`를 확인했습니다. 기존의 BE 작업 요청은 아래와 같이 구현됐으며, 이 문서는 FE 통합·검증 상태를 기록합니다. BE 코드는 이 FE MR에서 수정하지 않습니다.

## 확인한 구현

| 항목 | 최신 BE에서 확인한 동작 | 연결한 FE 동작 |
| --- | --- | --- |
| 이동 중 방귀 유지 | FART의 MOVEMENT 취소는 이벤트 제거/방송 없이 무시 | 이동 입력·좌표 갱신 때 재생 시작 시각 유지 |
| 취소 후 즉시 다른 표현 | 재생 중 MOVEMENT/ACTIVITY_STARTED 취소 시 lastSent 제거. 정상 완료·채널 이동은 기존 제한 유지 | 유효 취소 시 요청 잠금·쿨다운 해제. 늦은 이전 응답은 새 선택에 영향 없음 |
| 주변 사용자 착석 표시 | 같은 채널 WORLD_STATE의 아바타에 tableSeat 제공. 비착석은 null 명시 | 참가·관전 없이 다른 사람의 실제 좌석 위치와 앉은 모션 표시. null 수신 시 해제 |

## 확정된 공개 착석 계약

`WORLD_STATE.payload.avatars[]`의 기존 아바타 필드에 `tableSeat`가 포함됩니다.

```json
{ "tableSeat": { "tableId": "실제-서버-tableId", "seatNumber": 1 } }
```

비착석은 `{ "tableSeat": null }`입니다. 좌석 번호는 TABLE_STATE와 같은 1부터 4까지의 정수입니다. 좌표 변경 없이 좌석만 변경돼도 월드 버전과 방송을 갱신하며, 초기 입장·재접속 스냅샷에도 포함됩니다. FE는 기존 매핑으로 표시하고 참가 권한은 계속 TABLE_STATE로만 판단합니다. 필드 생략은 이전 서버 호환용입니다.

## 감정표현 제한

- 이미 시작한 FART는 걷기·달리기·점프로 끊기지 않습니다. 이동 중 새 표현 시작은 기존처럼 거절합니다.
- 유효한 활동 취소 후 이전 표현의 쿨다운·최소 간격은 해제합니다. 정상 종료한 표현의 남은 대기는 유지합니다.
- 별도의 승인 제한은 기본 직전 1초에 최대 5회입니다(ontop.world.emote.maximum-per-second). 초과는 EMOTE_TOO_FREQUENT로 응답합니다.
- 만료된 표현과 이전 이벤트의 늦은 취소는 새 표현을 해제하거나 덮어쓰지 않습니다.
