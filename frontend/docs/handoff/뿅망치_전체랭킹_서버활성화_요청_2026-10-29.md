# 뿅망치 방어·붕어빵 전체 랭킹 사용 설정

## FE 반영

사용자 요청으로 두 기능을 일반 개발 실행과 배포 빌드에서 기본 활성화한다. BE 구현은 기존 `docs/onecard-ux-be-spec.md`, `docs/bungeoppang-rankings-api.md` 계약을 사용한다. 실제 서버 설정이나 BE 코드를 이번 FE 변경에서 수정하지 않는다.

```dotenv
VITE_ONECARD_PRANKS=true
VITE_ONECARD_PRANK_DEFENSE=true
VITE_BUNGEOPPANG_RANKINGS=true
```

위 값이 없어도 이제 기본은 활성이다. 기존 로컬/Vercel 빌드 환경에 `false`가 지정돼 있다면 해당 항목을 `true`로 바꾸거나 제거하고 FE를 다시 빌드해야 한다. 명시적인 `false`는 긴급 비활성화 용도로 계속 지원한다. 전체 장난을 끄면 방어도 함께 꺼진다.

이전 문서의 ‘FE 기본 OFF’는 이 변경으로 대체한다. 격리된 기존 E2E만 명시적으로 OFF를 사용하고, 두 기능 전용 브라우저 검증은 기본 ON 경로를 사용한다. 서버 오류 시 가상 순위·로컬 차단으로 대체하지 않는다.

## BE·서버 담당자 요청

### 원카드

새 BE 이미지가 실행 중인 개발 서버에 아래 속성을 적용해 주세요. 기존 게임 시작/원카드 엔진 설정과 인증·DB 설정은 유지합니다.

```properties
ontop.games.onecard.pranks-enabled=true
ontop.games.onecard.defense-enabled=true
```

엔진과 게임 시작이 아직 꺼진 서버라면 해당 서버의 기존 `GAME_ONECARD_ENABLED`, `GAME_START_ENABLED`도 준비 상태를 확인해 활성화해야 합니다. 위 두 속성만으로 엔진이나 DB 시작 기능이 새로 켜지지는 않습니다.

Spring Boot 환경파일 방식이 필요하면 기존 `SPRING_APPLICATION_JSON`에 아래 내용을 **병합**할 수 있습니다. 다른 설정이 들어 있으면 전체 값을 덮어쓰지 마세요.

```dotenv
SPRING_APPLICATION_JSON={"ontop":{"games":{"onecard":{"pranks-enabled":true,"defense-enabled":true}}}}
```

실제 설정은 저장소 밖 `/etc/ontop/dev-app/app.env`에서 관리됩니다. `app.env`를 바꾼 뒤에는 단순 restart가 아니라 기존 배포 절차로 앱 컨테이너를 재생성해야 합니다. 저장소 예제 파일 변경이나 FE 머지만으로 실행 서버의 환경파일이 바뀌지는 않습니다.

### 붕어빵 전체 랭킹

별도의 BE 랭킹 ON/OFF 속성은 없습니다. 새 랭킹 컨트롤러·서비스가 포함된 이미지, `db` 프로필, 기존 정상 완료 기록을 읽는 DB 연결이 필요합니다. 인증된 요청으로 아래 조회가 정상 응답하는지 확인해 주세요.

```http
GET /api/v1/minigames/bungeoppang/rankings?period=ALL_TIME&rulesVersion=v5&limit=20
```

v4는 같은 API의 rulesVersion만 v4로 지정합니다. 무기록이면 200과 빈 목록, 본인 기록이 없으면 me:null을 반환하는 것이 정상입니다. 정상 완료 결과의 완성·실수·확정 완료 시각으로 개인 최고를 집계하고, 실제 정산 완료 후 새 첫 페이지에 반영되는 기존 BE 계약을 사용합니다.

## 활성화 후 공동 확인

- 플레이어/승인 관전자 두 계정으로 손 뻗기 → 반투명 손 → 타격 승인 → 해당 관전자만 3초 차단. 방어하지 않은 경우만 카드 뒤집기, 손패 정리와 선택 카드 보호 확인.
- 붕어빵 정상 완료 → 보상·전체 순위 → 상세 참여자 → 다음 페이지 확인. 동점은 공동 순위이며 먼저 완료한 기록부터 표시.
- BE 구현·FE 로컬 계약 검증과 실제 서버 배포·실계정 검수는 구분합니다. 적용한 이미지/커밋과 설정 적용 완료 여부를 공유해 주세요.

## 전달할 글

FE에서 뿅망치 방어와 붕어빵 전체 랭킹을 기본 ON으로 변경했습니다. 원카드 실행 서버에 `ontop.games.onecard.pranks-enabled=true`, `ontop.games.onecard.defense-enabled=true` 적용을 부탁드립니다. 랭킹은 별도 기능 스위치 없이 새 BE 이미지와 DB 연결이 필요하므로 인증된 조회 API 응답을 확인해 주세요. 환경파일 변경 후 앱 컨테이너 재생성과 적용 이미지/설정 공유를 부탁드리며, 이후 두 계정으로 실제 연동을 검수하겠습니다.
