# BE 개발자 전달용 메시지

소리함·전망대 익명 메모함의 FE 에셋과 작성 화면을 수정했습니다. 펼치기·접기·만년필 연출은 FE에서 처리했고, 소리함 600자·익명 메모 300자 제한을 유지했습니다. BE 코드나 DB는 수정하지 않았습니다.

BE에서는 아래 내용을 부탁드립니다.

1. **메모 주제 저장**: 기존 메모 작성 API에 선택적 `category(daily/cheer/worry/recommend/free)`를 추가하고, 작성 성공 응답과 목록 조회에도 저장된 주제를 내려주세요. 기존 글과 주제 없는 요청은 `free`로 처리하고, 중복 요청 검사에도 주제를 포함해주세요.
2. **작성할 때만 새 글 알림**: 2초 주기 새로고침은 FE에서 제거했습니다. 다른 사람이 메모를 작성하면 열린 목록만 갱신할 수 있도록, DB 저장 성공 후 본문·작성자 정보가 없는 변경 알림을 보내주세요. 이벤트 이름과 전달 경로를 공유해주시면 FE의 준비된 구독 포트에 연결하겠습니다. 현재 다른 사람의 글은 다시 열기·새로고침으로 확인합니다.
3. **개발 환경 확인**: 기존 소리함·메모 API의 활성화와 DB 적용·배포 상태를 확인하고, 실제 작성·재조회·소리함 관리자 조회를 함께 검수해주세요. 소리함은 기존 비공개 의견 API를 그대로 사용하므로 새 API나 필드를 요청하지 않습니다.

주제 전송은 구버전 서버와의 호환성을 위해 현재 꺼두었습니다. BE 검수 후 FE 빌드 환경의 `VITE_NOTES_CATEGORIES=true`로 활성화하고 다시 배포하겠습니다. 다른 사람의 작성 알림 연결은 별도 FE 후속 작업입니다.

자세한 요청·예시·완료 조건은 [BE 요청서](./TRADITIONAL_MAILBOX_BE_REQUEST_2026-10-29.md)를 확인해주세요. 작업 후 적용 커밋·환경과 주제 응답 예시, 이벤트 규격을 공유 부탁드립니다.
