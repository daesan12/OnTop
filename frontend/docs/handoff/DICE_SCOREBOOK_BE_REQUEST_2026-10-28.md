# 주사위 점수책·턴 모래시계 FE 완료 및 BE 연동 확인 요청

작성일: 2026-10-28 KST. 최초 작업 기준: 원격 `dev`의 `8494849`. 작업 중 추가된 원격 변경은 `539de2d`까지 충돌 없이 리베이스해 통합했습니다. 이 변경은 FE 소스·FE 테스트·이 문서에 한정하며 BE 소스, DB, WS 메시지와 배포 설정은 변경하지 않습니다.

## FE에서 처리한 내용

- 기존 보드·주사위·컵의 지오메트리와 재질은 그대로 유지하고 표시 그룹을 70%로 축소했습니다. 기존 로컬 시안의 모래시계 외형·텍스처도 그대로 이관했습니다. 양쪽 좌석에서 점수표와 보드·컵·모래시계가 겹치지 않도록 화면 배치를 맞췄습니다.
- T, 하단 점수표 버튼, 테이블 위 책 클릭이 같은 점수표 열기 동작을 사용합니다. 나무 프레임·양피지 UI, 실제 눈금 아이콘, 현재 득점 조합 강조, 책 표지 및 페이지 전환을 FE에서 표시합니다.
- 점수표가 열리면 채팅을 숨기고 굴리기·Bank 입력을 막습니다. T/Esc/닫기 버튼으로 돌아가면 채팅을 다시 표시합니다. 점수표 열기는 서버에 게임 명령을 보내지 않으며 제한시간을 정지하지 않습니다.
- 모래시계 뒤집기는 확정 상태의 `gameId / round / turnUserId` 변경에만 반응합니다. 재굴림·동일 상태 재수신은 뒤집기를 재시작하지 않습니다. 재접속으로 여러 턴을 건너뛴 상태도 턴 번호의 홀짝을 반영하며 과도하게 반복 회전하지 않습니다.
- 모래 양은 기존 `turnDeadline / turnTimeLimitMs`로 계산하며 아래로 떨어지는 모래 입자는 FE 연출입니다. 모래시계나 책 애니메이션은 시간 만료·눈·점수·승패·정산을 판정하지 않습니다. 모션 감소 설정에서는 회전·페이지 전환·낙사 움직임을 생략합니다.

## 유지한 족보

| 조합 | 점수 / 동작 |
| --- | --- |
| 1 한 개 / 5 한 개 | 100 / 50점 |
| 같은 눈 3개 | 1은 1,000점, 2~6은 눈 × 100점 |
| 같은 눈 4 / 5 / 6개 | 해당 눈 3개 점수 × 2 / 4 / 8 |
| 1~5 / 2~6 / 1~6 | 500 / 750 / 1,500점 |
| HOT DICE | 6개 모두 득점하면 턴 점수를 유지하고 6개 재굴림. 고정 보너스 없음 |
| BUST / 턴 시간 만료 | 이번 턴 점수만 잃고 다음 차례. 저장 총점 유지 |

선택 전체가 겹치지 않는 득점 조합에 포함되어야 하며 최대 합을 표시합니다. 이전 굴림에서 보관한 주사위와 새 주사위를 합쳐 새 조합을 만들지 않습니다. 기존 서버 규칙 및 [주사위 계약](../../../docs/farkle.md)을 기준으로 하며 새 점수 규칙은 추가하지 않았습니다.

## BE 담당자에게 요청하는 확인

이번 UI를 위해 새 API나 새 이벤트를 반드시 개발해야 하는 상태는 아닙니다. 현재 `FarkleEngine.publicState`와 `FarkleMatch.nextTurn/expire`에서 필요한 필드가 이미 제공되는 것을 읽기 전용으로 확인했습니다. 다음 항목을 개발 서버와 실제 두 계정 연결에서 확인 부탁드립니다.

1. **개발 환경의 게임 시작 가능 여부:** 주사위 선택 활성화와 참가·준비·명시적 시작·재화 예약 연결이 실제 환경에서 동작하는지 확인 부탁드립니다. 환경의 기존 주사위 활성화 설정과 공통 Gateway를 사용하며 FE에서 임의 경기를 생성하지 않습니다.
2. **턴 변경 스냅샷:** Bank/BUST/30초 만료 후 `round`, `turnUserId`, 새 UTC `turnDeadline`이 같은 확정 `GAME_STATE`에 반영되고 두 플레이어에게 전달되는지 확인 부탁드립니다. 같은 턴 재굴림 및 HOT DICE에서는 원래 마감을 유지해야 합니다. 변경 처리가 이미 구현되어 있으므로 중복 구현 요청이 아닌 실제 배포 상태 확인 요청입니다.
3. **복구와 타이머:** 재접속·지연 전송 후에도 원래 마감을 복구하고, 지연 타이머가 여러 턴을 넘겼다면 현재 `round`와 현재 마감으로 복귀하는지 확인 부탁드립니다. 점수표를 보는 동안 시간이 만료되어도 서버는 정상적으로 다음 차례를 진행해야 합니다.
4. **종료·정산:** 목표 도달 Bank/기권/재접속 유예 만료에 따른 기존 종료·정산 상태가 유지되는지 확인 부탁드립니다. FE 연출 완료 이벤트를 기다리거나 별도 정산 요청을 추가할 필요는 없습니다.

### 시계 오차에 관한 후속 협의

현재 주사위 계약은 UTC 마감을 제공하고 FE는 기존 구현과 같이 클라이언트 시각으로 남은 시간을 표시합니다. 시간 초과의 최종 판정은 항상 서버가 담당합니다. 실제 두 계정에서 OS 시계 오차에 따른 표시 차이가 관찰되면, 공통 서버 시각 동기화 계약을 주사위 타이머에 연결할지 함께 협의 부탁드립니다. 이 MR은 미확정 `serverNow` 필드나 새 메시지를 요구하지 않습니다.

## 검증과 범위

- FE 전체 단위 테스트, 앱·테스트 타입 검사, 프로덕션 빌드.
- 양쪽 좌석: 축소된 3D 주사위 선택/컵 조작, 책 클릭과 T, 실제 눈금 수, 모달 초점, 채팅 숨김·복원, 점수표 중 게임 명령 차단, 원래 마감 유지, 턴당 뒤집기, 모션 감소와 좁은 화면.
- 기존 재굴림·HOT DICE·Bank·승리·정산·BUST·만료·복구 회귀 및 기본 태블릿의 명시적 주사위 시작 경로.
- 브라우저 검증은 HTTP/WS 계약 fixture 기준입니다. 실제 로그인·두 계정 실서버·재화 DB 정산·운영 배포는 BE/환경 담당자와 공동 확인이 필요합니다.

## 전달용 메시지

> 주사위 게임 FE에 점수책(T/책 클릭), 채팅 숨김, 소품 70% 축소, 턴별 모래시계 뒤집기와 모래 낙하를 반영했습니다. 모델·재질과 기존 주사위 판정/점수/30초 규칙은 유지했습니다. 새 BE API는 필요하지 않으며, 기존 `round / turnUserId / turnDeadline / turnTimeLimitMs`의 실제 배포·전달 상태와 재접속/타임아웃/종료·정산 경로를 두 계정으로 확인 부탁드립니다. 점수표를 보거나 애니메이션이 진행 중이어도 서버 타이머는 계속 진행되어야 합니다.
