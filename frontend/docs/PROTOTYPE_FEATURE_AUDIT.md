# 프로토타입 기능 이관 비교

2026-10-22. 비교 대상은 사용자 프로토타입 apps/web과 GitLab dev의 공원 이관(6889d57), 이번 오목 준비 변경이다. 프로젝트 변경은 frontend 안으로 제한한다. **아래는 진입 컴포넌트·입력 처리·표시 상태·통신 호출을 대조한 코드 조사다. 모든 시설을 실제 BE에서 실행 검증했다는 뜻이 아니다.** 누락 기능을 이번 작업에서 임의로 추가하지 않는다.

## 후속 작업 분류

- 실제 BE 없이 먼저 준비 가능: F1 설명서 진입/로딩·입력 잠금, 광고 링크 안내, 지도/시설 안내, 기존 게임 화면 분리. 팀원 UI와 중복 여부를 확인하고 별도 요청 범위로 진행한다.
- 확정 계약 필요: 소리함 저장/조회·익명 메모, 벤치/운동기구/망원경 점유·해제·원격 상태, 감정표현 코드 매핑·따라가기, 붕어빵 검증/보상. 기존 Colyseus 명령을 운영 프로토콜로 복사하지 않는다.
- 설명서 재사용 주의: 프로토타입 catalog에는 오목 자유룰·시간 제한 없음 등 현재 BE의 렌주/30초 계약과 다른 문구가 남아 있다. 그대로 배포하지 말고 게임별 현행 문서와 대조한다.

이번 변경은 공통 경기 흐름·오목 준비이며 이 목록 전체의 기능 복구를 완료한 작업이 아니다.
