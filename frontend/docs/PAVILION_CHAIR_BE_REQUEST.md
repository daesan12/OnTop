# BE 전달용 요청문

제목: [BE 요청] 팔각정 숨겨진 3·4번 의자의 정적 충돌 해제 및 승인 인원수 동기화

팔각정 테이블을 기본 2인 의자로 표시하고, 서버에서 3인/4인 설정을 승인하면 추가 의자를 표시하도록 FE가 변경되어 있습니다. 현재는 숨겨진 좌우 의자 위치에서도 캐릭터 이동이 막힙니다.

확인 결과, FE 의자 렌더링 수와 별개로 `park.json`의 네 의자 박스가 `ParkScene` → `WorldPhysics`에서 항상 정적 충돌체로 등록됩니다. 실제 이동 위치는 서버가 결정하므로 FE 변경만으로 이 보행 막힘을 해결할 수 없습니다. BE 코드는 이번 작업에서 수정하지 않았습니다.

다음 사항을 요청드립니다.

1. 채널·테이블별 서버 승인 상태에 따라 의자 충돌을 2/3/4개로 활성화해 주세요. 미선택/2인은 좌석 3·4를 통과할 수 있고, 3인은 좌석 4만 통과할 수 있어야 합니다. 네 의자를 무조건 등록하는 정적 충돌과 동적 충돌이 중복되지 않도록 처리해 주세요.
2. 게임/설정 초기화와 퇴장 시에도 같은 규칙을 적용하고, 이미 점유 중인 좌석은 보존해 주세요. 의자 생성 위치에 산책자가 서 있는 경우의 안전한 위치 처리도 필요합니다.
3. 기존 GET `/api/v1/tables?channelId=...`의 공개 승인 인원수를 최신 상태로 유지하고, 채널 내 산책자·늦게 입장한 사용자에게도 의자 상태가 일치하도록 갱신 계약을 공유해 주세요. 새 WS 메시지/필드가 필요하면 버전·채널·테이블 식별과 초기화 규칙을 포함해 FE와 합의 부탁드립니다.
4. 맵 구조/지문이 변경된다면 FE에서 맞춰야 하는 자료도 함께 전달해 주세요. tableId와 시각 anchorId는 기존 binding으로 연결하며 숫자 접미사로 추정하지 않습니다.

FE에서는 공개 목록만 수신한 산책자도 승인 인원수에 맞춰 의자를 표시하도록 보완했고, 상세 상태가 있으면 실제 승인 좌석을 우선합니다. 현재 서버 정적 맵과의 일치 및 길 안내는 유지했습니다. 실시간 공개 상태 계약과 BE 물리 변경이 반영된 뒤 실제 서버에서 최종 통행 확인이 필요합니다.

상세 원인·재현·좌표 사례·수용 조건은 같은 폴더의 [PAVILION_CHAIR_COLLISION.md](./PAVILION_CHAIR_COLLISION.md)를 참고해 주세요. 2→3→4→2 전환, 두 채널 독립성, 기존 테이블/기둥 충돌 유지까지 확인 부탁드립니다.
