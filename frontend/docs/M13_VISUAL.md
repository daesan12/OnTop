# M13 거짓말 다리 원본 시각 요소 보완

기준: 2026-10-24. 기존 기능과 BE 계약을 유지하는 프론트 변경이다.

## 원본과 범위

`Desktop/topgoal.zip` 및 이를 풀어둔 `Desktop/topgoal/apps/web/`의 원본을 사용한다. `features/tables/bridge/BridgeBoard.tsx`와 대응하는 GLB·manifest를 확인했다.

게임 규칙·인증·실제 난수·패 배분·비밀 눈·기권·정산은 현재 BE 계약을 유지한다. 원본 Colyseus 연결이나 프로토타입 상태 모델은 복사하지 않는다. 게임 선택/준비, 요청 식별자·버전, ACK/최신 상태 대기, 응답 불명·복구·시간 만료 입력 차단과 관전자 권한은 기존 경로다. 새 목업 게임 엔진·가짜 결과·API를 추가하지 않는다.

원본 최적화 GLB 보드·말, 전체 0.5배 세트 크기, 진행·대기·골인 위치, 8칸 표식·색·사용 완료 표시와 말 LOD를 적용했다.

원본 모델과 그에 맞는 좌표를 함께 가져왔다. 판만 교체하고 기존 기본 도형용 좌표를 쓰지 않는다. 활성 말0.6·예비 말0.3·골인 말0.72의 원본 배율과 전체0.5배를 적용한다. 모델은 표시용이며 실제 이동 칸·점수·슬롯 발급/소진·승자는 BE 상태다.

모두 믿은 판정의 실제 눈은 표시하지 않고 다우트가 있는 승인 결과만 공개한다. 최초 진입·중복·오래된 판정·복구는 기존대로 최종 위치로 맞춘다. 비공개 눈을 GLB·텍스처·아바타 데이터에 전달하지 않는다.

## GLB 출처·무결성

원본 프로젝트에서 사용자 제공 모델을 최적화해 사용하던 런타임 파일이다. 새 다운로드·유료 생성·독립적인 사용권 취득 주장은 없다. 원본 manifest의 사용자 제공 출처 기록을 함께 보존한다.

| 파일 | 크기 | SHA-256 |
| --- | ---: | --- |
| `public/art/props/chao-board.glb` | 2,622,236 B | `e5991a11911e8e6c537162016090f83b1a14e802e6dda6bbb25b39048982b86e` |
| `public/art/props/chao-pawn.glb` | 89,568 B | `29a798ea7d0775b761d28f6fc97c9e6d4b9a73fdf615d5d5c93cca32dd507b7d` |

두 GLB는 원본 ZIP·풀어둔 파일·원본 manifest의 해시/크기가 모두 일치한다. 외부 buffer URI가 없는 GLB이며 보드 `board-detail/board-distant`, 말 `pawn-detail/pawn-distant` 노드를 확인했다. 기존 로컬 Meshopt 디코더와 `ParkAssetLoader`/`ImportedProp`를 사용한다. 원본 보드 manifest 항목은 `chao-board.manifest.json`으로 따로 기록하고 말 manifest는 그대로 가져왔다.

## 비용과 최적화

원본 Meshopt·WebP·LOD를 보존하고 기존 로컬 디코더와 ParkAssetLoader/ImportedProp를 사용한다. 말은 최대28개를 같은 geometry/material과 instanceColor로 그린다. 4m 이상에서600 triangles,3.6m 이내에서2,400 triangles로 복귀한다. 매 프레임 React 상태를 생성하지 않는다. 보드는 기존 LOD 로더와10m 기준을 사용한다.

| 단계 | 낮 calls / triangles | 밤 calls / triangles | geometry 추정 | 이미지 텍스처 추정 |
| --- | --- | --- | ---: | ---: |
| 기존 기본 도형 | 367 / 1,656,634 | 368 / 1,657,914 | 43,825,096 B | 211,435,520 B |
| 원본 최적화 GLB | 364 / 1,743,625 | 365 / 1,744,905 | 45,372,210 B | 244,989,952 B |

calls는3개 줄지만 triangles86,991개·geometry1,547,114B·이미지 메모리32MiB가 증가한다. 전체 성능 개선으로 해석하지 않는다. 최종 관측 p95는 낮11.1/밤16.9ms이며 밤 표본의 증가가 남는다. WebP는 GPU 텍스처 압축이 아니며 KTX2 재인코딩은 수행하지 않았다.

측정 조건은 Core Ultra9 185H/Intel Arc(ANGLE D3D11), Edge156.0.4314.42/WebGL2,1920×1080 Low(내부1280×720),16인·같은 착석1인칭·주야간·로컬 계약 HTTP/RawWS다. 워밍업 후240프레임 이상·GPU timer3표본을 수집했다. geometry 추정은 인스턴스 행렬·색 배열을 제외한다. 단일 장비 표본이며 별도 CPU 단계별 프로파일·다른 장비 FPS 보장은 없다.

## 동작 검수

순차 판단·슬롯·공동 결과, 관전자 GLB/말 LOD 양방향 전환·개인정보/입력 차단을 확인했다. 관전 종료 시 개별 인스턴스4 해제·공유 자원 해제0개였다.

실제 React+Java의 독립 참가자101/202·관전자505로 버전59·15번째 차례까지 진행했다. 202가9점/3골인 대101의6점/2골인으로 THREE_GOALS 승리했다. 모두 믿음·다우트 성공/실패·같은 비밀 눈/마감 복구·세 공개 판 일치·관전자 행동0개·페이지/콘솔 오류0개를 확인했다.

첫 연속 Java 검수는 이전 경기 좌석이 남아 입장 전에 중단돼 독립 서버에서 재실행했다. 첫 독립 검사에서는1.5초 판정 종료 중 QA가 과거 버전을 기다려 실패했다. 제품을 바꾸지 않고 Git 밖 검사만 세 화면의 최신 공개 상태 수렴과 실제 수신 프레임을 확인하도록 수정한 뒤 재실행해 통과했다.

Browser plugin not available에 따라 기존 Playwright/Edge를 사용했다. 페이지 제목·실제 본문·프레임워크 오류 오버레이 없음과 조작 후 상태를 검사했다. 타입·FE 단위27개 파일/203개·빌드·이관 경계 검사도 통과했다. 커밋별 분리본의 검사 기록은 Git 밖 QA 폴더에 별도 보관한다.

Java 검수의 로그인·프로필·목록·내부 경기 생성은 테스트 대역이며 규칙·개인/공개 RawWS·복구는 실제 BE다. 공개 경기 참조는 기존 미리보기 포트다. OAuth·DB 참가금/정산·개발 서버 배포 검수는 아니다. 수동 기권·공개 gameId 공급의 기존 미연결 항목도 유지한다. 검수 뒤 자체 테스트 서버만 종료했다. Three.Clock/ANGLE·큰3D청크 경고와 좁은 화면 전체 HUD의 한계는 남는다. PC 웹 검수이며 모바일 서비스 지원을 뜻하지 않는다.
