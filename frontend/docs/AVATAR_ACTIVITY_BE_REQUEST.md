# BE 전달용 요청문

제목: [BE 요청] 게임·상점 이용 상태를 공원 아바타 활동 말풍선으로 공개

현재 붕어빵 이용 시 `WORLD_STATE.avatars[].activity = "BUNGEOPPANG"`을 받아 머리 위에 '붕어빵 뒤집는 중'을 표시하고 있습니다. 같은 방식으로 보드게임 중에는 '게임 중', 추후 상점 이용 시에는 '상점 이용중'을 주변 사용자에게 보여주려 합니다.

FE에는 기존 공개 activity 필드의 `GAME`/`SHOP` 수신·검증·표시를 추가했습니다. 본인은 승인된 경기 상태와 기존 상점 열림/닫힘 컨트롤러로 로컬 표시도 연결했습니다. 상점 진입 버튼을 새로 활성화하거나 새 API를 임의로 호출하지는 않았습니다. BE 소스는 수정하지 않았습니다.

다음 작업을 요청드립니다.

1. 실제 보드게임 시작 승인 시 참가자의 공개 활동을 `GAME`으로 방송해 주세요. 착석·대기·준비·관전은 제외하고, 정산 진입·종료·확정 기권/탈락·참가 종료 시 해제해 주세요.
2. 상점 도입 시 진입/종료 승인 계약을 공유해 주세요. 목록·지갑 GET으로 창 열림을 추정하지 않고, 인증 사용자·채널·멱등성/lease·종료·재접속·만료 규칙을 확정한 뒤 `SHOP` 상태를 방송해야 합니다. 계약 합의 후 FE 컨트롤러에 연결하겠습니다.
3. 기존 `BUNGEOPPANG` 동작은 유지하고 활동 종료 시 `null`을 보내 주세요. 같은 채널의 주변 사용자와 늦게 입장한 사용자 모두 최신 상태를 받아야 하며, 오래된 이벤트가 종료된 표시를 되살리지 않도록 처리해 주세요.

주변 사용자에게는 서버 방송이 필요하므로 현재 FE 변경만으로 원격 게임/상점 표시가 완성된 상태는 아닙니다. BE 반영 후 두 브라우저에서 시작·종료·채널 이동·재접속을 확인해야 합니다.

상세 FE 구현, 수신 코드와 수용 조건은 [AVATAR_ACTIVITY_HANDOFF.md](./AVATAR_ACTIVITY_HANDOFF.md)에 정리했습니다.
