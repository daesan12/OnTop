# 소리함·전망대 메모함 코드 에셋 정교화

2026-10-29. 기존 FE 작업 위에 첨부 콘셉트의 형태와 장식을 보강했다. BE, API, 입력/작성 화면, 메모 300자·소리함 600자 정책은 이번 정교화에서 변경하지 않았다.

## 반영한 형태

- 공통: 겹치는 반원형 수키와와 오목한 암키와, 기와 이음선·막새 문양, 곡선 처마·용마루. 작은 모서리 깎기와 코드로 생성하는 나뭇결·석재 요철. 추가 이미지 파일이나 외부 3D 모델은 사용하지 않는다.
- 소리함: 진홍색 목재 판재와 측면 통풍 홈, 아치형 금테 명패와 지붕/꽃 장식, 투입구의 어두운 안쪽과 빗물받이, 경첩·나사·열쇠구멍, 봉투·삼층탑·금색 테두리, 받침의 돌 판재·탑·꽃 부조.
- 메모함: 목재 프레임과 연결부, 하단 버팀목·분리된 돌 받침, 종이별 크기·기울기·모서리 말림, 핀·필기 장식, 입체 등불과 원형 안내판, 꽃과 잎, 눈·부리·날개·꼬리가 구분되는 비둘기.

3D 종이의 필기선은 장식이다. 실제 사용자 메모는 기존 E 목록 화면이 담당한다.

## 경계와 렌더링

- 소리함은 기존 `MAILBOX` 위치·0.92 × 0.80 × 1.80m 기준 형태와 스케일을 유지한다.
- 전망대는 기존 `NOTES_BOX` 위치·1.30 × 0.96 × 1.72m 범위를 유지한다.
- 재질 프로필은 `CraftedPropLod`의 선택적 `heritage` 속성으로 두 에셋에만 적용한다. 주변 공원은 기존 재질을 사용한다.
- 코드 텍스처 두 장은 256 × 256으로 한 번 만들고 공유한다. 프레임마다 텍스처/지오메트리를 생성하지 않는다.
- 재질별 합친 메시와 근거리/원거리 LOD를 유지한다. 두 모델 모두 운영 빌드에서 미리 구워 런타임 재생성을 피한다.
- 기존 단순화 공원의 100,000 정점 구성 예산 검증은 유지하고, 정교화한 소리함의 구성 정점은 별도 18,000 미만으로 제한한다. 최종 삼각형 예산은 소리함 근거리 12,000 미만, 메모함 근거리 18,000 미만이다. 각 원거리 모델은 근거리의 70% 미만이다. 작은 필기선·꽃·기와 이음선의 분할은 실제 크기에 맞춰 줄였다.

## 로컬 확인

- 소리함: `pnpm dev:feedback` → `http://127.0.0.1:5204/feedback-preview.html`
- 메모함: `pnpm dev:notes` → `http://127.0.0.1:5205/notes-preview.html`
- `에셋 회전`으로 앞면·측면·뒷면을 확인한다. E 진입과 작성 동작도 기존대로 이용한다.
- 독립 미리보기는 메모리 목업이다. 실제 공원 회귀는 HTTP/WS 계약 대역을 사용하며 실제 BE 저장을 검증한 것은 아니다.

관련 소스: `world/art/heritageGeometry.ts`, `heritageTextures.ts`, `mailboxGeometry.ts`, `notesBoardGeometry.ts`, `TraditionalMailbox.tsx`, `TraditionalNotesBoard.tsx`.

검증: 소스·테스트 타입 검사, 단위 테스트 110개 파일 937개, 운영 빌드, 마이그레이션 경계 검사, 실제 공원 브라우저 에셋 회귀 2개를 통과했다. 독립 미리보기 앞면·측면·뒷면 캡처에서 pageerror 0을 확인했다. 커밋·푸시·머지는 진행하지 않았다.

## 2026-10-29 · 메모함 재정교화

소리함 형상·명패·공통 지오메트리 도우미는 보존하고 메모함만 다시 다듬었다.

- 판을 넓고 낮은 비례로 조정하고 명패를 작게 만들어, 지붕과 게시물이 주인공이 되게 했다. 기존 정상 위치·충돌 범위는 유지한다.
- 메모함 전용의 얇은 수키와, 위로 들린 처마와 용마루를 구현했다. 소리함은 기존 공통 기와를 그대로 사용한다.
- 반복된 필기선 대신 로컬 캔버스로 한글 문구·작은 손그림·종이 얼룩·꽃 스티커를 그린 1024px 아틀라스 한 장을 사용한다. 크기·기울기·높이가 다른 13장의 종이가 따로 말린다. 3D의 문구는 콘셉트 장식이며 실제 사용자 목록과 혼동해 API 데이터로 저장하지 않는다.
- 나무색 무광 바탕, 나뭇결의 매듭과 마모, 조각한 명패, 낮고 따뜻한 등불로 재구성했다. 좌우 같은 화분을 없애고 오른쪽 화분과 왼쪽 게시판 꽃으로 비대칭 구성을 만들었다.
- 글꼴을 로컬에서 불러온 뒤 명패·메모 텍스처를 다시 그려 잘못된 대체 글꼴이 남지 않게 했다. 텍스처는 공유하고 교체·해제할 때 정리한다. 프레임마다 캔버스를 그리거나 텍스처를 만들지 않는다.
- 선택적 재질 맵 전달만 공통 렌더러에 추가했다. 이 속성을 사용하지 않는 소리함과 다른 소품의 재질 경로는 그대로다.
- 기존 18,000 삼각형 미만의 메모함 근거리 예산, 단순한 원거리 LOD, 빌드 시 정적 베이킹을 유지한다.
- 로컬 메모함 미리보기는 조명 대상을 모델에 맞추고 처마·종이 그림자가 보이도록 개선했다. 실제 공원의 조명은 바꾸지 않았다.

메모 작성 UI·300자·폴링 제거·BE 요청 문서는 이번 에셋 변경에서 수정하지 않는다. 소리함의 600자·작성 연출도 그대로다.

### 안내 문구와 다리 마감 조정

- 소리함 작성·전송 완료 화면의 목업 안내와 메모함 하단의 로컬 미리보기 안내를 제거했다. 소리함의 실패 문구는 “전송 실패입니다. 작성한 내용은 그대로 보관됩니다.”로 정리했다.
- 메모함 양쪽 돌 받침을 없애고 나무 기둥과 목재 발을 바닥까지 내렸다. 오른쪽 화분도 바닥 높이에 맞췄다. 독립 미리보기의 데크 높이는 에셋 바닥에 맞춘다.
- 개발용 도구 모음의 안내와 기존 목업·서버 모드 분리는 유지한다. FE 표시와 에셋만 수정했으며 BE 변경은 없다.
