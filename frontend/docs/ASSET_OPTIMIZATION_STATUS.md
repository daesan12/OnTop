# 이관 에셋 최적화 상태 — 2026-10-22

**전체 게이트는 미완료**다. 아래는 이 브랜치에서 수행한 범위와 실측이며 전체 에셋 최적화, 모든 카메라·프리셋·GPU, 실제 다중 사용자 서버 성능의 보증이 아니다.

## 적용과 검수

- 정적 부품은 원래의 시설/로컬 구역 배칭을 유지하고 반복 수목·가구·소품을 인스턴싱한다. 맵 전체 병합은 하지 않는다. 움직이는 시설 부품·카메라 가림 처리·컬링을 보존한다.
- 남녀 GLB는 근/원거리 각각 약24k/6k삼각형, 1공유 재질·2048 WebP·Meshopt·49본 리그다. 거리 LOD와 포즈 갱신 감축을 유지한다. 기존 파일 해시는 manifest와 단위 테스트로 대조한다.
- 목재 의자는 4개 원본 중 실사용 한 의자를 오프라인 추출하고 정규화한다. 런타임의 섬 추출/배열 재생성을 제거했다. 1,128삼각형·1재질·3텍스처의 같은 형상을 테이블별로 공유/인스턴싱한다. 작은 정적 소품이므로 별도 의자 LOD를 강제로 만들지 않고 시설/프러스텀 컬링을 유지한다.
- 의자 파일 2,762,892→709,224 bytes. 색상 2048 유지, ORM/normal 2048→1024, Meshopt 형상 바이트 무손실 검사. 새 파일 해시·텍스처 크기는 props/wood-chair.manifest.json에 기록한다.
- 기본 Low는 실시간 그림자 OFF·내부 해상도 예산을 유지한다. 별도 bloom/SSR/volumetric 후처리는 추가하지 않았다. High 선택의 렌더링·그림자 경로는 브라우저 스모크에서 별도 확인한다.
- 캐시/공유 형상·재질을 재사용하고 아바타 개별 skeleton을 정리한다. 전체 구역 스트리밍·캐시 퇴거는 미완료다. 기존 WebP/Meshopt 로더는 유지하며 KTX2/Basis 로더와 GPU 압축은 아직 미적용이다.

## 맞춘 측정 조건

Intel Core Ultra 9 185H / Intel Arc 내장 GPU(ANGLE D3D11), Windows, Edge 155.0.4283.62, WebGL 2, Low. 뷰포트1920×1080, 실제 Canvas1280×720 / DPR0.6667. 16인 정지 아바타의 공원 장면, 동일 테이블 인근·yaw=-π/2·pitch=.45·거리9m. 낮 phase .6 / 밤 .05. 로컬 HTTP/RawWS 계약 대역이며 WAN 지연을 넣지 않았다. 서버 처리량·실제 16계정 접속 테스트가 아니다.

각 조건에서 60프레임 이상 워밍업 뒤 최소180프레임을 별도 측정했다. 스크린샷은 프레임 표본 수집 뒤에 찍어 캡처 정지 시간이 표본에 섞이지 않게 했다. GPU 시간은 EXT_disjoint_timer_query_webgl2의 8개 유효 표본 평균이다. CPU 렌더 시간만의 분리는 하지 못했으며 전체 프레임 분포로 기록한다. GPU 표본은 작은 탐색 표본이므로 정밀 회귀 판정으로 쓰지 않는다.

park-hidden은 static park 그룹만 숨긴 조건이다. 아바타·하늘·주변 효과와 이미 업로드한 리소스는 남는다. 따라서 에셋을 완전히 제거한 다운로드/메모리 기준선은 아니다.

해당 장면 /art 리소스의 decodedBodySize 합계는 18,620,633→16,566,965 bytes였다. UI 이미지·JS·폰트 등을 포함한 전체 첫 다운로드량은 아니다. 관측된 지오메트리 CPU 버퍼 추정은43,817,200 bytes로 같았다. 텍스처 RGBA8+mipmap 단순 추정은244,989,952→211,435,520 bytes, 약32MiB 감소했다. 실제 드라이버 GPU 메모리는 브라우저 표준 API로 확인할 수 없어 측정하지 못했다. 동영상·렌더 타깃·MSAA·스켈레톤 등 모든 비용을 포함한 합계가 아니다.

## 미완료·남은 교환 비용

완전 미배치/미로드 기준선, 모든 에셋의 개별 전후 비교, KTX2·구역별 지연 로딩/메모리 회수, 모든 LOD/가림/그림자·광고 슬롯의 전수 이동 경로, 장시간/다른 GPU·브라우저·WebGPU가 남는다. 원거리 아바타 LOD·근거리 복귀·착석 시점·다른 참가자 표시·High 품질 전환은 계약 대역의 브라우저 회귀로 검증하며 실제 서버 동등성을 대신하지 않는다.

Three.Clock 폐기 예정 경고와 원래 환경 셰이더의 정밀도 경고가 남는다. 큰 WorldCanvas 청크도 남는다. 최적화 완료나 특정30/60FPS를 보장하지 않고 검토용 MR로 제출한다. 측정 원시 JSON·스크린샷은 로컬 QA 산출물이며 저장소에 개인 경로/자동 생성 화면을 커밋하지 않는다. 재현 진입점은 tests/e2e/assets.spec.ts다.
