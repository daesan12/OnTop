## 1. 요청 배경

웹게임 플레이 중 다음 문제가 제보되었습니다.

- 화면이나 이미지에 마우스 오른쪽 버튼을 누르면 브라우저 기본 메뉴가 나타남.
- G 키로 여는 감정표현 창이 크고, 사용자에게 불필요한 '서버' 표시가 노출됨.
- 수영이 헤엄치기보다 떠 있는 모습으로 보이고, 의자에 앉으면 캐릭터나 의상이 에셋을 관통함.
- 분수 주변에서 보이지 않는 장애물에 이동이 막히고, 돌 의자를 통과하는 현상이 있음.

이 중 UI와 캐릭터 표현은 FE에서 수정했습니다. 분수·돌 의자의 실제 이동 충돌은 서버가 결정하므로, FE에서 준비한 충돌 정의를 서버가 사용하는 맵 데이터에 반영해주실 것을 요청드립니다.

## 3. BE 담당자께 요청드리는 작업

### A. 분수 주변의 보이지 않는 충돌 범위 수정

**확인한 문제**

분수 에셋은 원형인데, 확인 기준 dev의 `backend/src/main/resources/world/park.json`에는 `fountain-basin` 사각 상자 1개가 사용됩니다. X/Z 반폭이 각각 5m이므로 원형 에셋 밖 대각선 공간까지 막힐 수 있습니다. 실제 제보 위치에서의 재현과 활성 서버 데이터 확인이 필요합니다.

**FE에서 준비한 작업**

`frontend/src/config/parkExpansion.ts`의 `EXPANSION_COLLIDERS`에서 기존 사각 상자를 제거하고, 원형 하단 원판 반경 5.4m를 48개 얇은 상자로 근사했습니다. 수조 벽과 돌 원판 자체의 충돌은 유지하는 방향입니다.

**요청 작업**

1. 실제 서버가 사용하는 맵에서 기존 사각 충돌을 원형 에셋에 맞는 범위로 교체해주세요.
2. FE 제안인 48분할 상자를 사용한다면 기존 `fountain-basin`을 함께 남기지 말아주세요. 정확한 원형/볼록 형상으로 대체할 경우 최종 규격을 공유해주세요.
3. 분수 밖 대각선 통로는 지나갈 수 있고, 분수 구조물 자체는 통과하지 않는지 확인해주세요.

### B. 돌 의자 충돌 추가 및 자동 오르기 방지

**확인한 문제**

확인 기준 dev의 BE 물리 리소스에는 야외 `table-1`~`table-4`의 돌 좌석 충돌 16개가 없습니다. 피크닉 돌 의자는 충돌 상자가 있지만 낮은 높이로 설정되어 있어 자동 오르기 정책의 영향을 받을 수 있습니다.

**FE에서 준비한 작업**

`frontend/src/config/world.ts`의 `WORLD_COLLIDERS`에 야외 돌 좌석 16개를 추가하고, 야외·피크닉 돌 의자의 이동 벽 높이를 2.5m로 정의했습니다. 기존 좌석 ID·인덱스·승인 착석 좌표는 유지했습니다.

**요청 작업**

1. 실제 서버 맵에 누락된 야외 돌 좌석 충돌을 추가해주세요.
2. 피크닉 돌 의자에도 이동 벽 높이를 반영해 걷기·달리기로 통과하거나 자동으로 올라가는 현상을 방지해주세요.
3. 충돌 추가 후에도 기존 승인 절차를 통한 앉기·일어나기가 정상이고, 퇴장 위치가 막히지 않는지 확인해주세요.

### C. 활성 맵 반영·배포 및 FE 연결 정보 공유

**요청 작업**

1. 실제 실행 서버의 `WORLD_MAP_SOURCE`가 `legacy`인지 `generated`인지 확인해주세요. 기본값은 legacy지만 실제 환경값은 이번 FE 작업에서 확인하지 않았습니다.

2. BE 충돌 구현은 dev에 반영되어 있으므로 다시 구현할 필요가 없습니다. BE 담당자는 실제 서버가 legacy 수정본과 위 맵 버전으로 배포됐는지 확인하고, FE 배포와 버전을 맞춰주세요.
3. 양쪽 반영 후 실제 게임에서 아래 항목을 공동 검수합니다.

- 분수 주변을 8방향으로 걷기·달리기: 구조물 밖의 보이지 않는 벽이 없고 분수 자체는 통과하지 않음.

- 남녀 캐릭터 착석: 좌판에 신체·의상이 파고들지 않음.

## 5. BE 구현 참고 규격

### 분수

- FE 정의: `frontend/src/config/parkExpansion.ts`
- 중심 X/Z: `[-56,-45]`, 광장 바닥: `-1.1m`, 하단 원판 최대 반경: `5.4m`.
- 제안 ID: `fountain-basin-0` ~ `fountain-basin-47`.
- 각 Z 구간 폭: `10.8/48 = 0.225m`. 구간의 원점에 가장 가까운 Z 절댓값을 `d`라 하면 X 반폭은 `sqrt(5.4²-d²)`.
- FE 시각 상자 Y 중심: `0.7-plazaDepth`, 시각 반높이: `0.7`, 이동 벽 높이: `4m`.
- 확인 기준 BE의 기존 상자는 이동 높이 변환이 이미 적용된 중심 `[-56,0.9,-45]`, 반폭 `[5,2,5]`입니다.
