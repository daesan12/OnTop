## 1. 분수의 보이지 않는 벽

소스 확인 결과, 분수는 원형인데 기존 `fountain-basin`은 X/Z 반폭 5m인 사각형입니다. 예를 들어 분수 중심에서 X/Z가 각각 4.5m 떨어진 대각선 지점은 반경 약 6.36m로 분수 밖이지만 기존 상자 안입니다. 현장 증상의 가능한 원인이며, 실제 배포 맵/서버 물리 재현은 BE 확인이 필요합니다.

- 현재 FE 중심: `FOUNTAIN.x=-56`, `FOUNTAIN.z=-45`, 광장 바닥 `-1.1m`.
- 에셋 하단 원판 최대 반경은 `5.4m`, 수조 벽 반경은 `5m`입니다.
- FE 준비 파일: `frontend/src/config/parkExpansion.ts`, `EXPANSION_COLLIDERS`.
- 기존 상자 **1개를 제거하고** `fountain-basin-0` ~ `fountain-basin-47`의 48개 얇은 상자로 원판 외곽을 보수적으로 근사했습니다. 기존 상자를 함께 남기면 모서리 문제가 유지됩니다.
- 각 Z 구간 폭은 `10.8/48=0.225m`. 구간의 원점에 가장 가까운 Z 절댓값을 `d`라 하면 X 반폭은 `sqrt(5.4²-d²)`입니다. Y 중심 `0.7-plazaDepth`, 시각 반높이 `0.7`, 이동 벽 높이 `4m`는 기존 정책을 유지합니다.
- 박스 형식을 유지하는 FE 제안이며 정확한 원형/볼록 형상 지원이 가능하면 합의 후 대체할 수 있습니다. 최종 좌표는 활성 맵의 분수 위치에 맞춰주세요.

## 2. 돌 의자 통과·자동 오르기

FE `TableShell.tsx`는 야외 `table-1`~`table-4`에 돌 좌석 4개씩을 렌더링하지만, 기존 `WORLD_COLLIDERS`에는 해당 좌석 16개가 없습니다. 별도 피크닉 테이블의 낮은 돌 의자는 상자는 있으나 `movementHeight`가 없어 낮은 장애물 자동 오르기 정책의 영향을 받을 수 있습니다.

FE 준비 파일: `frontend/src/config/world.ts`, `WORLD_COLLIDERS`.

| 대상 | ID | 시각 중심/반폭 | 이동 벽 높이 |
| --- | --- | --- | --- |
| 야외 테이블 앞·뒤 좌석 | `${tableId}-stone-seat-0/1` | 테이블 위치 + 좌석 X/Z, Y=바닥+0.28; 반폭 `[1.05,0.28,0.26]` | 2.5m |
| 야외 테이블 좌·우 좌석 | `${tableId}-stone-seat-2/3` | 같은 위치 규칙; 반폭 `[0.26,0.28,0.425]` | 2.5m |
| 피크닉 돌 의자 | 기존 `${tableId}-stool-${i}` 유지 | 기존 반폭 `[0.325,0.28,0.325]` 유지 | 2.5m 추가 |

좌석의 서버 ID·인덱스·착석 좌표는 변경하지 않습니다. 앉기/일어나기는 승인된 기존 시설·테이블 경로를 사용하며, 이동 장애물 추가 후 승인 착석과 퇴장 위치가 막히지 않는지 확인해주세요. 키보드 이동으로 의자를 통과하거나 의자 위로 올라가는 것을 방지하는 기준입니다.

## 3. 서버 반영과 버전 공유

1. 실제 서비스가 `/world/park.json`을 쓰는지, 별도 생성 맵을 `PreparedParkMap` 경로로 로드하는지 먼저 확인해주세요. 최신 `docs/world-map-api.md`에는 `WORLD_MAP_SOURCE=legacy/generated` 선택이 있습니다. 기본값은 legacy이며 generated는 JSON/manifest 경로, require-match 설정과 서버 재시작·재배포가 필요합니다. 이번 FE 작업에서 실제 실행 환경은 변경하지 않았습니다.
2. 활성 맵의 분수·돌 의자 충돌 데이터를 위 FE 정의와 일치시켜주세요. `backend/tools/bake-world.mjs`의 출력만 바꾸는 것으로 활성 생성 맵까지 바뀌었다고 판단하지 말아주세요.
3. FE `movementHeight`는 시각 상자 높이가 아닙니다. 기존 변환처럼 `halfY=movementHeight/2`, `centerY=visualCenterY-visualHalfY+halfY`로 바닥을 유지해야 합니다. 카메라용 시각 높이와 구분해주세요.
4. 물리 리소스의 새 지문/`mapVersion`과 시설 카탈로그 버전·바인딩을 함께 공유해주세요. FE `EXPECTED_MAP_VERSION`, 필요한 `park-bindings*.json`은 합의된 실제 생성 값에 맞춰 후속 연결합니다. 이번 FE 작업에서는 기존 승인 버전을 임의로 바꾸거나 버전 검사를 우회하지 않았습니다.
5. 현재 FE 기본값은 `544bc6fa3890c77e8de0ec91d27f93981b4d23a477918963757e4762294ba8d0`입니다. 서버 반영 전에는 **실서버 분수/돌 의자 이동 문제가 해결됐다고 볼 수 없습니다.**

## 4. 공동 검수 조건

- 분수 주위를 걷기·달리기로 8방향 접근: 원형 에셋 밖 대각선 통로가 사각 벽에 막히지 않고, 수조/돌 원판 자체를 통과하지 않음. 캡슐 반지름에 따른 정상 여유 간격은 유지.
- 야외 돌 좌석 16개와 피크닉 의자: 정면·옆면 걷기/달리기·점프로 통과/자동 오르기 불가. 승인 착석/일어나기는 정상.
- 남녀 캐릭터의 야외 돌 좌석·목재 의자·벤치 착석: 신체·의상이 좌판을 파고들지 않음. FE는 실제 스킨의 골반 아래 표면과 의상 착석 morph를 보정하며, 서버 착석 좌표를 변조하지 않음.
- 수영: 이동 시 팔 교대 회전·발차기, 정지 시 물젓기, 입수/출수·점프 전환. 서버 `swimming/moving/running`·부력·속도는 변경 요청하지 않음. 상태/위치가 잘못되면 시간대와 WORLD_STATE·물리 로그를 함께 공유.
