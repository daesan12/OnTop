# 공원 VR 체험관 연결

- 220m 공원에서는 VR 건물 내부 표시 위치에서 E를 누르면 꼬치왕 무료 2인 협동이 열린다. 연결할 수 없을 때는 안내와 공원 복귀를 제공한다.
- PC와 VR 조작은 협동 게임에서 선택한다. 방, 진행, 종료, 서버 정산, 공원 복귀의 연결은 [협동 네트워크](SKEWER_COOP_NETWORK.md)를 따른다.
- 유료 1인 이용권은 제거했다. 과거 지갑 원장과 DB 적용 이력은 유지한다.
- 개발용으로는 [로컬 무료 연습](LOCAL_SKEWER_VR.md)이 있다. 로컬 VR 건물 미리보기에서 E를 누르면 연습 화면으로 이동한다.
