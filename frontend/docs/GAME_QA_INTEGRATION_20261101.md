공통 변경은 점프맵 상태 조회 연결, 오목 승인 착수음의 오디오 이벤트·기존 음원 별칭, 원카드 분기의 잔해 이동이다. 게임 참가·기권·복구·정산은 기존 경로를 재사용한다. `ONE_CARD` 시작 상태는 선택 필드 `dealEndsAt`을 추가하며 서버 입력 대기와 첫 차례 시간을 맞춘다. 붕어빵 v5 새 120초 판만 컴플레인을 적용하고 이전 저장 규칙의 판은 유지한다. 게임별 상세 계약은 각 `*_QA_20261101.md`를 따른다.

브라우저 검증은 HTTP/WS 계약 대역을 사용하며 실제 운영 사용자 세션을 대신하지 않는다. BE WebSocket 테스트도 인증·저장소 일부 대역과 제어 시계를 사용한다. 실제 MySQL/보상 지급·실서버 중단 로그·서버 재시작 복원은 별도 검증 범위다. DB 및 Flyway 변경이 없어 V133을 사용하지 않는다. 개발 모드의 기존 Three 경고와 번들 크기 경고는 남아 있으며 새 pageerror/console.error/오류 오버레이는 없다.

초기 전체 FE 실행의 임시 파일 EPERM과 고부하 시간 초과는 권한을 갖춘 제한 병렬 실행에서 재확인했다. 파생 맵과 코스가 다른 상태에서 발생했던 BE 실패는 버전 동기화 후 재검증했다. 원카드 소켓 시나리오는 분배 완료 뒤 행동하도록 제어 시계를 조정했다.
