최종 맵은 최신 기준과 동일한 `c05d8ada8b12d4e509f50c7e807949bd976811e1c69a628232520b88c15a0d07`이다. 오목판의 시각 높이를 게임 모듈 `OMOK_BOARD_Y`에 격리하여 공통 배치 설정과 충돌 맵 버전을 유지한다. 맵 생성기 검증 변경 0개, 테이블 18개·이동 장애물 536개 유지. 점프맵은 기존 113개 발판·규칙·전달 JSON·BE 리소스·체크섬을 유지한다. 시각 보존 검사는 의도한 돌 기단만 갱신했다. 목조 전망대나 맵 배치 전체를 교체하지 않았다.
