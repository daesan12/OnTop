# M15 공통 도움말·룰북

## 범위와 기준

- 시작점: `dev`의 `32286e13f4c94c7b1f6b228b8832daca29463e8d`.
- 브랜치: `feat/frontend-m15-manual-rulebooks`.
- 프로토타입 `topgoal/apps/web/src/features/manual/`의 한지 두루마리, 목재 축, SVG 게임 카드, 검색·분류·목차·본문 스크롤, 그림 룰북·확대 조작을 이관한다.
- 이번 범위는 공통 도움말·오목·주사위·원카드·다리 룰북과 기존 붕어빵/망원경 조작 안내 통합이다. 지도·길 안내·성능 UI 재구성은 포함하지 않는다.
- 기존 로그인/HUD/시설/테이블·게임의 REST/WS·지갑·정산을 유지한다. 신규 API, FE 정산, 인증 우회, BE·DB·Flyway 변경은 없다. 공통 도움말은 정적 FE 기능으로 새 목업이 필요하지 않다.

## 조작과 상태

- F1 또는 상단 게임 설명서 버튼. 착석·참가·관전 중에는 현재 종목, 붕어빵에서는 붕어빵, 망원경에서는 이동과 조작 안내를 연다.
- 열림 약 1.3초, 닫힘 약 0.8초(접힌 신문 표지를 보여 준 뒤 펼치고, 닫을 때 다시 접어 표지를 보여 줌); 동작 줄이기에서는 120ms. 전환 중 반복 F1은 무시하며 펼침 도중 Esc로 닫을 수 있다.
- native dialog, 전환 중 inert, 배경 스크롤 차단, Tab 순환, 닫힘 후 원래 포커스 복귀. 확대 그림은 별도 native dialog이며 Esc는 확대만 먼저 닫는다. F1은 확대와 설명서를 모두 닫는다.
- 열 때와 최종 닫힘에서 held input을 지운다. 설명서가 닫힐 때까지 이동·카메라·시설·게임 입력을 막으며 다른 패널의 입력 소유권은 보존한다. 채팅 초안과 주사위 점수표는 유지한다.
- 망원경/붕어빵의 별도 F1 창을 공통 도움말로 연결했다. 주사위 점수표의 Esc/T가 설명서 뒤에서 실행되지 않도록 우선순위를 보정했다.
- 서버 경기 시간, 붕어빵 60초, 연결/정산은 계속된다. 채널·계정 변경/연결 해제/공원 해제 시 도움말 소유권을 정리한다.

## 콘텐츠와 에셋

- 상세 규칙 원본: `src/features/manual/rulebooks/*.md`. 화면과 다운로드가 이 원본을 공유한다. 로컬 Markdown 렌더러는 제목·목록·표·인용·강조만 지원하며 HTML/외부 이미지·링크를 실행하지 않는다. 추가 패키지 의존성은 없다.
- `pnpm rulebooks:publish`로 `public/rulebooks/{id}/v1.md`를 생성한다. `pnpm build`가 배포 전 자동 갱신하며 단위 검사에서 원본 일치를 확인한다.
- 그림 재생성: `pnpm assets:rulebooks <topgoal/apps/web/public/art/rulebooks 절대 경로>`.
- 원본 5장 8,930,668B → WebP 1,005,154B(약 88.7% 감소). 원본 해상도 1672×940/941 유지, quality 90. 원본 파일은 수정하지 않았다. 출처·SHA-256·크기·해상도는 `public/art/rulebooks/manifest.json`에 기록한다.
- 현재 그림 페이지에 진입할 때만 요청한다. 최초 F1의 설명 본문은 별도 청크나 네트워크 없이 앱에 포함된다. 그림 실패 시 로컬 상세 규칙으로 전환한다.
- HTML 이미지/CSS/SVG이므로 Three 재질·GPU 텍스처·3D 그림자·LOD/섹터 병합·KTX2는 적용 대상이 아니다. WebP는 전송 용량을 줄이며 디코딩 픽셀 메모리까지 줄인다고 주장하지 않는다. 확대 창은 닫을 때 그림 노드를 제거하고 기본 창은 최근 페이지를 보존한다.

## 실행과 검증 경계

- 실행: `pnpm dev` → 기존 로그인·채널 입장 → F1. 명시적 시설 미리보기는 `pnpm dev:facilities`.
- 검사: `pnpm test`, `pnpm typecheck:tests`, `pnpm build`, `pnpm check:migration`, Playwright의 `manual.spec.ts` 및 기존 게임/붕어빵 검사. `manual-preview.spec.ts`와 기존 망원경 검사는 시설 미리보기 설정을 사용한다.
- Browser plugin이 없어 프로젝트의 기존 Playwright + Edge/WebGL2로 로컬 화면·실제 키보드/마우스 조작을 검사한다. HTTP/RawWS 계약 fixture를 사용하며 실제 개발 서버 다중 계정/지갑 정상화/지급 검증과 구분한다.
- 에셋 비교는 같은 PC/Edge, Low, 1920×1080, 8명 장면에서 원본 PNG 응답과 WebP를 비교하고 낮/밤·원본 크기·반복 열기·복귀 및 1280×720 화면을 확인한다. 기존 월드의 광고 텍스처·야간 조명 수는 시간에 따라 변하므로 전체 GL 자원 수 변화가 설명서 때문이라고 간주하지 않는다. FPS 향상이나 GPU 시간 보장은 하지 않는다.
- 기존 Three.Clock 및 Intel 드라이버 셰이더 경고는 별도로 기록하며 새 앱 오류와 구분한다. 설명서 변경은 후속 지도 작업 전에 별도 커밋·푸시로 분리한다. 머지·배포는 별도 요청 범위다.

### 삽화 비교 측정

Intel Arc 내장 GPU / Core Ultra 9 185H, Edge 156.0.4314.42, WebGL2, Low, 화면 1920×1080(실제 3D 버퍼 1280×720/DPR 0.667), 계약 fixture 8명, 같은 위치·카메라에서 측정했다. 원본 PNG는 테스트 라우트의 응답만 교체하고 제품 파일은 변경하지 않았다.

| 장면 | draw calls | triangles | 관측 FPS / 프레임 간격 p95 |
| --- | ---: | ---: | --- |
| M15 추가 전 | 329 | 1,327,249 | 113.0 / 10.7ms |
| 원본 삽화 · 낮 | 329 | 1,327,249 | 115.1 / 8.7ms |
| WebP · 낮 | 329 | 1,327,249 | 115.0 / 8.7ms |
| 원본 삽화 · 밤 | 330 | 1,328,529 | 120.0 / 8.7ms |
| WebP · 밤 | 330 | 1,328,529 | 120.0 / 8.8ms |

장면 geometry buffer 추정 43,817,200B, texture 픽셀 추정 211,435,520B는 동일했다. GL 자체 캐시 수는 원본 낮 267 geometry/40 texture, WebP 낮 269/39; 야간·광고 갱신 후 원본 268/46, WebP 270/43으로 달랐다. 기존 동적 월드의 캐시 수이며 DOM 삽화의 디코딩 메모리를 포함하지 않는다. 한 장을 RGBA 픽셀로 환산하면 약 6.3MB다. 확대와 기본 창은 같은 URL을 사용하고 캐시 관리는 브라우저에 맡긴다. 반복 열기에서 새 이미지 URL 요청은 없었다.

약 2초의 짧은 프레임 표본으로 CPU 작업 시간·GPU query 시간·전체 브라우저 메모리를 측정한 것은 아니다. 다운로드 감소와 원본 크기에서의 글자 가독성은 확인했으며 하드웨어별 FPS 향상을 주장하지 않는다. DOM 화면이므로 3D LOD/culling/shadow 전환은 추가되지 않았다. 같은 공원 낮/밤과 닫은 뒤 카메라 설정 복귀를 확인했다.
