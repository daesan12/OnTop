# 아바타 활동 말풍선 FE 구현 및 BE 인계

## 후속 반영 상태 (2026-10-29)

BE MR !192(`a6b06d6`)에서 GAME 방송·종료/기권 해제가 머지됐다. FE 수신·표시는 새 공개 의자 상태와 함께 후속 검증한다. SHOP 방송은 여전히 상점 진입·종료 계약 확정 후의 작업이다. 자세한 검증 범위는 [PUBLIC_CHAIRS_FE_INTEGRATION.md](./PUBLIC_CHAIRS_FE_INTEGRATION.md)를 참고한다. 아래 본문은 최초 FE 인계 당시의 준비 상태와 요청 기록이다.

## 범위와 반영 상태

FE 소스·테스트·문서만 수정했다. BE 코드는 변경하지 않았다.

| 상태 | 말풍선 | FE 반영 상태 |
| --- | --- | --- |
| 공개 `BUNGEOPPANG` | 붕어빵 뒤집는 중 | 기존 동작 유지 |
| 공개 `GAME` | 게임 중 | 수신·검증·표시 준비 완료. BE 방송 필요 |
| 공개 `SHOP` | 상점 이용중 | 수신·검증·표시 준비 완료. BE 방송 필요 |
| 본인 경기 | 게임 중 | 승인된 실제 경기 정보에서 자동 판단 |
| 본인 상점 | 상점 이용중 | 기존 `openShop`/`closeShop` 상태에 연결. 상점 진입 버튼은 새로 활성화하지 않음 |

다른 사람에게 본인의 새 활동을 보이게 하려면 서버가 채널 내 아바타의 공개 활동을 전달해야 한다. 로컬 UI 상태는 다른 브라우저에 전파되지 않는다. 현재 BE의 `WorldChannelRegistry`는 미니게임 확정 상태로 `BUNGEOPPANG` 또는 null만 만든다. 따라서 **이번 FE 변경만으로 실제 서버에서 원격 GAME/SHOP 말풍선이 동작한다고 보장하지 않는다.**

## FE 동작

- `src/network/avatarActivity.ts`: 허용 코드와 표시 문구를 한 곳에서 관리한다. 서버 자유 텍스트를 말풍선에 넣지 않는다.
- `src/network/protocol.ts`: 기존 선택 필드 `WORLD_STATE.avatars[].activity`에 `GAME`, `SHOP`을 추가 허용한다. 기존 BUNGEOPPANG/null/필드 생략은 호환된다.
- `src/network/worldClient.ts`: 동일 채널의 유효한 맵·최신 스냅샷만 반영하며 null/누락/퇴장/채널 정리 시 기존처럼 활동을 제거한다.
- `src/world/avatarActivity.ts`: 본인이 승인된 경기의 실제 참가자인지 확인한다. 착석·준비·시작 전·관전·정산·종료·기권 확정 상태에는 로컬 '게임 중'을 표시하지 않는다.
- `src/world/AvatarOverlays.tsx`: 기존 활동 말풍선 스타일과 위치를 공유한다. 채팅 말풍선과 분리되므로 채팅 만료에 따라 활동이 사라지지 않는다. 공개 활동이 있으면 우선 사용하고, 없으면 본인에 한해 승인된 경기/실제 열린 상점 상태를 사용한다.
- 현재 옷장만 여는 동작은 상점 이용으로 취급하지 않는다. 추후 상점 기능은 기존 상점 컨트롤러에 연결하면 본인 말풍선도 따른다.
- 본인 모델이 착석 카메라나 1인칭에서 숨겨지는 정책은 유지한다. 이 경우 본인 머리 말풍선도 화면에 보이지 않을 수 있다. 주변 사용자의 관찰 시점은 별개다.
- 새 활동 setter API나 임의의 WS 전송, 참가/관전 요청은 추가하지 않았다.

## BE 요청

### 기존 공개 활동 확장

동일한 `WORLD_STATE.avatars[].activity` 필드에 다음 코드를 전달해 주세요.

| 코드 | 의미 | 종료 |
| --- | --- | --- |
| `BUNGEOPPANG` | 기존 붕어빵 이용 | 기존 확정 종료 규칙 유지 |
| `GAME` | 현재 채널의 실제 보드게임 참가자 | 경기 종료·무효·정산 진입·기권/탈락·참가 종료 시 해제 |
| `SHOP` | 승인된 상점 이용 | 닫기·세션/채널 종료·lease 만료 시 해제 |
| `null` | 표시할 활동 없음 | 다음 공개 스냅샷에서 기존 말풍선 제거 |

게임별 상세 명칭, 비공개 패/주사위, 보상, 진행 로그는 필요 없다. 좌석만 점유하거나 게임을 고르고 준비하는 사용자는 `GAME`이 아니다. 관전자도 실제 경기 참가자로 표시하지 않는다. 다인 게임에서 탈락한 사용자만 해제하고 남은 참가자는 유지해야 한다.

`WORLD_STATE`의 채널·버전 정합성을 그대로 사용하고 상태 변경을 빠르게 방송해 주세요. 입장/재접속한 관찰자에게도 현재 스냅샷이 전달되어야 하며, 종료 상태가 사라진 후 늦은 시작 이벤트로 말풍선이 부활하면 안 된다.

### 상점 이용 승인 계약

현재 BE에는 상점 창의 열림/닫힘을 공개 활동으로 승인·해제하는 계약이 없다. 상품 목록 GET이나 지갑 GET만으로 상점 이용을 추정하지 말아 주세요. 프리패치·재시도가 실제 열림과 다르기 때문입니다.

실제 상점 도입 시 진입/종료 계약을 합의해 주세요. 필요한 내용은 인증 사용자·채널 범위, 요청/응답 형식, 멱등 키 또는 lease 식별자, 종료·재시도·연결 끊김·브라우저 종료·만료 처리입니다. 이 계약이 정해지면 FE의 `openShop`/`closeShop` 흐름에 승인 요청을 연결하고, 성공한 서버 상태만 공개 말풍선으로 방송하도록 연동하면 됩니다. 이번 FE는 이름을 추정한 메시지를 전송하지 않습니다.

서버는 사용자당 공개 활동 하나를 결정해야 합니다. 동시에 불가능한 활동은 서버의 기존 이용 제한으로 정리하고, 종료가 다른 새 활동을 지우지 않도록 활동 소유/세대도 구분해 주세요.

## 실제 서버 수용 조건

1. 브라우저 A가 보드게임에 착석·준비하는 동안 B에게 '게임 중'이 보이지 않는다.
2. A의 게임 시작이 승인되면 같은 채널 B/C에게 '게임 중'이 나타난다. 관전 없이 볼 수 있어야 한다.
3. 경기 종료·정산 진입·확정 기권/탈락 이후 말풍선이 제거된다. 다른 참가자의 진행 표시는 유지된다.
4. A가 상점 진입을 승인받으면 B에게 '상점 이용중'이 표시되고, 닫기·연결 종료·만료 시 제거된다.
5. 현재 옷장 이용을 임의로 상점 이용으로 표시하지 않는다.
6. 채팅과 함께 표시되고 채팅 만료 후에도 유효한 활동은 유지된다.
7. 다른 채널, 오래된 스냅샷, 퇴장, 재접속, 활동 교체, 중복 종료에서 상태가 섞이거나 남지 않는다.

모의 HTTP/WS 테스트는 FE 수신·표시를 검증할 뿐 BE의 실제 방송을 검증하지 않는다. BE 반영 후 두 브라우저로 위 조건을 별도 확인해야 한다.
