# M12 원카드 원본 시각 요소 보완

기준: 2026-10-24. 기존 기능과 BE 계약을 유지하는 프론트 변경이다.

## 원본과 범위

`Desktop/topgoal.zip` 및 이를 풀어둔 `Desktop/topgoal/apps/web/`의 원본을 사용한다. `features/tables/onecard/OneCardBoard.tsx`와 원본 카드 스타일를 확인했다.

게임 규칙·인증·실제 난수·패 배분·비밀 눈·기권·정산은 현재 BE 계약을 유지한다. 원본 Colyseus 연결이나 프로토타입 상태 모델은 복사하지 않는다. 게임 선택/준비, 요청 식별자·버전, ACK/최신 상태 대기, 응답 불명·복구·시간 만료 입력 차단과 관전자 권한은 기존 경로다. 새 목업 게임 엔진·가짜 결과·API를 추가하지 않는다.

원본 녹색 매트·받침, 덱 뒷면 금색 장식, 탁자별 높이, 카드 글꼴·색·선택 표현과 가로 손패를 현재 OnTop 패널에 적용했다. 본인 패는 공개 3D 장면에 전달하지 않는다.

중앙 팔각정에서는 새 매트를 겹치지 않고 기존 felt를 사용한다. 원본 높이대로 공개 카드1.078m·손패 뒷면1.077m를 배치하고 덱은 장수에 따른 높이로 놓는다. 다른 탁자는 원본 매트와 공개 카드1.112m·손패 뒷면1.107m를 사용한다. 실제 맵 탁자 배율·위치·좌석은 바꾸지 않는다.

공통 버튼 CSS가 손패 배경을 덮던 부분은 원카드 패널 범위의 선택자 우선순위를 맞췄다. 현재 API의 조작 가능 카드·선택·제출 방식은 그대로다. 카드 앞면 텍스처는 공개 바닥 카드만 생성한다. 상대 손패·덱 순서는 장면/공용 재질에 없다.

## 비용과 최적화

매트·덱·뒷면의 geometry/material을 공유하고 상대 뒷면은 최대48장 인스턴싱한다. 공개 바닥 카드 교체 시 해당 texture/material만 해제한다. 외부 카드 이미지·새 모델은 사용하지 않는다.

| --- | --- | --- | ---: | ---: |
| 기존 | 365 / 1,651,766 | 366 / 1,653,046 | 43,818,180 B | 211,959,808 B |

3 calls·16 triangles·geometry1,260B 증가다. 최종 관측 p95는 낮11.1/밤9.7ms다.

측정 조건은 Core Ultra9 185H/Intel Arc(ANGLE D3D11), Edge156.0.4314.42/WebGL2,1920×1080 Low(내부1280×720),16인·같은 착석1인칭·주야간·로컬 계약 HTTP/RawWS다. 워밍업 후240프레임 이상·GPU timer3표본을 수집했다. geometry 추정은 인스턴스 행렬·색 배열을 제외한다. 단일 장비 표본이며 별도 CPU 단계별 프로파일·다른 장비 FPS 보장은 없다.

## 동작 검수

2/3/4인 조작·개인 패 분리와 네 탁자의 매트/높이·카드 스타일·실제 제출·공개 카드 갱신을 확인했다. 바닥 카드 교체/다음 판에서 텍스처2·재질2·뒷면 인스턴스1 해제, 공유 자원 해제0개였다.

실제 React+Java의 독립 참가자101/202·관전자505로 버전51·44번째 차례까지 진행해202 EMPTY_HAND 승리를 확인했다. 실제 셔플·본인 패 격리·재접속 시 같은 패/마감·세 공개 판 일치·페이지/콘솔 오류0개를 확인했다.

첫 연속 Java 검수는 이전 경기 좌석이 남아 입장 전에 중단됐다. 제품·BE 좌석/정산 규칙은 바꾸지 않고 독립 테스트 서버에서 재실행해 통과했다.

Browser plugin not available에 따라 기존 Playwright/Edge를 사용했다. 페이지 제목·실제 본문·프레임워크 오류 오버레이 없음과 조작 후 상태를 검사했다. 타입·FE 단위27개 파일/203개·빌드·이관 경계 검사도 통과했다. 커밋별 분리본의 검사 기록은 Git 밖 QA 폴더에 별도 보관한다.

Java 검수의 로그인·프로필·목록·내부 경기 생성은 테스트 대역이며 규칙·개인/공개 RawWS·복구는 실제 BE다. 공개 경기 참조는 기존 미리보기 포트다. OAuth·DB 참가금/정산·개발 서버 배포 검수는 아니다. 수동 기권·공개 gameId 공급의 기존 미연결 항목도 유지한다. 검수 뒤 자체 테스트 서버만 종료했다. Three.Clock/ANGLE·큰3D청크 경고와 좁은 화면 전체 HUD의 한계는 남는다. PC 웹 검수이며 모바일 서비스 지원을 뜻하지 않는다.
