# 공원 공개 의자 실시간 동기화 FE 연동

## 반영 기준과 범위

BE MR !192, `a6b06d6`의 `docs/world-table-chairs-api.md` 및 `docs/world-websocket-api.md`를 확인했다. 기존 전적 화면 FE 작업을 보존하여 최신 dev 위에 반영했다. 이번 변경은 FE 소스·테스트·문서만 포함한다. BE 소스, 정적 충돌 맵, 맵 생성기, 배포 설정은 변경하지 않는다.

## 서버 승인 의자 수

서버의 전체 `WORLD_STATE.tables` 목록을 검증해 채널 범위의 `Session.publicTables`에 저장한다. 각 항목은 `{tableId,anchorId,chairCount}`이며 chairCount는 정수 2·3·4만 허용한다. 중복 tableId/anchorId와 잘못된 형식은 거절한다. 추가 비공개 필드는 표시 상태로 복사하지 않는다.

의자 표시는 다음 순서로 결정한다.

1. 맵 버전과 채널이 맞는 최신 WORLD_STATE의 공개 의자 수를 우선한다. 서버 tableId와 장면 anchorId는 기존 명시적 binding 양쪽이 일치해야 한다. 숫자 접미사나 배열 순서로 추정하지 않는다.
2. 전체 목록의 빈 배열·항목 제거·바인딩 불일치는 기본 2개로 되돌린다. 오래된 HTTP/상세 테이블 상태로 새 공개 상태를 덮지 않는다.
3. 공개 tables 필드가 없는 이전 서버에서는 기존 상세 승인 상태, HTTP chairCount, 기존 승인 인원수 fallback을 사용한다. 기존 태블릿 비활성 호환 모드도 공개 스냅샷을 받으면 서버 승인 수를 따른다.

다른 채널·낮은 버전 메시지는 기존 WORLD_STATE 규칙으로 무시한다. 맵 불일치·채널 종료·재접속 시 공개 투영을 초기화한다. 같은 공개 값이 반복되는 이동 tick에서는 저장 객체를 재사용하고, 렌더링은 의자 개수의 변경만 구독한다.

HTTP polling, 테이블 참가/관전 구독, 클라이언트 충돌 우회는 추가하지 않는다. 서버가 의자 충돌을 제어하고, FE는 그 승인 수로 모델을 표시한다. 실제 이동 승인·다른 시설 충돌·정적 맵 버전 검증과 기존 길 안내 데이터는 유지한다.

## 게임 중 말풍선

기존 `WORLD_STATE.avatars[].activity`의 GAME 수신·표시를 새 tables 필드와 함께 검증한다. 주변 사용자는 테이블 참가/관전 요청 없이 '게임 중'을 볼 수 있고, 채팅 만료와 별개로 유지한다. 서버가 해당 참가자의 활동을 null로 보내면 그 사람의 표시만 해제하고 다른 참가자의 GAME은 유지한다.

본인 경기는 기존 승인된 실제 참가 상태를 사용하며 대기·준비·관전·정산/종료 상태와 구분한다. 기존 BUNGEOPPANG 표시도 유지한다. SHOP은 미래 수신 호환과 본인 상점 컨트롤러 연결만 유지하며, **현재 BE에서 SHOP을 방송한다고 주장하지 않는다.** 상점 진입·종료 계약이 확정되면 별도 연동이 필요하다.

## 검증과 실제 서버 확인 범위

단위 테스트는 공개 목록의 형식·중복·2~4 범위, HTTP 호환, 최신 순서·채널 분리, 전체 목록 교체·초기화, 객체 재사용과 기존 맵 일치를 검증한다. 전적 화면의 응답·인증 테스트도 함께 실행한다.

브라우저에서는 실제 장면 mesh의 의자 개수가 2→3→4→2로 변하는지, 기존 HTTP 목록이 새 값을 덮지 않는지, 명시적 binding·재접속·맵 불일치·누락/빈 목록 처리를 확인한다. GAME 말풍선의 유지·해제와 기존 활동 표시, 전적·프로필 메뉴 및 게임 시작 회귀를 함께 확인한다. Browser 플러그인이 제공되지 않아 프로젝트 Playwright/Edge를 사용한다.

2026-10-29 검증 결과:

- 관련 단위 테스트 7개 파일, 111개 통과 (`publicChairState`, `tabletLobby`, `minigameActivity`, `avatarActivity`, `worldMapParity`, `gameHistory`, `movementRuntime`).
- `pnpm typecheck:tests`, `pnpm build`, `pnpm check:migration` 통과. 기존 Three.js 사용 중단 예고와 번들 크기 경고는 남아 있다.
- 정상 태블릿 모드: 공개 의자 새 시나리오 5개, 기존 공개 요약 1개, 오목·주사위·원카드·다리 게임 시작 4개, 합계 10개 통과.
- 이전 서버 호환 모드: 전적 7개, 프로필/메뉴 7개, 활동 4개, 공개 의자·GAME 병행 2개, 합계 20개 통과. 기존 활동 테스트의 진입 절차를 현재 의자 근처에서 바로 앉는 UI로 갱신했다.
- Edge `http://127.0.0.1:5278`, 데스크톱 1920×1080, 전적 화면 390×844·320×568. 페이지 제목·내용, Vite 오류 오버레이 부재, 관련 콘솔/런타임 오류 부재, 버튼 동작, 장면 mesh 수와 스크린샷을 확인했다.
- 신규 의자 검사는 `pnpm exec playwright test public-chairs.spec.ts --config playwright.tablet-default.config.ts`로 실행할 수 있다. 호환 모드의 기존 말풍선·전적·메뉴는 기본 Playwright 설정을 사용한다. 이번 실행은 기존 Vite 의존성 캐시의 영향을 피하려고 저장소 외부 임시 설정에서 포트/캐시/결과 폴더만 분리했다.
- 맵 불일치 테스트는 이후 이동 응답도 같은 불일치 맵을 유지하도록 모의 서버를 구성했다. 단 한 프레임만 다른 맵을 보내면 다음 정상 응답이 즉시 복구하여 불일치 장면을 안정적으로 관측할 수 없다.

이 검증은 FE에서 실제 HTTP/WS 계약을 재현한 모의 서버 검사다. **개발 서버의 인증된 두 브라우저 통행, BE의 실제 Bullet 충돌과 배포 완료를 직접 검증한 것은 아니다.** BE가 실제로 반영된 환경에서 산책자 두 명으로 2/3/4인 변경과 숨겨진 자리 통행, 경기 시작·기권·종료 시 주변 말풍선을 최종 대조해야 한다. BE의 WorldChairPhysicsTests/WorldPublicTablesActivityTests 추가는 코드로 확인했으며 이번 FE 작업에서 BE 테스트를 실행하거나 수정하지 않았다.
