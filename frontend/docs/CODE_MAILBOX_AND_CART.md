# 우체통·붕어빵 카트 코드 모델

## 변경 범위

두 정적 GLB의 화면 표현을 코드 형상으로 교체했다. 원본 GLB는 보관하며 파일 내용을 수정하지 않는다.
캐릭터·정자 가구·서버 코드·공통 맵 설정과 생성된 맵 데이터는 변경하지 않는다.

| 대상 | 유지한 앵커/동작 | 외형 구현 |
| --- | --- | --- |
| 우체통 | `feedback-mailbox`, `MAILBOX` 위치·높이·접근 반경, 기존 의견 작성 UI | `TraditionalMailbox.tsx`, `mailboxGeometry.ts` |
| 카트 | `fish-bread`, `MINI_PROPS[0]` 위치, 연결 상태/40m 접근 시 마운트 | `ActivityProps.tsx`, `CodeFishBreadCart.tsx`, `fishCartGeometry.ts` |

우체통은 기존 1.8m 높이와 충돌 외곽 안에 맞췄다. 카트는 기존 3.8×2.4×3.1m 범위 안에 구성했다.
실제 위치와 충돌 형상은 공통 설정을 그대로 사용한다. 새 상호작용·상점·구매 API는 추가하지 않는다.
의견 작성/전송 기능은 별도 기능 작업의 범위이며, 이 외형 교체에 포함하지 않는다.

## 외형 구성

### 소리함

- 베지어 곡면 지붕과 별도 크라운 이음선.
- 붉은 에나멜 본체, 검은 금속 받침과 고정 볼트, 하단 스커트.
- 어두운 투입구 안쪽과 비를 막는 돌출 후드·금속 입구 턱.
- 별도 서비스 문, 문틈, 경첩 마디, 황동색 잠금장치·나사.
- 입체 봉투 문양, 소리함 제목과 안내판, 측면 통풍구.

### 붕어빵 카트

- 곡면 줄무늬 차양, 스캘럽 밑단, 지붕 보강 리브와 네 기둥.
- 금속 섀시/차축, 네 고무 바퀴와 허브·볼트, 목재 프레임/패널 이음.
- 모서리 마감이 있는 조리대, 여섯 물고기 모양 구멍이 있는 조리틀과 손잡이·조절 노브.
- 얇은 프레임과 투명 패널의 진열장, 꼬리·눈·비늘 선이 있는 붕어빵 여섯 개.
- 종이 봉투·포장지·준비 도마·집게, 앞면 상호와 상단 간판·메뉴판.
- 기존 환경의 밤 상태를 따르는 차양/진열대 발광 스트립. 추가 그림자 조명은 생성하지 않는다.

간판은 로컬 CanvasTexture로 생성한다. 이미지/폰트 서비스나 새 이미지 다운로드는 사용하지 않는다.
CanvasTexture는 컴포넌트 생명주기에 맞춰 생성/해제한다.

## 렌더링 구조

`PropBuilder`로 모듈 로딩 시 한 번 형상을 만들고 재질별 정적 메시로 합친다.
구성용 임시 형상은 병합 후 해제한다. 완성 형상은 앱 생명주기 동안 공유하고
컴포넌트에서 만든 재질/간판 텍스처는 언마운트 시 해제한다.

`CraftedProp.tsx`는 재질 묶음과 LOD, 로컬 간판을 제공한다.
근거리에서는 경첩·나사·조리틀·붕어빵 장식 등 디테일을 표시하고,
원거리에서는 큰 형상과 간판을 유지하면서 장식/분할 수를 줄인다.
우체통 18m, 카트 22m와 15% 히스테리시스는 기존 GLB의 전환 거리를 따른다.
추가한 발광 재질은 기존 `NightMaterial`의 환경 상태를 사용하며, 정적 형상을 매 프레임 재생성하지 않는다.

기존 우체통 GLB의 사전 로딩은 제거했다. 두 소품을 보기 위해 GLB를 요청하지 않는다.
기존 캐릭터 로더/캐시와 원본 자산 manifest는 유지한다.

## 검증과 결과 보기

프론트 폴더에서:

```sh
pnpm typecheck:tests
pnpm build
pnpm test
pnpm exec playwright test code-props.spec.ts pavilion-furniture.spec.ts --reporter=line
```

Browser plugin not available: 기존 Playwright/Edge 설정을 사용한다.
HTTP·WebSocket·인증은 테스트 대역이다. 모델 검증은 의견 작성 UI나 맵 데이터 자동화에
의존하지 않는다. 의견 작성/저장 기능은 별도 기능 검증 대상으로 둔다.

`QA_ARTIFACT_DIR`를 지정하면 두 모델의 낮·밤·근접·1280×720 화면을 저장한다.
기본 전체 화면은 1920×1080이다. `codePropsProbe.ts`의 카메라와 검사는 테스트 전용이며 production에는 포함되지 않는다.
페이지 URL/제목, 빈 화면/오류 오버레이 부재, 콘솔 오류, 기존 GLB 요청 부재,
월드 앵커/충돌 범위 안의 시각 외곽, 근/원거리 전환 및 삼각형 감소를 확인한다.

기존 Three.Clock 폐기 예정 및 환경 셰이더 정밀도 경고는 이 변경의 오류와 구분한다.
실제 서버의 물리 판정·거리 권한·의견 저장·운영 배포와 여러 GPU의 성능은 별도 검증 대상이다.
삼각형 감소나 다운로드 제거를 실제 FPS 향상으로 간주하지 않는다.
