# 원본 테이블 화면 이관

2026-10-26. 기준은 GitLab dev `239406b`와 기존 `topgoal/apps/web/src/features/tables`다. 기존 작업 폴더의 미커밋 변경과 기권 브랜치는 보존하고 별도 `feat/frontend-prototype-table-ui`에서 FE만 수정한다.

## 화면과 조작

- 착석 전 정보/게임 설정은 원본의 짙은 녹색·금색 안내·게임 제목과 인장·좌석 목록을 사용한다. 첫 착석자의 선택, 준비 취소, 목표 점수는 기존 Spring 명령을 그대로 사용한다.
- 게임을 선택한 준비 화면과 종료 결과는 원본 `TableGathering`, `TableGatheringHud`, `gatheringModel`, `gathering.css`에서 화면·목재 안내판·UV 클릭 영역·함께 보는 카메라 계산을 이관했다. 키보드로 조작할 수 있는 보조 버튼도 유지한다.
- 준비/결과에는 본인 착석 캐릭터와 실제 주변 참가자가 보인다. 참가자의 상태는 서버 좌석/결과에 따라 머리 위에 표시한다. 빈자리를 가짜 관중으로 채우거나 실제 관전 권한을 새로 만들지 않는다.
- 원본 `minigames.css`와 게임별 HUD 구성을 사용해 원카드/다리는 왼쪽 참가자, 상단 상태, 오른쪽 공개 정보, 아래 행동 영역으로 분리한다. 주사위는 원본 갈색 HUD·점수판·굴림/Bank·도구 배치를 재사용한다. 오목은 3D 판 중심 HUD이며 별도 키보드 판을 펼칠 수 있다.
- 주변 둘러보기/판으로 돌아가기, 게임 설명, 기존 최신 상태/복구 확인을 유지한다. 경기 단계가 바뀌면 둘러보기는 초기화한다. 일어날 때 기존 시설 카메라 복귀 경로를 사용한다.
- 일반 착석의 눈높이1.95m/바라보는 높이1.85m는 원본 `SEATED_LOOK`를 사용한다. 낮은 기존 카메라에서 테이블 상판이 다리 보드를 가리던 차이를 해소하며, 게임판 집중/벤치/망원경/로밍 복귀는 기존 경로를 유지한다.
- 기존 지갑·계정·지도·F1·채팅은 보존한다. 원본과 현재 HUD의 크기가 다른 부분은 버튼/채팅이 겹치지 않게 PC 화면에서 배치한다.

## 운영 계약과 원본의 차이

- 오목은 내 차례의 판 내려다보기와 상대 차례의 착석 시점 전환을 유지한다. 카메라 세부 구현은 원본과 동일하지 않으며, 화면 비율에 따른 판 확대 계산·좌석별 판 방향·부드러운 회전/줌 전환의 완전 이관은 후속 작업이다.
- Colyseus/원본 tableClient/로컬 규칙 엔진을 가져오지 않는다. 기존 로그인, RawWS, 준비·게임 행동, 원카드 개인 손패, 다리 개인 주사위, 서버 승패·정산을 사용한다.
- 원본의 자유 오목·시간 제한 없음 안내는 현재 렌주/금수·한 수 30초, 주사위 차례 전체 30초 계약으로 표시한다. 원카드/다리의 현재 시간·규칙도 유지한다.
- 결과판은 공개 승자와 서버 결과만 사용한다. 전체 순위나 타인의 지급액을 추정하지 않는다. 관전 결과에는 준비/정산 요청과 개인 상태를 제공하지 않는다.
- 원본의 방장 `nextTableRound` 명령을 복사하지 않는다. 서버가 전체 정산 완료 및 WAITING을 확인한 뒤 `다음 판 준비`는 지난 결과 표시만 닫는다. READY_SET 없이 자동 재경기를 만들지 않는다.
- 자리 번호를 직접 골랐던 원본과 달리 현재 `TABLE_JOIN {tableId}`의 서버 좌석 배정을 유지한다. 수동 좌석 선택 계약을 새로 만들지 않는다.
- 수동 기권은 별도 `feat/frontend-game-forfeit`의 검토 대상이다. 이 브랜치는 최신 dev의 기존 기권 연결 경계를 유지하며 해당 브랜치나 BE 코드를 섞지 않는다.

## 입체 안내판의 비용과 검수 경계

원본의 박스+평면 두 메시, 14삼각형, 재질 2개, 1024×640 동적 아틀라스 1장 구성을 그대로 사용한다. 형상 버퍼 980B, RGBA 아틀라스 약2.5MiB이며 실제 GPU 전체 메모리와 다르다. 표시 내용이 같으면 텍스처를 다시 그리지 않고 프레임에는 ref 위치/회전만 갱신한다. 언마운트에서 형상 2개·재질 2개·텍스처 1개를 해제한다.

추가 이미지/GLB 다운로드와 새 의존성은 없다. 작은 UI 형상이므로 별도 LOD/GLB 전송 압축 실익이 없고, 런타임 한글 아틀라스에는 오프라인 KTX2 변환을 적용하지 않는다. 그림자는 추가하지 않으며 프러스텀 컬링과 근거리 표시 제한을 유지한다. 기존 월드와 합치지 않아 카메라/클릭/수명주기가 독립적이다.

Browser plugin not available: 프로젝트 Playwright와 Edge를 사용한다. 검증 흐름은 로그인 응답 대역 → 착석 → 게임 선택 → 준비/입체 판 클릭 → 기존 경기 명령 → 서버 결과 → 정산/WAITING → 다음 판 준비 → 기립이다. UI, 공개/개인 상태와 RawWS 계약 대역 검증이며 실제 계정·공유 DB 지급·운영 다인원 검증은 아니다.

대표 PC 화면 1920×1080, 1280×720, 1000×700을 확인한다. QA 화면/측정값/실행 설정은 저장소 밖에 보관한다. 모든 테이블·GPU·브라우저·WebGPU의 시야/성능 보증은 아니며 기존 큰 청크/Three.Clock/셰이더 경고는 별도다.

## 최종 검증

- 단위52파일/481개, 테스트 타입 검사, 배포 빌드, migration boundary 검사 통과. 기존 이동 보간 검사의 엄격한 실수 비교가 한 번 `0.9999999999999996`/`1` 차이로 실패했으며 해당 파일 수정 없이 단독9개와 전체481개 재실행에서 통과했다.
- 최종 브라우저41개 모두 통과: 기존 공개 관전9, 다리4, 주사위3, 오목5, 원카드4, 원본 화면/입체 판/PC 크기12, 테이블 로비4. 새 카메라가 원본 높이로 안정된 뒤 캡처하며, API payload/서버 상태/비공개 상태/정산 권한과 단일 소켓을 확인한다.
- 작은 설정창에서 일어나기 버튼이 스크롤 아래로 밀린 문제는 상단 고정 버튼으로 수정했다. 오목 무승부, 주사위 점수의 천 단위 구분도 서버 결과에 맞춰 확인했다. 페이지 오류·프레임워크 오류 오버레이와 새 콘솔 오류는 없었다.
- Edge/WebGL2/Low, 1280×720 실제 버퍼, P1 팔각정, 공개 아바타12개의 계약 대역 장면에서 같은 카메라로 미표시→표시→미표시→표시를 교차 측정했다. 조건별60프레임 워밍업 후180프레임 표본이다. GPU 모델/전체 GPU 메모리·서버 부하는 이 측정으로 확인하지 않았다.
