# 오목 착수음

stone-tap.wav는 2026-11-01 QA에 맞춰 직접 합성한 65ms 단일 채널 PCM 음원이다. 외부 샘플을 사용하지 않는다. 이전 stone-place.wav의 지속적인 사인파 공명을 제거하고, 광대역 충격과 빠르게 사라지는 낮은 목재 성분만 남겼다. 피치 변조·음정 공명·반향을 사용하지 않는다.

재생성: node scripts/generate-omok-place-sfx.mjs. 고정 난수로 재현하며 피크를 0.88로 제한한다. 실제 타격 에너지는 처음 20ms에 집중된다. 새 파일명으로 기존 공개 파일의 브라우저 캐시와 구분한다. 승인 착수 이벤트·효과음 버스·음량·음소거는 유지하며, 같은 착수에서 내 차례 전자음을 겹쳐 재생하지 않는다. 다른 게임 및 점프맵 음원은 변경하지 않는다.
