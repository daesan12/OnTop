# 원카드 카드 이미지

일반 카드와 카드 뒷면의 기존 출처·라이선스는 `classic/`의 문서를 따른다.

`joker-moon-color.webp`, `joker-moon-black.webp`는 2026-10-29 사용자가 첨부한 컬러/흑백 조커를 참고해 imagegen으로 다시 그린 이미지다. 초승달에 앉아 쌍안경을 보는 광대, 체크 의상, 왼쪽 위와 오른쪽 아래의 세로 JOKER 표기를 유지했다. 일반 카드와 맞는 흰 바탕과 얇은 테두리를 사용한다.

각 이미지는 640×896, 5:7 비율의 무손실 WebP다. `cardArtwork.ts`를 통해 2D 손패·현재 카드와 3D 테이블 카드가 같은 이미지를 사용한다. 원래 조커 SVG는 이전 버전으로 남기며 현재 카드 렌더링에서는 사용하지 않는다. 생성한 조커에 일반 카드의 CC0 출처를 적용하지 않는다.
