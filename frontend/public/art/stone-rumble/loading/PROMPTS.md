# 돌탑 로딩 팁 이미지 생성 프롬프트

2026-11-16 · 내장 Image Gen으로 `scene-*-native-1280.webp`의 각 장면을 한지 삽화(`scene-*-hanji-*`)로 다시 그렸다. 데스크톱용 1280/1672px WebP와 동작을 중심으로 자른 모바일용 640px WebP를 사용한다.

> 한지 위에 과슈와 수채로 그린 한국 그림책 느낌. 따뜻한 아침빛, 부드러운 옥색과 살구색, 안개 낀 공원. 갈색 머리와 남색·분홍 후드, 공중의 반투명 사각 석판을 유지한다. 16:9 화면 중앙에 동작을 모으고 왼쪽 위 제목과 하단 안내가 들어가는 곳은 차분하게 둔다. 그림 안에는 글자나 UI를 넣지 않는다.

- 발판: 남색 후드 캐릭터가 가장자리가 부서지는 황토색 돌에서 옆의 안정된 돌로 이동한다.
- 비둘기: 남색 후드 캐릭터가 비둘기 한 마리를 보내고, 분홍 후드 캐릭터가 팔을 펼치며 옆 발판에서 균형을 잡는다.
- 슬라이딩: 남색 후드 캐릭터가 두 팔을 앞으로 뻗고 발판 한 칸을 건너 다이빙한다.

2026-11-07 · 내장 Image Gen · 실제 로컬 게임 스크린샷을 스타일/캐릭터/공원/발판 레퍼런스로 사용.

글자와 버튼은 이미지에 넣지 않고 React UI로 표시한다. PNG 원본은 생성 위치에 보존하고, 사용 에셋은 동일 그림을 종횡비 변경 없이 640/1280px WebP로 변환했다.
