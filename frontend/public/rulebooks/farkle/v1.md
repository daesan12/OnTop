# 주사위 한 판

주사위 여섯 개를 굴려 점수가 되는 것을 골라요. 남은 주사위로 더 벌 수도, 지금까지 얻은 점수를 저장하고 멈출 수도 있어요.

## 준비와 승리 목표

공정한 6면체 주사위 6개를 사용하고, 먼저 할 사람은 무작위로 정해요. 두 사람 모두 총점 0점부터 시작해요.

목표는 시작 전에 서버가 확정한 2,000·4,000·6,000점 중 화면에 표시된 값이에요. 점수를 확정해 총점이 목표 이상이 되면 즉시 승리하며, 상대에게 추가 차례는 주어지지 않아요.

## 굴리고 → 고르고 → 결정해요

1. R 키 또는 굴리기 버튼으로 시작해요. 통을 마우스 왼쪽 버튼으로 잡고 앞뒤로 충분히 흔든 뒤 놓아도 돼요. 잡은 통은 Esc로 취소할 수 있어요.
2. 이번 굴림에서 점수가 되는 주사위를 클릭해 하나 이상 골라요. 선택 점수에 표시된 숫자를 확인해요.
3. 더 얻고 싶다면 ‘한 번 더!’ 버튼 또는 R 키를 눌러요. 고른 점수는 이번 턴에 쌓이고, 남은 주사위만 다시 굴려요.
4. 안전하게 가져가려면 ‘점수 챙기기’ 버튼 또는 Q 키를 눌러요. 이번 턴 점수와 선택 점수가 총점에 더해지고 상대 차례가 돼요.

> 기억해 주세요: 최소 확정 점수 제한은 없어요. 5 하나로 얻은 50점도 저장할 수 있어요. T 키로 간단한 점수표를 볼 수 있어요.

## 점수표

선택한 주사위 전부가 겹치지 않는 득점 조합에 들어가야 해요. 계산 방법이 여러 개라면 가장 높은 점수를 적용해요. 세 쌍 보너스나 특수 주사위는 없어요.

| 이번 굴림의 조합               | 점수                               |
| ------------------------------ | ---------------------------------- |
| 1 한 개 / 5 한 개              | 100점 / 50점                       |
| 같은 눈 3개: 1·1·1             | 1,000점                            |
| 같은 눈 3개: 2 / 3 / 4 / 5 / 6 | 200 / 300 / 400 / 500 / 600점      |
| 같은 눈 4개 / 5개 / 6개        | 같은 눈 3개 점수의 2배 / 4배 / 8배 |
| 1·2·3·4·5                      | 500점                              |
| 2·3·4·5·6                      | 750점                              |
| 1·2·3·4·5·6                    | 1,500점                            |

## 한 번 같이 골라 볼까요?

### 예시 · 3 · 3 · 3 · 1 · 5 · 2가 나왔다면

3·3·3과 1, 5를 고르면 300 + 100 + 50 = 450점!

남은 2 하나만 다시 굴리거나 450점을 확정해요. 여섯 개를 전부 고르면 무효예요. 2 하나는 득점 조합에 들어가지 못해요.

> 기억해 주세요: 이전 굴림에서 따로 보관한 주사위와 새로 나온 주사위를 합쳐 세 개짜리 조합을 만들 수는 없어요.

## 허탕! · 싹쓸이!

허탕!: 굴린 결과에 점수가 되는 조합이 하나도 없으면 이번 턴에 쌓은 점수를 모두 잃고 차례가 끝나요. 이미 저장한 총점은 그대로예요.

싹쓸이!: 여섯 개를 모두 득점에 쓰면 이번 턴 점수를 유지한 채 여섯 개를 다시 굴릴 수 있어요. 반복해서 이어갈 수도 있지만, 다음 굴림에서 ‘허탕!’이 나오면 이번 턴 점수는 전부 사라져요.

### 예시 · 목표가 4,000점이라면

총점 3,800점에서 이번 턴 250점을 확정하면 4,050점으로 승리해요. 확정하지 않고 다시 굴리다 ‘허탕!’이 나오면 총점은 3,800점으로 남아요.

## 제한시간과 조작

게임 설정의 ‘판 시점 고정’을 켜면 상대 차례에도 주사위 판을 볼 수 있어요. 경기 중 드래그나 Tab으로 주변 시점을 바꾸지는 않아요. Tab은 버튼 사이를 이동해요.

플레이 화면에서 Esc를 누르면 기권 확인 안내가 열려요. ‘기권 확정’을 눌러야 요청이 전송되고, ‘계속 플레이’ 또는 Esc로 취소할 수 있어요. 점수표·설명서·채팅·설정이 열려 있거나 컵을 잡고 있다면 먼저 해당 창을 닫거나 컵 조작을 취소해요. 안내를 보는 동안에도 제한시간은 계속 흘러요.

R 또는 컵 조작으로 굴리고, 득점 주사위를 선택한 뒤 Q로 확정해요. T로 점수표를 열고 닫아요. 한 차례 전체는 30초이며 재굴림·재접속으로 연장되지 않아요. 시간 초과면 이번 턴 점수만 잃고 상대에게 넘어가요. 이미 확정한 총점은 유지돼요.

목표 점수는 시작 전에 서버가 확정한 2000·4000·6000점 중 화면에 표시된 값을 따라요.
